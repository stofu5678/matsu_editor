# ADR-0012: 当面は 2GB までのファイルを扱う

- 状態: 決定
- 日付: 2026-10-10
- 変えるもの: [ADR-0001](0001-project-approach.md) の進める順序（巨大ファイルを最後に回す）

## 背景

[ADR-0005](0005-text-buffer-and-large-files.md) では、2GB を超えるファイルを範囲ごとに読む方式を、メモ帳相当の次（Phase 2）に作ることにしていた。印刷とスクリプトの互換を先に進めたいので、順番を変える。

## 決定

- 当面は、サクラと同じく 2GB までのファイルを扱う。2GB を超えるファイルは、開けない理由を示して断る
- 範囲ごとに読む方式は、ロードマップの最後のフェーズで作る
- ADR-0005 の作り（ピースツリー 1 つで編集し、元データの持ち方だけを差し替える）は変えない。差し替えの入口は Phase 1 から用意する

## 影響

- 文書へのアクセスを範囲指定で行うルール（[CLAUDE.md](../../CLAUDE.md)）は残す。後で範囲ごとに読む方式を足したときに、作り直さずに済むため
