# ADR-0015: タブとグループ

- 状態: 決定
- 日付: 2026-10-16（同じ日に、ユーザーが下の案 1 を選んだ）

## 背景

サクラエディタのタブ表示（タブバー、「ウィンドウをまとめてグループ化する」）は、文書ごとの別々のウィンドウを、見た目だけ 1 つの枠にまとめる作りになっている。タブに関わる機能は、F_SHOWTAB（タブバーの表示）、F_BIND_WINDOW（グループ化）、F_GROUPCLOSE、F_NEXTGROUP、F_PREVGROUP、F_TAB_MOVERIGHT、F_TAB_MOVELEFT、F_TAB_SEPARATE、F_TAB_JOINTNEXT、F_TAB_JOINTPREV、F_TAB_CLOSELEFT、F_TAB_CLOSERIGHT がある（F_TAB_CLOSEOTHER は、ウィンドウを単位にして PR #88 で入れた）。サクラの説明は `help/sakura/res/HLP000150.html`（タブバー）など。

UME Editor は、今は 1 つの文書に 1 つのウィンドウを使う（サクラでタブ表示を使わないときと同じ）。画面分割（PR #91）は、1 つのウィンドウの中に、同じ文書のビューを複数並べる。

GPUI には、ほかのウィンドウを取り込んで 1 つの枠の中に見せるしくみがない。サクラと同じ作りは、Windows・macOS・Linux に共通しては作れない。

## 決定

タブは、UME Editor のウィンドウの中に持つ（2026-10-16 にユーザーが選んだ）。

- 1 つのウィンドウが、タブで複数の文書を持つ。タブの中身は、今のウィンドウの中身（文書と、その画面分割）と同じ
- サクラの「グループ」は、UME Editor の 1 つのウィンドウに当たる
  - F_TAB_SEPARATE（新規グループ）: タブを新しいウィンドウへ移す
  - F_TAB_JOINTNEXT / F_TAB_JOINTPREV（次・前のグループに移動）: タブを隣のウィンドウへ移す
  - F_GROUPCLOSE（グループを閉じる）: そのウィンドウのタブをすべて閉じる
  - F_NEXTGROUP / F_PREVGROUP（次・前のグループ）: ほかのウィンドウへ切り替える
  - F_TAB_MOVERIGHT / F_TAB_MOVELEFT、F_TAB_CLOSELEFT / F_TAB_CLOSERIGHT: ウィンドウの中のタブの並びに対して働く
  - F_BIND_WINDOW（グループ化）: タブにまとめる・ばらすを切り替える
- タブバーは、サクラの既定と同じく、はじめは表示しない。表示しない間は今と同じく 1 つの文書に 1 つのウィンドウで、新しい文書は新しいウィンドウに開く。表示している間に新しい文書をどこに開くか、次・前のウィンドウ（F_NEXTWINDOW / F_PREVWINDOW）やウィンドウの一覧がタブを数えるかどうかは、サクラの設定と動きに合わせる
- 作るときは、サクラの動きを `sakura_core/window/CTabWnd.cpp` などで確かめ、根拠をコードに残す

## 見送った案

- macOS だけ OS のタブ（NSWindow のタブ）を使い、ほかの OS は上の形にする案: 見た目は OS になじむが、作りが 2 通りになり、タブの機能を OS ごとに作り分けることになる
- タブを作らない案: タブの機能 12 個が使えないままになる

## 影響

- `crates/ume-ui/src/app.rs` の `Workspace`（ウィンドウ）と、文書（`SharedDocument`）、画面分割（`PaneSet`）の関係を、ウィンドウ ⊃ タブ ⊃ ペイン にする
- ウィンドウを単位にしているもの（閉じるときの保存の確認、すべて閉じる、ウィンドウの一覧と前後、タイトル、検索パネル、マクロ、ビューモード、タグジャンプの戻り先）を、タブの単位と合わせて見直す
- モジュールの分け方（ADR-0013）は変わらない。タブは `ume-ui` の中の話で、`ume-core` と `ume-commands` は文書とビューしか知らない
