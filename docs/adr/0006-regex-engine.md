# ADR-0006: 正規表現エンジン

- 状態: 決定
- 日付: 2026-10-08（2026-10-11 に、fork する時期を変えた）

## 背景

サクラエディタは bregonig.dll（中身は Onigmo）で正規表現を処理している。上流の Onigmo は 2024-06-15 を最後に更新がなく、元になった Oniguruma も 2025-04-24 にメンテナンスを終えた。

## 決定

- Onigmo を採用する。当面は上流の Onigmo をそのまま取り込む。改修が要るとき（下の「保守の方針」の、照合の中断や Unicode の表の更新など）に、ユーザーの GitHub に fork して取り込み元にする（2026-10-11、ユーザー）
- 外部ライブラリとしてではなく、自分たちのコードとして保守する。取り込むコミットを固定し、改修は fork の上で別のコミットに分ける
- Rust から使う部品（`-sys` クレートと安全なラッパー）は自作する
- Onigmo は trait の裏に隠し、検索や UI のコードから直接呼ばない。PCRE2 などに切り替える余地を残す
- 照合は既定で 1 行ずつ行う（サクラと同じ）。行をまたぐ検索は将来の拡張として扱う
- 置換文字列の書き方（`$1` など）とオプションの意味は、bregonig の仕様に合わせて自前で実装する

## 保守の方針

- Onigmo には照合を途中で打ち切る仕組みがない。照合のループに中断の確認を入れる修正を加える（Ruby 本体にある同系統のエンジンの仕組みを参考にする）
- 照合は UI とは別のスレッドで行い、いつでも止められるようにする
- Unicode の表は 12.1.0 のままなので、同梱の生成スクリプト（`tool/enc-unicode.rb` など）で更新する
- テストは次の 3 層にする
  - Onigmo 自身のテスト（`testpy.py` の約 1,200 ケースを Rust に移植する）
  - bregonig との互換テスト（サクラのヘルプの構文一覧を元にケースを作り、期待値は Windows で bregonig.dll を実際に動かして作る）
  - ファジング（CI で回す）
- 取り込み方（git submodule か、ソースのコピーか）は Phase 2 で決める
