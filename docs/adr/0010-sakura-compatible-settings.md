# ADR-0010: 設定ファイルをサクラエディタと互換にする

- 状態: 決定
- 日付: 2026-10-10（2026-11-01 に、本文の名前を今の名前に直した。[ADR-0021](0021-rename-to-matsu.md)）
- 置き換えるもの: [ADR-0001](0001-project-approach.md) の「設定ファイルやキーワードファイルはサクラと互換にせず、独自の形式にする」と、[ADR-0008](0008-commands-and-keybindings.md) の「キー割り当ては、独自形式の設定ファイルで変更できる」

## 背景

ADR-0001 では、設定は独自の形式にし、サクラの設定の取り込みは後から別の機能として足すことにしていた。サクラから移る人が今の設定をそのまま使えるほうがよいので、方針を変える。

## 決定

- 設定ファイルは、サクラの `sakura.ini` と同じ形式で読み書きする。ファイル名は `matsu.ini` とし、サクラ自身のファイルと取り違えないようにする（2026-10-15 にユーザーが決めた）
- データベース機能（ADR-0023）の接続は、サクラにない設定なので、`matsu.ini` の隣の別のファイル `databases.ini` に置く（同じ書式。パスワードは書かない。2026-10-24 にユーザーが決めた）
- サクラが書き出す・取り込むファイル（キー割り当て、メニュー、色、キーワード、タイプ別設定など）も同じ形式で扱う
- サクラにない項目（macOS 用の設定など）は、サクラが使わない節か別のファイルに置く。サクラで開いても壊れないようにする
- 読んだが使っていない項目は、書き戻すときに消さずに残す。まだ実装していない機能の設定を失わないため

## 影響

- 設定は Phase 1 から読み書きするので、互換の読み書きは Phase 1 で作る。Phase 5 の「サクラ設定の取り込み」は不要になる
- Windows に固有の値（フォントの指定、ウィンドウの位置、パス）は、ほかの OS での読み替えを決める必要がある
- 新しい文書の改行コードの既定は OS に合わせる（Windows は CRLF、macOS と Linux は LF）。matsu.ini のタイプ別設定にあればそれに従う。設定ファイル自身の改行コードも、新しく書くときと「サクラの形式」で書くときは OS に合わせる（既存のファイルは今の改行コードのまま書き戻す）（2026-10-15 にユーザーが決めた）

## タイプ別設定（文書タイプ）の扱い（2026-10-16）

- サクラが最初から持つ 17 のタイプ（基本、テキスト、C/C++、HTML、PL/SQL、COBOL、Java、アセンブラ、AWK、MS-DOS バッチファイル、Pascal、TeX、Perl、Python、Visual Basic、リッチテキスト、設定ファイル）と、強調キーワードの 17 のセットは、プログラムが組み込みで持つ（`matsu-config` の `settings/builtin_types.rs` と `settings/keyword_data/`。出どころは `sakura_core/types/CType_*.cpp`）。`matsu.ini` がなくても、拡張子でタイプが決まり、タブ幅・折り返し・コメント・文字列・キーワードのルールが使える
- `matsu.ini` の `Types(N)` は、組み込みのタイプ N の上に重ねて読む。ファイルにないキーは組み込みの値のままなので、1 つのタイプの 1 つの設定だけを変えられる。`[Other]` の `nTypesCount`（なければ 36。サクラの 30 も 36 として読む。最大 60。ADR-0023）が 17 より大きいと、足した分は「基本」の写しで始まり、名前は `設定N` になる
- 強調キーワードのセットは、`[KeyWords]` に `nKeyWordSetNum` があれば、その節の内容で組み込みのセットをすべて置き換える（サクラと同じ）。ない場合は組み込みのまま
- タイプの選び方は `CDocTypeManager::GetDocumentTypeOfPath` に従う。番号の小さいタイプから順に拡張子の一覧と照合し、最初に合ったものにする。どれにも合わなければ 0（基本）。拡張子は大文字小文字を区別しない
- 色分け（次の PR）が読むもの: コメント（`szLineComment`/`nLineCommentColumn` の 3 組、`szBlockCommentFrom`/`To` の 2 組）、文字列（`nInts` の `stringType`、`bStringLineOnly`、`bStringEndLine`）、数値（`C[NUM]` の表示）、キーワードのセット（`nInts` と `nKeywordSelect3` から `10`）、正規表現キーワード（`bUseRegexKeyword`、`RxKey[NNN]`）、縦線（`nVertLineIdxN`）、アウトライン（`nDefaultOutline`）
- ユーザーが選んだタイプ（`F_CHANGETYPE`、`F_TYPE_LIST` の「一時適用」）は、文書の名前が変わっても変わらない。次にファイルを読み込むと、名前で決まるタイプに戻る（`CDocType::LockDocumentType`）。ファイルを別の名前で保存したときは、名前で決まるタイプに変わる

## 調べる場所

- 設定の読み書き: `sakura_core/env/CShareData_IO.cpp`、`sakura_core/env/CDataProfile.cpp`、`sakura_core/util/CProfile.cpp`
- 書き出し・取り込みのファイル: `sakura_core/typeprop/CImpExpManager.cpp`

## メニューの MATSU の版（2026-10-31）

サクラの `nMainMenuVer` は、サクラが後から足した項目だけを、保存されたメニューに足す。MATSU だけの項目（「LF改行でコピー」など）は、MATSU がその項目を入れる前に保存されたメニューに出なかった。そこで、メニューを保存する節に MATSU の版のキーを足した（2026-10-31 にユーザーが決めた）。サクラはこのキーを使わず、読まずに残す。

| 節 | キー | 今の版 | 版 1 で足す項目 |
|---|---|---|---|
| `[MainMenu]` | `nMatsuMainMenuVer` | 1 | 32700（LF改行でコピー）を 30603（CRLF改行でコピー）の後ろに、32701（CR改行でコピー）を 32700 の後ろに、32702（プレビューを別のタブで開く）を 31370（アウトプット）の後ろに |
| `[CustMenu]` | `nMatsuCustomMenuVer` | 1 | 右クリックのメニュー（メニュー 0）に、32700 と 32701 を 30603 の後ろに |

- 読むとき: キーの値が今の版より小さい（キーがなくメニューがある場合は 0）と、その版より後の項目のうち、メニューにないものだけを足す。置く場所の項目（30603 など）がメニューにないときは足さない。サクラの `Addition` と同じやり方で、`nMainMenuVer` の仕組みと表は変えない
- 書くとき: 共通設定の OK で並びが変わったときに、今の版を書く。変わらないときは何も書かない。足した項目をユーザーが消して保存すると今の版が書かれるので、もう足さない
- 書き出し・取り込みのファイル（`.mnu` など）には、この版を書かない
