# ADR-0011: 印刷

- 状態: 提案中（PoC の結果で確定する）
- 日付: 2026-10-10

## 背景

サクラエディタは印刷と印刷プレビューを持つ（ヘッダー・フッター、行番号、折り返し、段組）。印刷の仕組みは OS ごとに大きく違い、UI フレームワークの GPUI には印刷の機能がない。

## 提案

- ページへの割り付け（折り返し、行番号、ヘッダー・フッター、段組）は OS に依存しない部分で行い、結果を「ページごとの、文字とその位置の一覧」にする
- 印刷プレビューは、その一覧を GPUI で描く。3 つの OS で同じものになる
- 印刷ダイアログとプリンターへの出力だけを、OS ごとのモジュールで作る
  - Windows: GDI（サクラと同じ）
  - macOS: macOS の印刷の仕組み（Core Graphics）
  - Linux: PDF を作り、xdg-desktop-portal の印刷の仕組みに渡す

## 注意

- Linux でよく使われる GTK の印刷ダイアログは LGPL なので使わない（[CLAUDE.md](../../CLAUDE.md) のライセンスのルール）
- PDF を作るときは、日本語のフォントを必要な文字だけ埋め込む

## PoC で確かめること

- 3 つの OS で、印刷ダイアログを出し、日本語の 1 ページを印刷できるか（Linux は PDF に出力して確かめてもよい）
- 共通の割り付けの結果から、プレビューと印刷の両方を作れるか

## 調べる場所

- `sakura_core/print/CPrint.cpp`、`sakura_core/print/CPrintPreview.cpp`、`sakura_core/dlg/CDlgPrintSetting.cpp`
