# 自動保存

保存していない文書の内容を、少しずつ別の場所に残します。MATSU Editor や OS が突然止まっても、次の起動で、その文書が戻ります。

この機能は、MATSU Editor が自分で動かします。コマンドはありません。設定だけがあります。

> サクラにもある共通設定の「自動的に保存する」（一定の時間ごとに、名前のある文書を上書き保存する機能）は、別の機能です。この節の機能は、元のファイルには書きません。

## 何を残すか

- まだ一度も保存していない文書（無題）
- 名前のある文書の、保存していない変更。文字コードや BOM だけを変えた場合も含みます

次のものは残しません。

- 保存していない変更のない文書
- Grep の結果のウィンドウ、アウトプットのウィンドウ
- シェルのタブ（[シェル](shell.md)）

名前のある文書の内容も、元のファイルには書きません。別の場所に写しを作ります。

## いつ書くか

- 最後の変更から 2 秒たったとき
- 入力し続けているときは、最後に書いてから 30 秒たったとき
- ウィンドウが前面でなくなったとき、閉じるとき、MATSU Editor を終えるとき

書く作業は後ろで行うので、入力は止まりません。保存したとき、文書を閉じて「いいえ」と答えたとき、変更をすべて元に戻して変更なしになったときは、写しを消します。

## 次の起動で戻る

次に MATSU Editor を起動すると、確認なしに、残した文書を戻します。状態バーに「前回の未保存の文書を N 件戻しました。」と出ます。

- 前に開いていたウィンドウ、グループ、タブの並びに合わせて戻します。
- 戻した文書は、変更ありの状態です。無題の番号、文字コード、BOM、改行コード、文書のタイプ、キャレットの位置、先頭の行、ブックマークも戻ります。
- 元に戻すの履歴、選択範囲、検索の状態、キーボードマクロの記録は、戻りません。戻した時点から、元に戻すが始まります。
- 写しを作ったあとで、元のファイルが別のプログラムによって変わっていたときは、状態バーに「N件はディスク上のファイルが変わっています。」と出ます。
- 読めなかった写しは、戻さずに `rejected` フォルダーへ移し、状態バーで知らせます。30 日たつと、消えます。

## 終了するときの確認

ふつうは、サクラと同じように、保存していない文書があると「保存しますか」と聞きます。

設定の「終了のとき保存の確認をしない」を選ぶと、最後のウィンドウを閉じるときと、全部のウィンドウを終えるときに、聞かずに閉じます。次の起動で、文書が戻ります。

聞かない場合でも、次のときは聞きます。

- タブを 1 つ閉じるとき
- 最後でないウィンドウを閉じるとき
- 写しを書くのに失敗している文書があるとき

## 設定

共通設定の「ファイル」ページ。`matsu.ini` の `[MATSU]` に書かれます。

| 項目 | キー | 既定 | 意味 |
|---|---|---|---|
| 保存していない文書を残し、次の起動で戻す | `KeepUnsaved` | オン | 写しを作り、戻します |
| 終了のとき保存の確認をしない | `KeepUnsavedNoAsk` | オフ | 上の「終了するときの確認」。上の項目がオンのときだけ選べます |
| （画面にない） | `KeepUnsavedMaxMB` | 64 | この大きさ（MiB）を超える文書は、残しません。0 は上限なし。ファイルを直接書き換えて変えます |

「保存していない文書を残し、次の起動で戻す」をオフにすると、いま残してある写しを、消すか残すかを聞きます。「残す」を選んだ写しは、オンに戻すまで使いません。

## 大きな文書と、使えないとき

- 上限を超える文書は、写しを作りません。状態バーに「大きいため、保存していない内容を残しません。」と出て、終了のときは、ふつうに「保存しますか」と聞きます。
- 別の MATSU Editor が同じ設定のフォルダーを使っているときは、2 つ目の MATSU Editor は、この機能を使いません。状態バーに「別のマツエディタが使っているため、保存していない文書を残しません。」と出ます。
- 写しを置くフォルダーを使えないときも、状態バーで知らせます。

## 置き場所と安全

写しは、`matsu.ini` と同じフォルダーの `unsaved` フォルダーに置きます。`-PROF` で使い分けているときは、プロファイルごとにあります。

- 中身は、打った内容の平文の写しです。暗号化はしません。無題の文書に貼ったパスワードも、そのまま残ります。
- macOS と Linux では、フォルダーを自分だけが読めるようにします。
- 写しを消しても、ディスクや OS のバックアップに、内容が残ることがあります。上書きして消すことはしません。
- 共有のフォルダーに置いた持ち運び用の MATSU Editor では、ほかの人が読めることがあります。

## サクラとの違い

サクラエディタには、保存していない文書を残して戻す機能がありません。MATSU Editor だけの機能です。サクラの「自動的に保存する」は、そのまま動きます。

## 根拠

- 設定の読み込みと既定値: `crates/matsu-ui/src/unsaved/prefs.rs`
- 設定の画面: `crates/matsu-ui/src/common_settings/pages/file.rs`（`keep_unsaved`、`keep_unsaved_no_ask`）
- 書くとき・消すとき・終了: `crates/matsu-ui/src/unsaved/keeper.rs` の `DEBOUNCE`、`MAX_WAIT`、`hot_exit_enabled`
- 戻すとき: `crates/matsu-ui/src/unsaved/restore.rs` の `notice`、`restore_all`
- 置き場所と `rejected`: `crates/matsu-config/src/unsaved/store.rs` の `unsaved_dir`、`REJECTED_KEEP`
- サクラの自動保存: `crates/matsu-ui/src/file_watch/auto_save.rs`（`CAutoSaveAgent` の再現）
- 試験: `crates/matsu-ui/src/unsaved/tests.rs`、`crates/matsu-ui/src/unsaved/restore_tests.rs`、`crates/matsu-ui/src/unsaved/quit_tests.rs`
- 決めたこと: `docs/adr/0022-autosave-unsaved.md`
