# プレビュー

文書を Markdown または HTML として整えて表示するタブです。元の文書のタブの隣に開き、文書を編集すると、表示も追いかけて変わります。

## 開き方

- メニュー: 「ウィンドウ」の「プレビューを別のタブで開く」
- 機能名: `F_PREVIEW_TAB`
- マクロ: `PreviewTab()`
- 既定のキー: なし。キー割り当ての設定で割り当てられます

動きは次のとおりです。

- いま見ている文書のタブの隣に、プレビューのタブが開きます。
- その文書のプレビューがすでにあるときは、新しく開かず、そのタブへ移ります。
- プレビューのタブの上で実行しても、何も起きません。
- 文書が大きすぎるときは、タブを開かず、「大きいので、プレビューしません（2 MiB までのファイルを表示します）。」と知らせます。

## 何を表示するか

- 拡張子が `.html`、`.htm`、`.xhtml` のファイルは、HTML として表示します。
- それ以外（Markdown、プレーンテキスト、まだ名前のない文書）は、Markdown として表示します。
- 表示の形式は、プレビューのメニューで切り替えられます（下の「プレビューのメニュー」）。
- 画面の上に、「Markdown のプレビュー: 文書の名前」のような 1 行が出ます。

文書を編集すると、手を止めて 0.3 秒たったところで、表示を読み直します。

### 大きさの限り

| 文書の大きさ | 表示 |
|---|---|
| 256 KiB まで | 全部 |
| 256 KiB より大きく、2 MiB まで | 先頭の 256 KiB だけ。上の 1 行に「大きいので、先頭の 256 KiB だけを表示しています」と出ます |
| 2 MiB より大きい | 表示しません |

### 画像

文書の中の画像のうち、読み込むのは、パスで書かれたものだけです。パスは、絶対パスか、文書のあるフォルダーからの相対パスです。

次のものは、読み込みません。プレビューが、ネットワークから何かを取ってこないようにするためです。

- `http://` や `file://` で始まるアドレス
- `//ホスト名/...` や `\\ホスト名\...` のような、別の PC を指す書き方
- `data:` で文書に埋め込まれた画像

## プレビューのメニュー

プレビューのタブを見ている間は、メニューバーに「プレビュー」が出ます。

| 項目 | キー | 動き |
|---|---|---|
| 更新 | `F5` | 文書を読み直します |
| ソースに戻る | `Esc` | 元の文書のタブへ移ります。タブを閉じていたときは、同じファイルを開き直します |
| Markdown として表示 | なし | Markdown として表示します |
| HTML として表示 | なし | HTML として表示します |
| プレビューを閉じる | `Ctrl+W`（macOS は `Cmd+W`） | プレビューのタブを閉じます |

次のウィンドウ、前のウィンドウ、タブの移動と閉じる、ウィンドウの一覧など、ウィンドウの機能のキーは、プレビューを見ている間も使えます。

## サクラとの違い

サクラエディタには、プレビューのタブがありません。MATSU Editor だけの機能です（ADR-0024）。サクラの「印刷プレビュー」とは別のものです。
