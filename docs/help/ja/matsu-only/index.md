# MATSU Editor だけの機能

サクラエディタにない、MATSU Editor 独自の機能をまとめた章です。

| ページ | 何をするか |
|---|---|
| [シェル](shell.md) | シェル（端末）を、エディタとは別のタブで動かします |
| [プレビュー](preview.md) | Markdown と HTML を、元の文書の隣のタブで見ます |
| [巨大なファイル](huge-files.md) | 数 GB のファイルを、全部は読み込まずに開きます |
| [自動保存](autosave.md) | 保存していない文書を残し、次の起動で戻します |
| [データベース](database.md) | 編集中の SQL を、データベースのクライアントで実行します |
| [エンコードとデコード](encode-decode.md) | 選んだ文字列を URL・HTML・Base64 に変えます |
| [ワンライナー](oneliner.md) | 登録したシェルの 1 行で、選んだ文字列を加工します |

## この章の決まり

- ここにある機能は、サクラエディタに対応するものがありません。各ページの「サクラとの違い」では、その旨を書いています。
- 設定は、`matsu.ini` の MATSU 独自の節（`[Terminal]`、`[OneLiner]`、`[MATSU]`）か、独自のファイル（`databases.ini`）に置きます。サクラが読む節は変えません。
- 共通設定にページがあるものは、各ページに書いています。
