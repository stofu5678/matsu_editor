# 生成 AI に送る

選んでいる文字列を、生成 AI のコマンドに通し、答えを文書に入れます。専用のコマンドがあるわけではありません。[ワンライナー](oneliner.md)に「生成 AI に送る」の印を付けたものが、これです。印を付けると、実行の前に確認の窓が出て、送った内容と答えがログのタブに残ります。

たとえば、選んだ文の英訳を頼むワンライナーを登録すると、訳が選んだ文の次の行に入ります。

## 動き

1. 登録したワンライナーを実行します（[実行のしかた](oneliner.md#実行する)は、ふつうのワンライナーと同じです）。
2. 確認の窓が出ます。「送る」を押すまで、何も送りません。
3. 作業用の空のフォルダを作り、そこでコマンドを動かします。選んだ範囲（なければ文書全体）を標準入力に渡します。
4. 終わったら、答えを結果の置き場所に入れます。送った内容と答えは、ログのタブに記録します。

AI のツールを動かすのは、利用者が書いたコマンドです。MATSU Editor は、どのツールを動かすかを決めません。ツールを同梱することも、入れ方を案内することもしません。

文字列は、標準入力だけで渡します。コマンドラインにも環境変数にも入れません。API キーなどの認証は、ツール自身に任せます。MATSU Editor が、キーを渡したり、保存したりすることはありません。

## 登録する

共通設定の「ワンライナー」ページで登録します。ページの欄は[共通設定: ワンライナー](../common-settings/page-oneliner.md)にもあります。ここでは、AI に関わる欄を説明します。

| 欄 | 意味 |
|---|---|
| 生成 AI に送る | オンにすると、このワンライナーは AI のワンライナーになります。既定はオフ |
| 送る前に確認する | 実行のたびに確認の窓を出すか決めます。「生成 AI に送る」がオンのときだけ使えます。既定はオン |
| ひな形、「ひな形を入れる」 | コマンドの例を入れます（下の表） |

「ひな形を入れる」は、次の 4 つを一度にします。

- コマンドを、ひな形のものにする
- 結果の置き場所を「次の行に入れる」にする
- 「生成 AI に送る」をオンにする
- 名前が空のときだけ、名前をひな形の名前にする

「送る前に確認する」の状態は変えません。ひな形を入れたあと、コマンドの中の「ここに指示を書く」を、自分の指示に書き換えてください。

| ひな形 | 入るコマンド |
|---|---|
| Claude Code | `claude -p --no-session-persistence --tools "" --permission-mode dontAsk "ここに指示を書く"` |
| Codex CLI | `codex exec --sandbox read-only --ephemeral --skip-git-repo-check "ここに指示を書く"` |
| Ollama | `ollama run llama3.2 "ここに指示を書く"` |

- ひな形は、AI のツールが道具を使えなくするフラグ（Claude Code の `--tools ""`、Codex CLI の `--sandbox read-only`）と、ツールが会話の履歴を残さないフラグ（`--no-session-persistence`、`--ephemeral`）を入れた形です。
- フラグはツールの版で変わります。ひな形は、claude 2.1.323 と codex-cli 0.160.0 の `--help`（2026-11-13）と突き合わせたものです。動かなくなったら、ツールの説明を見て直してください。
- Ollama のひな形は、道具を切るフラグがありません。
- 「ワンライナーを入力して実行」から登録したワンライナーは、ふつうのワンライナーです。AI の印は付きません。

AI のワンライナーでも、結果の置き場所は 3 つから選べます。ひな形は「次の行に入れる」です。

## 確認の窓 {#confirm}

「AI に送る前の確認」の窓です。エディタのウィンドウの中に出て、文書を覆います。窓が出ている間、文書にキーは届きません。

窓に出るものは、次のとおりです。

- 送り先（ワンライナーの名前）
- 実行するコマンド
- 文字数、行数、大きさ
- 送る文字の最初の 10 行と最後の 5 行。間は「（n 行を省略）」と出ます。1 行は 200 文字までで、長い行は途中で切ります
- 秘密に見える行があれば、その警告（次の節）
- 次の 2 つの注意。「MATSU は、このコマンドのフラグが AI のツールを本当に切るかを確かめられません。」と、「秘密に見える行の検査は形によるものです。見つけられない秘密もあります。」

| 操作 | 動き |
|---|---|
| 「送る」を押す | 実行します |
| 「送らない」、`Esc`、窓を閉じる | 何も送りません。ワンライナーは動かず、文書も変わりません |
| 「次から聞かない（このワンライナーだけ）」 | 「送る」を押したときだけ効きます。このワンライナーの「送る前に確認する」をオフにします。次からは、窓を出さずに実行します |

- キーは、`Tab` と `Shift+Tab` で、チェック、「送る」、「送らない」の順に動かします。`Space` でチェックを切り替え、`Enter` か `Space` で、いまのボタンを押します。
- 「送る」を選ばずに終わらせたときは、状態バーに「生成 AI に送らないので、ワンライナーを実行しませんでした。」と出ます。ログのタブには、送らなかったという記録が残ります。
- 「次から聞かない」を取り消すには、共通設定の「ワンライナー」ページで、「送る前に確認する」をオンに戻します。
- 窓が読む量には、上限があります。大きな選択で窓が固まらないためです。先頭の約 4 MiB だけを調べ、それを超えるときは、文字数を「以上」と出し、「大きいので、秘密に見える行の検査は先頭の一部だけです。」と添えます。

### 大きな文字列

送る文字が 100 KB を超えるときは、窓が赤い文字で知らせます。このとき、最初にフォーカスがあるのは「送らない」です。急いで `Enter` を押しても、送りません。

### 秘密に見える行の警告

文字列に、API キーやトークンの形が見つかると、その行を一部伏せて窓に出します。見つかった行の番号と、種類が出ます。出す行は 20 行までで、残りは「ほか n 行」と数だけ出ます。警告が出ても、送るかどうかは利用者が決めます。止めることはしません。

見つける形は、次のとおりです。

| 種類 | 形 |
|---|---|
| API キー | `sk-` ではじまる長い文字列（`sk-ant-`、`sk-proj-` を含む） |
| GitHub のトークン | `ghp_`、`gho_`、`ghu_`、`ghs_`、`ghr_`、`github_pat_` |
| GitLab のトークン | `glpat-` |
| AWS のアクセスキー | `AKIA` か `ASIA` と、大文字と数字の 16 文字 |
| 秘密鍵 | `-----BEGIN ... PRIVATE KEY-----` から `-----END` まで（`OPENSSH` と PGP の鍵も） |
| Slack のトークン | `xoxb-`、`xoxa-`、`xoxp-`、`xoxr-`、`xoxs-` |
| Google の API キー | `AIza` ではじまる文字列 |
| Stripe のキー | `sk_live_`、`rk_live_` |
| JWT | `eyJ` ではじまる、ドットで区切った 3 つの部分 |
| Bearer トークン | `Bearer` のあとの長い文字列 |
| URL の中のパスワード | `scheme://user:password@host` |

この検査は、形を見るだけです。ここにない形の秘密は、見つかりません。普通の文章や日本語、コードを、秘密と間違えないように、長さと文字の混ざり方も見ています。送る前に、自分の目でも確かめてください。

## 作業用のフォルダ

AI のワンライナーは、文書のあるフォルダではなく、実行のたびに作る空の一時フォルダを作業フォルダにして動かします。AI のツールには、作業フォルダの設定を読み込むものがあるためです。文書の隣のファイルは、ツールから見えません。

- フォルダは、OS の一時フォルダの中に作ります。名前は `matsu-ai-` ではじまります。Unix 系の OS では、自分だけが入れる設定で作ります。
- 実行が終わると、結果を入れたあとで、フォルダを消します。失敗、中断のときも消します。
- 作れなかったときは、実行せず、メッセージの箱で知らせます。

ふつうのワンライナーは、これまでどおり、文書のフォルダで動きます。

## AI ログ {#ai-log}

AI に送った内容と答えを並べる、読み取り専用のタブです。タブの名前は「AI ログ」です。

### 開く

- AI のワンライナーを実行すると、ログのタブがなければ開きます。このとき、フォーカスは文書に残ります。
- メニュー「ツール」の「ワンライナー」の、いちばん下にある「AI ログを表示(L)」で、タブへ移ります。タブがなければ開きます。機能名は `F_AI_LOG_SHOW` です。登録したワンライナーの並びとは、区切り線で分かれています。macOS では、メニューの名前に `(L)` は付きません。
- ログのタブは、1 つのウィンドウに 1 つだけです。

実行している間も、記録は先に出ます。「状態: 実行中」と、動かしているコマンドの行が見えます。裏でコマンドが動いていることを、ここで確かめられます。

### 記録の中身

1 回の実行が、1 つの記録です。新しいものが下に並びます。

| 項目 | 内容 |
|---|---|
| 名前、番号 | ワンライナーの名前と、ログの中の通し番号 |
| 開始 | 開始した日時 |
| 状態 | 実行中か、終了コードとかかった時間 |
| コマンド行 | 動かしたコマンド |
| 入力 | 送った文字列 |
| 答え（標準出力） | コマンドの標準出力 |
| 標準エラー | コマンドの標準エラー出力 |

- 標準エラーは、文書の答えには混ぜず、ここにだけ出します。
- 「送らない」を選んだときは、送らなかったことが記録に残ります。
- コマンドが終了コード 0 以外で終わったときは、文書に何も入れません。終了コードと標準エラーが、アウトプットに出ます。ログにも記録が残ります。
- 1 つの文字列は 256 KiB までです。これより長いものは、先頭だけを残し、記録に切ったことと元の大きさを書きます。
- 記録は 50 件までです。超えたときは、古いものから消えます。

### 文字を選んでコピーする

記録の文字は、選んでコピーできます。コマンド行をコピーして、[シェルのタブ](shell.md)に貼れば、同じコマンドを自分で試せます。

| 操作 | キー（macOS） |
|---|---|
| コピー | `Ctrl+C`（`Cmd+C`） |
| すべて選択 | `Ctrl+A`（`Cmd+A`） |
| AI ログを閉じる | `Ctrl+W`（`Cmd+W`） |

ログのタブがアクティブなときは、メニューバーに「AI ログ(L)」だけが出ます。中身は、コピー、すべて選択、AI ログを閉じるです。

### 残らない

ログは、メモリにだけ持ちます。ファイルには書きません。[自動保存](autosave.md)にも入りません。タブを閉じるか、MATSU Editor を終えると、消えます。ログのタブを閉じても、確認は出ません。動いている実行は止まらず、その終わりの記録だけが、捨てられます。

### ウィンドウの機能のキー

次のウィンドウ（`Ctrl+Tab`）や前のウィンドウ（`Ctrl+Shift+Tab`）などの、ウィンドウの機能のキーは、ログを見ている間も使えます。タブの帯を出さない既定の設定でも、この 2 つで、文書とログのタブのあいだを行き来できます。シェルのタブとプレビューのタブと同じです。

## サクラとの違い

サクラエディタには、生成 AI に送る機能も、ワンライナーもありません。MATSU Editor だけの機能です。

## 守られないこと

- 送った文字列は、AI のサービスの外に出ます。サービスがそれをどう扱うかは、提供元と利用者の間の取り決めです。MATSU Editor は、どれも制御できません。
- ツールの道具が本当に切れているかは、MATSU Editor には分かりません。ひな形のフラグが効かない版も、ありえます。
- 秘密の検査は、形によるものです。
- 端末（シェルのタブ）には、何も送りません。AI のツールは、パイプで動かします。
