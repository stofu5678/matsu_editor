# ワンライナー

シェルの 1 行のコマンドを登録しておき、選んでいる文字列をそのコマンドに通して加工します。たとえば `sort -u` を登録すれば、選んだ行を、重複を除いて並べ替えられます。

## 動き

1. 選んでいる範囲の文字列を、コマンドの標準入力に送ります。何も選んでいないときは、文書全体を送ります。
2. コマンドの標準出力を、決めた置き場所に入れます。

文字列は、標準入力だけで渡します。コマンドラインにも環境変数にも入れません。外部コマンド実行にある `$F` のような置き換えもありません。

## 結果の置き場所

ワンライナーごとに、3 つから選びます。

| 置き場所 | 動き |
|---|---|
| 置き換える（既定） | 選んだ範囲（なければ文書全体）を、出力で置き換えます。入った文字列は、選んだ状態になります。元に戻すは 1 回で戻ります |
| 次の行に入れる | 入力の最後がある行の、次の行から、出力を行として入れます。入力は変えません。入った行は、選んだ状態になります |
| アウトプットに出す | アウトプットのウィンドウに出します。文書は変えません |

- 出力の改行は、文書の改行コードにそろえます。
- 「置き換える」では、入力の最後に改行がなく、出力の最後に改行があるときは、その改行を 1 つだけ取り除きます。`sort` や PowerShell が、最後に改行を足すためです。
- 「次の行に入れる」では、出力の最後に改行がなければ、足します。
- 文書が編集できないとき（閲覧モードなど）は、「置き換える」と「次の行に入れる」は動きません。「このウィンドウは編集できないので、ワンライナーを実行しません。」と状態バーに出ます。「アウトプットに出す」だけが使えます。
- 箱型の選択のときは、外部コマンド実行と同じです。箱の中の文字列（行ごと）を送り、「置き換える」では、箱を消して、結果をキャレットの位置に 1 回だけ入れます。「次の行に入れる」では、箱の最後の行の次に入れます。

## 実行のあいだと、失敗したとき

実行している間は、外部コマンド実行と同じ「コマンド実行中」の箱が出ます。「キャンセル」か `Esc` で、コマンドと、そのコマンドが起こした処理を止めます。文書は変わりません。

| 結果 | 文書 | 知らせ |
|---|---|---|
| 終了コードが 0 | 置き場所のとおりに変わる | 標準エラー出力があれば、アウトプットに出る |
| 終了コードが 0 以外 | 変わらない | 終了コードと標準エラー出力が、アウトプットに出る |
| キャンセル | 変わらない | 状態バーに「ワンライナーを中断しました。」 |
| 起動できない、入力を読めない | 変わらない | メッセージの箱 |
| 出力が 128 MiB を超えた | 変わらない | 「出力が 128 MiB を超えたので、止めました。」 |

- 標準エラー出力は、文書には入りません。標準出力と分けて受け取ります。
- 出力は、終わるまでためてから、文書に入れます。失敗したときに、文書を変えないためです。
- 実行している間に文書が変わったときは、結果を入れず、アウトプットで知らせます。
- 別のコマンドが動いている間は、実行しません。

## どのシェルで動くか

シェルのタブと同じシェルを使います。共通設定の「シェル」ページの「コマンドライン」（`[Terminal]` の `Shell`）から、プログラムだけを取ります。引数は使いません（`-NoExit` や `/K` が混ざるためです）。設定が空なら、[シェルのタブの既定](shell.md#どのシェルが動くか)と同じです。

「1 行を実行する」ための引数は、MATSU Editor が、プログラムの名前から決めます。

| プログラム | 動かし方 | 文字コード |
|---|---|---|
| `pwsh`、`powershell` | プロファイルを読まずに、1 行を PowerShell のスクリプトとして動かします | UTF-8 |
| `cmd` | `/D /S /C "1行"` | OEM コードページ（日本語の Windows では CP932） |
| そのほか（`sh`、`bash`、`zsh`、`fish` など） | `-c 1行` | UTF-8 |

- 起動ファイル（PowerShell のプロファイル、`.zshrc`）は読みません。そのため、別名（alias）と、`.zshrc` に書いた関数は使えません。zsh は、`-c` でも `.zshenv` は読みます。
- macOS では、ログインシェルの `PATH` を渡します。
- 作業フォルダーは、文書のあるフォルダーです。ファイルのない文書は、ホームフォルダーです。
- 環境変数は、MATSU Editor のものをそのまま渡します。何も足しません。

### PowerShell で書くとき

標準入力は、行の並びとして `$input` で読めます。

```powershell
$input | Sort-Object -Unique
```

- 入力の最後の改行は、空の行にはなりません。入力の中の空の行は、残ります。
- 終了コードに数えるのは、最後に動いた外部プログラムの終了コードだけです。外部プログラムを複数つなぐとき、途中のものが失敗しても、最後のものが成功すれば、成功として扱い、結果が文書に入ります。途中の失敗で文書が守られると期待しないでください。
- コマンドレットのエラー（失敗したコマンドレット、`Write-Error`、`throw`）は、あとのコマンドが成功しても、終了コード 1 の失敗として扱い、文書を変えません。

### cmd で使うとき

CP932 で表せない文字（絵文字など）が入力にあるときは、「入力に、シェル (cmd) の文字コードで表せない文字 (絵文字など) があります。実行しませんでした。」と知らせ、実行しません。

## 登録する

ワンライナーは、50 個まで登録できます。番号は 0 から 49 です。

### 共通設定の「ワンライナー」ページ

登録マクロのページと同じ作りです。

- 一覧から番号を選ぶか、「Id」に番号を入れます。
- 「名前」、「コマンド」、「結果の置き場所」を入れて、「設定」を押すと、一覧が書き変わります。
- OK を押すと、ファイルに書きます。キャンセルなら、何も変わりません。
- 名前は 63 まで、コマンドは 1023 までです（どちらも UTF-16 の単位で数えます）。コマンドは 1 行で書きます。コマンドのない番号は、登録されていません。名前だけでは登録できません。

このページには、生成 AI に送るための欄もあります。それは別のページで説明します（このページでは扱いません）。

### 「ワンライナーを入力して実行」

メニュー「ツール」の「ワンライナー」の「ワンライナーを入力して実行...」です。機能名は `F_ONELINER_DIALOG`、マクロは `OneLinerDialog()` です。

- 1 行の入力欄に、コマンドを書きます。履歴から選べます（最新の行が、最初から入っています）。
- 結果の置き場所を選んで、「実行」を押すと、実行します。実行した行は、履歴に入ります。履歴は 20 行までで、外部コマンド実行の履歴とは別です。
- 「登録...」を押すと、名前を聞きます。空いている最初の番号に、いまの行と置き場所を登録します。どの番号に入れたかを、画面に出します。50 個が埋まっているときは、そのことを知らせます。登録したあとも、ダイアログは閉じません。
- 編集できない文書では、置き場所は「アウトプットに出す」だけです。
- 空の行は、「ワンライナーを入力してください。」と知らせ、実行しません。

## 実行する

登録したワンライナー n を実行する方法は、次のとおりです。

- メニュー「ツール」の「ワンライナー」の下の「登録済みワンライナーリスト」。登録したものが、名前（なければコマンド）で並びます。
- 右クリックのメニューの「ワンライナー」。
- キー割り当て、カスタムメニュー、ツールバーに、機能 `F_ONELINER_0` から `F_ONELINER_49` を割り当てます。
- マクロの `OneLiner0()` から `OneLiner49()`。キーボードマクロに記録されます。

登録していない番号を実行すると、「ワンライナー n は登録されていません。」と状態バーに出ます。

メニューの「ワンライナー」の下には、登録済みの一覧のほかに、「ワンライナーを入力して実行...」と「ワンライナーの設定...」（共通設定の「ワンライナー」ページを開く。機能名 `F_ONELINER_SETTINGS`）があります。

保存してあった右クリックのメニューにも、「ワンライナー」が足されます（メニューの版 3）。アクセスキーは `7` です。

マクロとプラグインは、登録したワンライナーを実行できます。ワンライナーを登録したり変えたりする機能は、ありません。自動では動きません（ファイルを開いたとき、保存の前、など）。入力と出力を、ファイルに残すこともしません。

実行のたびの確認はありません。登録した利用者が、自分で選んで動かすものだからです。

## matsu.ini の書き方

`matsu.ini` の `[OneLiner]` に書かれます。サクラが使わない節です。

```ini
[OneLiner]
Name[000]=重複を除いて並べ替え
Command[000]=sort -u
Output[000]=0
Recent[00]=tr a-z A-Z
```

| キー | 意味 |
|---|---|
| `Name[000]` から `Name[049]` | 名前 |
| `Command[000]` から `Command[049]` | コマンド。空のときは、登録されていません |
| `Output[000]` から `Output[049]` | 0 が置き換える、1 が次の行に入れる、2 がアウトプットに出す。それ以外の値は 0 として読みます |
| `Recent[00]` から `Recent[19]` | 「入力して実行」の履歴。新しい順 |

知らないキーは、書き戻すときも残します。

## サクラとの違い

サクラエディタには、ワンライナーがありません。MATSU Editor だけの機能です。

いちばん近いのは、外部コマンド実行（`F_EXECMD`）です。違いは次のとおりです。

| | 外部コマンド実行 | ワンライナー |
|---|---|---|
| 標準エラー出力 | 標準出力とまとめる | 分けて受け取り、文書に入れない |
| シェル | `cmd.exe`（Windows）か `/bin/sh`（macOS と Linux） | シェルのタブと同じ |
