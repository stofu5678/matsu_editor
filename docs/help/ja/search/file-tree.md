# ファイルツリー

設定で決めたフォルダーとファイルを、アウトラインのペイン（[アウトライン解析](outline.md)）にツリーで出します。ファイルの項目をダブルクリックするか、選んで `Enter` かスペースキーを押すと、そのファイルを開きます。1 回クリックしただけでは、選ぶだけで開きません。

- メニュー: 検索 → ファイルツリー
- 既定のキー: なし
- マクロ: なし（機能名 `F_FILETREE`）

## ツリーに出るもの

ツリーの項目は、「ファイルツリー設定」で決めます。項目には 3 つの種類があります。

| 種類 | ツリーでの出方 |
|---|---|
| フォルダー | 枝になる。その下の深さの項目が、この枝にぶら下がる |
| ファイル | 葉になる。ダブルクリック、`Enter`、スペースキーでそのファイルを開く（1 回のクリックは選ぶだけ） |
| Grep | フォルダーの中のファイルとサブフォルダーを一覧にする。サブフォルダーは、開いたときに一覧にする |

Grep の項目のファイルの書き方は、[Grep](grep.md) の「ファイル」の欄と同じです（`*.rs;*.toml`、除外の `!*.bak`、除外フォルダーの `#target`）。一覧は、サブフォルダー、ファイルの順で出します。一覧は裏で作るので、大きなフォルダーでもウィンドウは止まりません。

## 項目をどこから読むか

次の順に決まります。

1. 設定が「共通」か「タイプ別」か。`[Common]` の `nOutlineDockSet` が 0 なら共通の設定、そうでなければ文書のタイプの設定。この値は、アウトラインのペインの右クリックメニュー「ウィンドウの位置」の「ドッキング配置を共通継承」「ドッキング配置をタイプ別継承」で切り替える
2. 設定キー `bFileTreeProject` が入なら、文書のフォルダーとその上のフォルダーから、プロジェクトのファイル `_sakurafiletree.ini` を探す。いちばん近いものの項目を使う
3. 設定キー `szFileTreeProjectIni` にファイルの名前があり、読めるなら、そのファイルの項目を使う（相対の名前は、設定ファイルのフォルダー、プログラムのフォルダーの順に探す）
4. どれもなければ、設定の項目

## 設定を変える

ペインがファイルツリーを出しているときだけ、ペインに「設定」ボタンが出ます。押すと「ファイルツリー設定」のパネルが開きます。OK で設定を書き、ツリーを読み直します。キャンセルなら何も変えません。パネルは本文の上に出て、閉じるまで他の操作を受けつけません。

## サクラエディタとの違い

- 「ファイルツリー設定」のヘルプのボタンは、灰色で効きません。
- ペインは、本文の上に浮かせる形のとき、別のウィンドウでなく本文に重なります（アウトラインと同じ）。
