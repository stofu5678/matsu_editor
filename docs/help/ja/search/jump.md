# 指定行へジャンプ

行番号を入力して、その行へ移動します。

- メニュー: 検索 → 指定行へジャンプ...
- 既定のキー: `Ctrl+J`
- マクロ: `Jump(行番号, オプション)`（機能名 `F_JUMP`）。パネルを開くのは機能名 `F_JUMP_DIALOG`

## パネル

パネルには「行番号」の入力欄、行番号の単位を選ぶ 2 つのラジオボタン、「OK」のボタンがあります。数字でない入力で OK を押しても、何も起きません。移動したらパネルは閉じます（`Esc` でも閉じます）。

行番号の単位は、次の 2 つから選びます。

- 「改行単位の行番号」（既定）: 改行で区切られた行を数えます。
- 「折り返し単位の行番号」: 折り返した表示行を、ウィンドウに見えるとおりに数えます。折り返しのない文書では、改行単位と同じです。

選んだ単位は、OK を押したときに覚えられ、次にパネルを開くときの初めの選択になります（設定ファイルの `[Other]` の `bLineNumIsCRLF`。サクラと同じ名前で、1 が改行単位です）。閉じるでやめたときは、覚えません。

`Alt+N`（「行番号(N)」）で入力欄に移り、`Alt+R`（「折り返し単位の行番号(R)」）と `Alt+W`（「改行単位の行番号(W)」）で単位を選び、`Alt+X`（「閉じる(X)」）で閉じます。

## 動き

- キャレットは、その行の先頭に動きます。
- 最終行より大きい番号は最終行になります。パネルでは 0 は先頭の行になり、負の数は受け付けません（何も起きず、パネルも閉じません）。マクロの `Jump` は、1 より小さい番号（負の数も）を先頭の行にします。
- 移動の前の位置は、移動の履歴に残ります。
- 選択のロック中は、選択を伸ばしながら動き、そうでなければ選択を外します。
- 行数をまだ調べている途中の巨大なファイルでは、調べ終わるのを待つか、ファイルの該当の部分から表示します。

## マクロのオプション

`Jump` のオプションは、次の値の合計です。省略すると 1 です。

| 値 | 意味 |
|---|---|
| 0x01 | 行番号は、改行で区切られた行を数える。付けなければ、折り返した表示行を数える |
| 0x02 | PL/SQL: 先頭から、ソースの有効な行だけを数える（空行は数えない） |

## サクラエディタとの違い

- パネルには、PL/SQL の数え方の選択がありません。マクロの `Jump` のオプションでは使えます。PL/SQL の数え始めの行は、マクロでは先頭の行に固定です。
- パネルのジャンプは、数え終わるのを待つとき以外は、キーマクロに記録されません。マクロの `Jump` が、パネルの単位の選択を書き換えることもありません。
