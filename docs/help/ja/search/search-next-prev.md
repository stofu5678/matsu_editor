# 次を検索・前を検索

直近の検索条件で、キャレットから後ろ（または前）へ次の一致を探して選びます。

- メニュー: 検索 → 次を検索 / 前を検索
- 既定のキー: `F3`（次を検索）、`Shift+F3`（前を検索）
- マクロ: `SearchNext(文字列, フラグ)`、`SearchPrev(文字列, フラグ)`（機能名 `F_SEARCH_NEXT`、`F_SEARCH_PREV`）

## 動き

- 探す文字列がまだないときは、[検索...](search.md) のパネルを開きます。
- 選択があるときは、探す前に選択を外します。次を検索ならキャレットを選択の終わりへ、前を検索なら始まりへ動かします。つまり、見つからなかったときは選択が残りません。マクロは「選択されているか」で、見つかったかどうかを調べられます。
- 見つかったら、一致を選択し、キャレットを一致の先頭に置きます。
- 長さ 0 の一致（正規表現 `^` など）の上に居るときは、次を検索で 1 文字進んでから探します。
- 選択のロック（`BeginSelect` などで選択を伸ばしている状態）のときは、選択を外さず、始点から一致までを選びます。
- 見つからなかったときは、ステータスバーに「▽見つかりませんでした」（前を検索は「△」）と出ます。選択肢「見つからないときにメッセージを表示」が入なら、箱でも知らせます。
- 「先頭（末尾）から再検索する」が入なら、文書の端で反対側から続けます。

## マクロの引数

`SearchNext` と `SearchPrev` は、文字列とフラグを渡すと、その条件を設定してから探します。引数がなければ、ウィンドウが覚えている条件を使います。フラグは次の値の合計です。

| 値 | 意味 |
|---|---|
| 0x001 | 単語単位 |
| 0x002 | 英大文字と小文字を区別 |
| 0x004 | 正規表現 |
| 0x008 | 見つからないときに知らせる |
| 0x010 | 検索パネルを閉じる |
| 0x020 | 先頭（末尾）から再検索 |
| 0x800 | 履歴に入れない |
| 0x1000 | 呼び出しのあと、元の条件に戻す |

マクロには箱に答える人がいないので、0x008 を付けないと「見つかりません」の箱は出ません。0x008、0x010、0x020 は呼ぶたびに設定され、付けなければ 0 になります。
