# 検索...

探す文字列を入力するパネルを開きます。

- メニュー: 検索 → 検索...
- 既定のキー: `Ctrl+F`
- マクロ: `SearchDialog`（機能名 `F_SEARCH_DIALOG`）

## パネルの開き方

パネルを開くと、入力欄の初期値が次のように決まります。

1. 文字列を選んでいれば、その最初の行（長い選択では先頭の一部）
2. 選んでいなければ、キャレットの位置の単語。共通設定「検索」の「カーソル位置の文字列をデフォルトの検索文字列にする」が入のときだけ（既定は入）
3. どちらもなければ、ほかのウィンドウで直近に探した文字列

選択肢は、直近の検索で使ったものを引き継ぎます。

## 選択肢

| 項目 | 意味 |
|---|---|
| 単語単位で探す | 単語として独立した一致だけを探す。「正規表現」が入のときは使えない（灰色になる） |
| 英大文字と小文字を区別する | 入にすると大文字と小文字を別の文字として扱う |
| 正規表現 | 探す文字列を正規表現として読む |
| 見つからないときにメッセージを表示 | 見つからなかったとき、ステータスバーに加えてメッセージボックスを出す（既定は入） |
| 先頭（末尾）から再検索する | 文書の端まで探して見つからなければ、反対の端から続ける（既定は切） |
| 検索ダイアログを自動的に閉じる | 見つかったらパネルを閉じる（既定は入） |

## ボタン

| ボタン | 動き |
|---|---|
| 上検索 | キャレットから前へ探す |
| 下検索 | キャレットから後ろへ探す |
| 該当行マーク | 一致した行すべてにブックマークを付ける（[ブックマーク](bookmark.md)）。探す文字列が空なら何もしない |
| 閉じる | パネルを閉じる |

`Esc` でも閉じます。パネルの中でも `F3` と `Shift+F3` で探し続けられます。探す文字列の入力欄には履歴があり、▼ のボタンで開きます。

見つけた一致は選択され、キャレットは一致の先頭に置かれます。「先頭（末尾）から再検索する」で反対の端から続けたときは、ステータスバーに「▼先頭から再検索しました」「▲末尾から再検索しました」と出ます。

正規表現が正しくないときは、その理由を箱で知らせ、検索はしません。

## サクラエディタとの違い

- 検索条件の「他のビューの条件を引き継ぐ」は、常に引き継ぐ動きに固定です。正規表現のライブラリを選ぶ項目は、MATSU Editor が自前の実装を使うので意味がありません（`docs/sakura-gaps.md`）。
- Migemo による検索の選択肢はありません。
