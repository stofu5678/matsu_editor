# DIFF差分表示

いまの文書と、別のファイル（または開いている別の文書）を行ごとに比べ、違う行に印を付けます。メニュー「検索」に、4 つの機能が入っています。

| 機能 | メニュー | 既定のキー | マクロ（機能名） |
|---|---|---|---|
| DIFF差分表示... | DIFF差分表示... | なし | `DiffDialog`（`F_DIFF_DIALOG`） |
| 次の差分へ | 次の差分へ | なし | `DiffNext`（`F_DIFF_NEXT`） |
| 前の差分へ | 前の差分へ | なし | `DiffPrev`（`F_DIFF_PREV`） |
| 差分表示の全解除 | 差分表示の全解除 | なし | `DiffReset`（`F_DIFF_RESET`） |

パネルを使わずに比べるマクロは `Diff(ファイル, フラグ)`（`F_DIFF`）です。

## DIFF差分表示...

パネルを開きます。比べる相手は、「外部ファイルを指定」（ファイルの名前を入力、「参照」で選ぶ）か、「他の編集中のファイル」（開いている文書を名前で選ぶ）です。開いている文書があるときは、初めは後者が選ばれます。

| 項目 | 意味 |
|---|---|
| 大文字小文字の同一視 | 大文字と小文字の違いを無視する |
| 空白無視 | 空白の違いをすべて無視する |
| 空白変更無視 | 空白の量の違いを無視する |
| 空白行無視 | 空行の違いを無視する |
| タブ空白変換 | 選べるが、いまの MATSU Editor では差の印に効かない（タブと空白は違うものとして比べる）。サクラエディタとの違い |
| 編集中ファイルが…: 新ファイル / 旧ファイル | いまの文書が新しい方か古い方か |
| 見つからないときにメッセージを表示 | 「次の差分」「前の差分」で見つからないとき、箱でも知らせる |
| 先頭（末尾）から再検索する | 「次の差分」「前の差分」が、端で反対側から続ける |
| DIFF差分がないときにメッセージを表示 | 違いがなかったとき、「DIFF差分は見つかりませんでした。」と箱で知らせる |

OK を押すと、いまの文書の、相手と違う行に印が付きます。相手が開いている文書なら、保存していない変更も含めた画面のとおりの内容で比べます。

印の種類は、追加、変更、削除です。印は文書に付き、編集で行が増減しても、その行に付いたまま動きます（ブックマークと同じ）。マクロの `GetLineAttribute` では、種類 3 で調べられます（1 追加、2 変更、3 削除、4 文書の終わりより後ろの削除）。

相手のファイルが見つからないときは、「差分コマンド実行は失敗しました。」に続けて理由を箱で知らせます。バイナリのファイルは「DIFF差分を行おうとしたファイルはバイナリファイルです。」と断ります。

巨大な文書は、比べません（片側が、巨大ファイルの設定のサイズ以上、または 256 MiB 以上のとき）。その旨を、箱で知らせます。

## 次の差分へ・前の差分へ

印がひとつも出ていないとき、これらと「差分表示の全解除」は、メニューで灰色になります。

印の付いた次の（前の）行へ動きます。動きは [ブックマーク](bookmark.md) の「次のブックマークへ」と同じで、選択のロック中は選択を伸ばし、端では「先頭（末尾）から再検索する」に従い、見つからないときは「前方(↓) に差分が見つかりません。」（前は「後方(↑) に…」）と知らせます。

## 差分表示の全解除

その文書の印をすべて消します。

## DIFF差分表示を使わずに比べる（`Diff` マクロ）

ファイルの名前は必須です。フラグは次の値の合計で、省略は 0 です。

| 値 | 意味 |
|---|---|
| 0x0001 | 大文字小文字の同一視 |
| 0x0002 | 空白無視 |
| 0x0004 | 空白変更無視 |
| 0x0008 | 空白行無視 |
| 0x0010 | タブ空白変換（値は受け取るが、比べ方は変わらない） |
| 0x0020 | いまの文書が旧ファイル |
| 0x0040 | 違いがないとき、そのことを知らせる |

## サクラエディタとの違い

- サクラエディタは、2 つの文書を一時ファイルに書いて、外部の `diff.exe` を動かします。MATSU Editor は、外部のプログラムを使わず、自分で差を計算します。
- 「タブ空白変換」は、選択肢にありますが、比べ方に効きません。
- ヘルプのボタンは、ありません。
