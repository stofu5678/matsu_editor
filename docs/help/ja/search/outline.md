# アウトライン解析

文書の構造（関数、クラス、見出しなど）を一覧にして、項目を選ぶとその行へ移動できるようにします。

- メニュー: 検索 → アウトライン解析...
- 既定のキー: `F11`
- マクロ: `Outline(動作)`（機能名 `F_OUTLINE`。動作は 0 で表示、1 で解析し直して表示、2 で表示と閉じるの切り替え。メニューとキーは 0 を渡します）

一覧は、編集ウィンドウの中のペインに出ます。表示と閉じるを切り替えるコマンド（`F_OUTLINE_TOGGLE`）と、一覧の印を前後にたどるコマンド（`F_FUNCLIST_NEXT`、`F_FUNCLIST_PREV`）もあります。`F_OUTLINE_TOGGLE` はメニューにありません。`F_FUNCLIST_NEXT`、`F_FUNCLIST_PREV` は、メニュー「編集」の「移動」にある「次の関数リストマーク」「前の関数リストマーク」です。

## 解析の種類

どの種類で解析するかは、タイプ別設定の「スクリーン」にある「アウトライン解析方法」で決まります。

| 種類 | ペインの名前 |
|---|---|
| C（C/C++ は、ファイル名の拡張子で C か C++ に決まる） | C 関数一覧 / C++ メソッドツリー |
| Java | Java メソッドツリー |
| Python | Python メソッドツリー |
| Perl | Perl 関数一覧 |
| Visual Basic | Visual Basic アウトライン |
| PL/SQL | PL/SQL 関数一覧 |
| COBOL | COBOL アウトライン |
| アセンブラ | アセンブラ アウトライン |
| Erlang | Erlang 関数一覧 |
| TeX | TeX |
| HTML、XML | HTML、XML |
| テキスト | テキスト トピックツリー（見出し記号は、共通設定「書式」の「見出し記号」） |
| WZ 階層付テキスト | WZ階層付テキスト |
| ルールファイル | ルールファイル |
| プラグイン | 動いているプラグインの `Outline` が選択肢に出る |

選んだ種類がサクラエディタの種類にもプラグインにもないときは、テキストのトピックになります。ブックマークの一覧は、この設定ではなく、[ブックマーク](bookmark.md)の「ブックマークの一覧...」で出します。

## ペインの使い方

- 解析は裏で動き、文書を止めません。結果は、一覧かツリーで出ます。
- 項目をクリックすると、フォーカスを動かさずにキャレットがそこへ動きます。`Enter` かダブルクリックで、動いてからフォーカスを本文に戻します。スペースキーは、動いてフォーカスはペインに残します。
- 文書を編集したあとは、結果は残りますが、キャレットに追従しなくなります。ペインの「更新」、ペインにフォーカスがあるときの `F11`、別のタブへの切り替えで、解析し直します。本文にフォーカスがあるときの `F11` は、すでに同じ種類のペインが開いていれば、そのペインにフォーカスを移すだけです。
- ペインは、左・右・上・下にドッキングでき、本文の上に重ねて浮かせることもできます。大きさは境目をドラッグして変えます。右クリックのメニューで「左ドッキング」「右ドッキング」「上ドッキング」「下ドッキング」「ドッキング禁止」を選びます。位置と大きさ、並べ替えは、設定として覚えます。
- 右クリックのメニューには、ほかに「更新」、「すべて展開」「すべて縮小」（ツリーのとき）、「ブックマーク削除」「ブックマーク全削除」（ブックマークの一覧のとき）、「閉じる」があります。
- ペインの下の「コピー」ボタンで、一覧の内容をクリップボードへ写せます。

## サクラエディタとの違い

- ペインは、別のウィンドウにせず、本文の上に重ねて浮かせます（型 B）。
- 浮かせたペインの「自動的に閉じる」「フォーカスを移す」のチェックは、ありません（ドッキングしたペインは、移動のあとフォーカスを本文に返すため）。
- 各項目の桁は、サクラエディタの解析と同じで、いつも 1 です。
