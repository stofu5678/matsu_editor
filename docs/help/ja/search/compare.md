# ファイル内容比較

いまの文書と、開いている別の文書を、キャレットの位置から文字ごとに比べて、最初に違うところへ両方のキャレットを動かします。

- メニュー: 検索 → ファイル内容比較...
- 既定のキー: `Ctrl+Enter`
- マクロ: `Compare`（機能名 `F_COMPARE`）

## パネル

比べる相手は、開いている他の文書の一覧から選びます。初めに選ばれるのは、ファイル名がいまの文書にいちばん近いものです（合うものがなければ、先頭のもの）。

| 項目 | 意味 |
|---|---|
| 相手のファイル | 比べる相手の一覧。「ソースファイル」の行に、いまの文書の名前が出る |
| 左右に並べて表示 | 比べたあと、2 つのウィンドウを左右に並べる（OS が窓の位置を決められない環境では、並べずに比べる） |
| OK | 比べる |
| キャンセル | 取りやめる |

## 動き

- 2 つの文書を、それぞれのキャレットの位置から、文字ごとに比べます。開いている文書が 2 つ未満のときは、メニューの項目が灰色になります。
- 違う場所が見つかったら、両方のキャレットをその位置へ動かしてから、「異なる箇所が見つかりました。」と知らせます。
- 比べる文字には改行の種類も含まれます。一方だけが先に終わったときも、違いとして扱います（キャレットは、短い方の最後の行の次の行頭に動きます）。
- 最後まで同じなら、「異なる箇所は見つかりませんでした。」と知らせます。
- まだ行の数を調べている途中の巨大なファイルがあるときは、比べず、調べ終わってからやり直すよう知らせます。

行ごとの違いを印で見たいときは、[DIFF差分表示](diff.md) を使います。

## 根拠

- サクラのソース: `sakura_core/cmd/CViewCommander_Diff.cpp` の `Command_COMPARE`、`sakura_core/dlg/CDlgCompare.cpp`
- MATSU のコード: `crates/matsu-ui/src/ui_commands/search/compare.rs`、`crates/matsu-ui/src/diff/compare.rs`（パネル、メッセージ、並べる動き）、`crates/matsu-core/src/diff.rs`（`first_difference`）
- 既定のキー: `crates/matsu-commands/src/sakura/key_bindings.rs`（`Enter`）
- 差: ヘルプのボタンは、ありません（`crates/matsu-ui/src/diff/compare.rs` の説明）
