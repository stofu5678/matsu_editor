# Grep置換

フォルダーの中の複数のファイルで、文字列を探して置き換えます。ファイルは書き換わります。

- メニュー: 検索 → Grep置換...（パネルを開く）
- 既定のキー: なし
- マクロ: `GrepReplace(条件, 置換後, ファイル, フォルダー, フラグ, 文字コード)`（機能名 `F_GREP_REPLACE`）。パネルを開くのは機能名 `F_GREP_REPLACE_DLG`。キーマクロの記録には入りません

## パネル

[Grep](grep.md) のパネルに、次の違いがあります。

- 「条件」が「置換前」になり、その下に「置換後」の欄が増えます。
- 「編集中のテキストから検索」は選べません（サクラエディタと同じ）。マクロやコマンドラインで、ファイルの欄に `:HWND:` を渡したときだけ、編集中のテキストを置換できます（下を見てください）。
- 実行のボタンが「置換」になります。
- 次の項目が増えます。

| 項目 | 意味 |
|---|---|
| クリップボードの内容で置換 | 置換後の文字列の代わりに、クリップボードの文字列を使う（パネルを開くたびに切に戻る）。クリップボードに文字列がないときは、「クリップボードに有効なデータがありません！」と箱で知らせる |
| バックアップ作成 | 書き換える前のファイルを、`ファイル名.skrold` として残す（既定は入）。前のバックアップは、新しい内容が置き換わった後で、新しいものに替わる |

置換前の文字列が空のときは、「置換条件を指定してください。」と箱で知らせます。

アクセスキー（`Alt` と文字）は、[Grep](grep.md) と同じように使えます。この画面で増えるのは、「置換前(N)」「置換後(Z)」（入力欄に移る）、「クリップボードの内容で置換(V)」「バックアップ作成(B)」、ボタンの「置換(R)」です。

## 動き

- 一致があったファイルだけを書き換えます。結果のウィンドウには、置換した内容と、最後に「N 個を置換しました。」が出ます。
- 文字コードに入らない文字を置換後に使ったときは、そのファイルは書き換えません（サクラエディタは `?` に替えて書きます）。
- 置換した結果のバックアップのファイル（`.skrold`）は、同じ Grep の中で探しません。

## サクラエディタとの違い

- 「編集中のテキストから検索」の相手（`:HWND:`）でも、置換します。置換は、検索が終わったときに、その文書へ 1 回の操作（元に戻すのも 1 回）で行います。検索のあいだに文書が変わったときは、何も置換せず、結果のウィンドウに知らせます。巨大なファイルを読み込んでいる最中の文書は、読み込みが終わるまで置換できません（箱で知らせます）。サクラエディタは、何も置換せずに置換した数だけを出します。
- 正規表現（`\n` など）が行の終わりの改行に一致するときは、その改行も置換されます。たとえば改行を空に置換すると、行がつながります。使うときは気をつけてください。`docs/sakura-gaps.md` には「改行込みの一致は置換しない」とありますが、コードと試験（`a_regular_expression_for_the_line_break_joins_the_lines`）は置換するので、ここはコードに従って書いています。
- 範囲ごとに読む大きさのファイル（巨大なファイル）は、全体を読み込まず、1 行ずつ読んで、新しいファイルへ書きながら置換します。メモリは、いちばん長い行の分だけです。結果の表示、置換の数、書き込む中身は、小さいファイルと同じです。64 MiB を超える行は、検索も置換もせず、そのまま残して、結果に知らせます。中断したときと、書き込めなかったときは、もとのファイルのままです。
