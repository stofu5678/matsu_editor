# Grep

フォルダーの中の複数のファイルから、文字列を探します。結果は、別のウィンドウ（または Grep 用のウィンドウ）の文書として出ます。

- メニュー: 検索 → Grep...（パネルを開く）
- 既定のキー: `Ctrl+G`
- マクロ: `Grep(条件, ファイル, フォルダー, フラグ, 文字コード)`（機能名 `F_GREP`）。パネルを開くのは機能名 `F_GREP_DIALOG`

## パネル

パネルを開くと、「条件」は、選択している文字列（なければ、キャレットの位置の単語。共通設定「検索」の同じ項目に従う）が入ります。「フォルダー」は、欄が空なら、開いているファイルのフォルダーが入ります。

| 項目 | 意味 |
|---|---|
| 条件 | 探す文字列。履歴がある |
| ファイル | 探すファイルの名前。既定は `*.*` |
| フォルダー | 探すフォルダー。`;` で区切って複数書ける。「参照」で選び、「上」で最後のフォルダーを 1 つ上にし、「現フォルダー」で開いているファイルのフォルダー（ファイルがなければプログラムのフォルダー）にする |
| 除外ファイル / 除外フォルダー | 探さないものの名前。既定は、除外ファイルが `*.msi;*.exe;*.obj;*.pdb;*.ilk;*.res;*.pch;*.iobj;*.ipdb`、除外フォルダーが `.git;.svn;.vs` |
| 編集中のテキストから検索 | ファイルを見ずに、いまのウィンドウの文書（保存していない変更を含む）から探す。このとき、ファイルとフォルダーの欄は使わない |
| サブフォルダーからも検索する | 下のフォルダーも探す（既定は入） |
| 英大文字と小文字を区別する / 単語単位で探す / 正規表現 | [検索...](search.md) と同じ意味 |
| 除外ファイルを正規表現で指定 | 除外ファイルの欄を正規表現として読む |
| フォルダーの初期値をカレントフォルダーにする | 入にすると、パネルを開くたびに、フォルダーの欄を開いているファイルのフォルダーにする。切のときは、欄が空のときだけそうする（前に使ったフォルダーが残る）。ファイルのない文書では、どちらも欄を変えない |
| 文字コードセット | ファイルを読む文字コード。既定は「自動選択」。ボタンを押すたびに次の文字コードに替わる |

### 結果の出し方

| 項目 | 選択肢 |
|---|---|
| 結果出力 | 該当行（既定）: 一致した行全体 / 該当部分: 一致した部分だけ / 否該当行: 一致しない行 |
| 出力形式 | ノーマル（既定）: 1 行ごとにファイルの名前を付ける / ファイル毎: ファイルの見出しの下に行を並べる / 結果のみ: 文字だけ |
| ファイル毎最初のみ検索 | 1 つのファイルで最初の一致だけを出す |
| ベースフォルダー表示 | 探し始めのフォルダーを見出しに出し、ファイルの名前をそこからの相対にする |
| フォルダー毎に表示 | フォルダーごとに見出しを出す |

### ファイルの書き方

「ファイル」の欄は、空白・`;`・`,` で区切って複数書けます（引用符の中は区切りません）。次のものは、探さないものになります。

- `!` で始まる要素: 除外するファイル（例 `!*.bak`）
- `#` で始まる要素: 除外するフォルダー（例 `#.git`）

ファイルの名前の大文字と小文字は、OS に関わらず区別しません。

## ボタン

| ボタン | 動き |
|---|---|
| 検索 | Grep を始める |
| キャンセル | パネルを閉じる |

ファイルの指定が正しくない、正規表現が正しくないときは、箱で知らせ、始めません。条件が空でも始められます。このときは、条件に関係なく、対象のファイルの名前だけを一覧にします。

## 結果のウィンドウ

結果は文書として出ます。いまのウィンドウが Grep のウィンドウで探索中でなければ、そこへ書きます。名前のない、変更のないウィンドウでも書きます。それ以外のときは、新しいウィンドウを開きます。

- ウィンドウの名前は `【Grep】条件`（条件は 32 文字まで）です。
- 先頭に「□検索条件」「検索対象」「フォルダー」などの見出しがあり、最後に「N 個が検索されました。」が付きます。途中でやめたときは「中断しました。」が付きます。
- 探している間は、「Grep 中  N 個  ファイル名」の小さな表示が出て、「中断」でやめられます。「リアルタイム表示」の切り替えもここにあります。探索中は、そのウィンドウを閉じられません。
- 結果の文書は、変更ありにならず、閉じるときに保存を聞きません（共通設定「検索」の「Grepモードで保存確認する」を入にすると聞きます）。
- 共通設定「検索」の「リアルタイムで表示する」が入なら、探しながら結果を出します（既定は切。終わってからまとめて書きます）。
- 結果の行は、`Enter` かダブルクリックで、その場所へジャンプできます（[タグジャンプ](tag-jump.md)）。共通設定「検索」の「Grep結果からのタグジャンプ」にある「エンターキーでタグジャンプ」「ダブルクリックでタグジャンプ」で、それぞれ切れます（既定は両方入）。
- 巨大なファイルは、全体を読まず、先頭から順に読みます。

## サクラエディタとの違い

- 標準出力へ出す設定（コマンドラインの `-GOPT=S`）と、`GetLongFileName` は、Windows だけのものなので、ありません。
- 改行をまたぐ一致は、結果に出ます。置換のときの扱いは [Grep置換](grep-replace.md) を見てください。
- 自動判別の文字コードで、タイプの CESU-8 優先の設定は使いません。
- ファイルの一覧は、名前の順です。
