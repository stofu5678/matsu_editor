# マクロの関数（3）: 検索・モード・設定・ウィンドウなど

マクロから呼べるコマンドのうち、検索、モードと設定、マクロと外部コマンド、ウィンドウとタブ、カスタムメニュー、MATSU Editor だけの関数、支援をまとめた表です。名前の並びは、マツエディタの表 `MACRO_COMMANDS` の `SearchDialog` の行から最後までです。

ほかの関数は、同じ並びの別のグループにあります。

- マクロの関数（1）: ファイル、編集、カーソル移動
- マクロの関数（2）: 選択、クリップボード、挿入、変換
- マクロの関数（4）: 値を返す関数

各言語での呼び方は「マクロの使い方」の章にあります。ここには書きません。

## 表の読み方

- **マクロ名**: マクロが呼ぶ名前です。先頭に `S_` を付けた古い書き方（`S_SearchNext` など）も通ります。大文字と小文字は区別します。
- **引数**: 型は「整数」と「文字列」の 2 つです。後ろの引数は省略できます。表にある数より多く渡すと、エラーになります。型が合わないときも、エラーになります。
- **戻り値**: このグループの関数は、どれも値を返しません。値を返す関数は、マクロの関数（4）にあります。
- **キーマクロに記録**: 「する」は、キー操作を記録したとき（キーマクロ）に、その操作が記録に入ることです。「しない」は、入らないことです。
- **MATSU での違い**: コードのコメントや試験に、サクラとの違いが書いてあるものだけを書きます。「記録なし」は、違いの記録がないという意味です。

## どの関数にも当てはまること

- ダイアログやパネルを開く関数、バックグラウンドで動く関数を、スクリプトから呼んだときは、閉じる（終わる）まで、スクリプトの時計を止めて待ちます。例外があります。ステータスバーを隠して `StatusMsg` をオプション 1 で呼ぶと、メッセージボックスが開きますが、待たずにスクリプトは進みます。
- 引数の数や型が合わないときは、マクロにエラーが返ります。
- ウィンドウが要る関数（ダイアログ、ウィンドウの操作など）は、画面のある MATSU Editor の中で動きます。
