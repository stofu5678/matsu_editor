# 支援の関数

入力補完、キーワードヘルプ、ヘルプ、コマンド一覧、バージョン情報の関数です。

## 表

| マクロ名 | 引数 | 戻り値 | 動き | キーマクロに記録 | MATSU での違い |
|---|---|---|---|---|---|
| `Complete` | なし | なし | 入力補完。キャレットの前の単語で始まる、文書の中の単語を、候補として出す。候補が 1 つなら、すぐ補う。なければ、そう知らせるだけ。 | しない | 記録なし |
| `ToggleKeyHelpSearch` | 整数（0 切り替え、1 オン、2 オフ） | なし | キャレットの下の単語を、キーワードヘルプで引くかどうかを決める。 | しない | すべてのウィンドウに効く。設定ファイルには書かない。0〜2 以外の数は、何もしない。 |
| `HelpContents` | なし | なし | ヘルプの目次を出す。 | しない | ヘルプのファイルの代わりに、Web 上のプロジェクトの文書（`docs`）を開く。 |
| `HelpSearch` | なし | なし | ヘルプの索引を出す。 | しない | ヘルプのファイルの代わりに、Web 上の、決めたことの一覧を開く。 |
| `CommandList` | なし | なし | コマンド一覧を、グループごとのメニューで出す。選ぶと、その関数を実行する。 | しない | 記録なし |
| `ExtHelp1` | なし | なし | 外部ヘルプのファイルを、キャレットの下の単語（選択があれば選択）で開く。 | しない | ファイルは、文書タイプのものを使い、なければ共通設定の「支援」のページのものを使う。どちらもないときは、設定するかどうかを尋ねる。macOS と Linux では、HTML ヘルプのファイルを単語で開けず、OS の既定の方法でファイルを開き、単語を探せなかったと知らせる。 |
| `ExtHtmlHelp` | 文字列（ファイル（省略できる））、文字列（キーワード（省略できる）） | なし | 外部の HTML ヘルプのファイルを、単語で開く。 | しない | 省略したファイルは設定のもの、省略したキーワードはキャレットの下の単語（選択があれば選択）を使う。空の文字列は、省略と同じ。macOS と Linux では、単語で開けず、OS の既定の方法でファイルを開き、単語を探せなかったと知らせる。 |
| `About` | なし | なし | バージョン情報のダイアログを出す。名前、版、ライセンス、リポジトリが載る。 | しない | 記録なし |


## 根拠

- 表の元: `crates/matsu-commands/src/sakura/macro_functions.rs`（`Complete` から `About`）
- サクラ: `sakura_core/cmd/CViewCommander_Support.cpp`
- MATSU のコード（`crates/matsu-ui/src/ui_commands/support/`）: `hokan.rs`、`toggle_key_search.rs`、`help_contents.rs`、`help_search.rs`、`menu_allfunc.rs`、`exthelp1.rs`、`exthtmlhelp.rs`、`about.rs`
- MATSU のコード: `crates/matsu-ui/src/support/help.rs`（`CONTENTS_URL`、`INDEX_URL`）
