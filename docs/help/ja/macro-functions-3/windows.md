# ウィンドウとタブの関数

ウィンドウの分割、大きさ、並べ方、切り替え、閉じること、タブの操作の関数です。

## 表

| マクロ名 | 引数 | 戻り値 | 動き | キーマクロに記録 | MATSU での違い |
|---|---|---|---|---|---|
| `SplitWinV` | なし | なし | ウィンドウを上下の 2 つのペインに分ける。すでに分けてあるときは、分割をやめる。 | しない | 記録なし |
| `SplitWinH` | なし | なし | ウィンドウを左右の 2 つのペインに分ける。すでに分けてあるときは、分割をやめる。 | しない | 記録なし |
| `SplitWinVH` | なし | なし | ウィンドウを 4 つのペインに分ける。すでに分けてあるときは、分割をやめる。 | しない | 記録なし |
| `WinMaximize` | なし | なし | ウィンドウを最大化する。 | しない | すでに最大化してあるときは、何もしない（GPUI が切り替えしかできないため）。 |
| `WinMinimize` | なし | なし | ウィンドウを最小化する。 | しない | 記録なし |
| `WinRestore` | なし | なし | ウィンドウを元の大きさに戻す。最大化も、最小化も、元に戻る。 | しない | Windows と macOS では、OS の機能を呼ぶ。Linux では、最大化だけ戻し、最小化は戻せない。 |
| `WinClose` | なし | なし | ウィンドウを閉じる。未保存の変更があるときは、保存するかどうかを尋ねる。 | しない | 記録なし |
| `WinCloseAll` | なし | なし | すべてのウィンドウを閉じる。未保存の変更があるウィンドウでは、保存するかどうかを尋ね、取りやめると、残りのウィンドウは残る。 | しない | 「複数のウィンドウを閉じますか」の確認は、まだない（設定 `bCloseAllConfirm` を読まない）。 |
| `CascadeWin` | なし | なし | ウィンドウを重ねて並べる。最小化したウィンドウはそのまま。ほかは、作業領域の 5 分の 4 の大きさで、1 つずつ右下へずらす。このウィンドウが最後で、いちばん手前。 | しない | Linux（Wayland）は、ウィンドウを動かせないので、動かせないと知らせる。 |
| `TileWinV` | なし | なし | ウィンドウを、上下に並べる。最小化したウィンドウはそのまま。このウィンドウが上になる。 | しない | Linux は、動かせないと知らせる。 |
| `TileWinH` | なし | なし | ウィンドウを、左右に並べる。最小化したウィンドウはそのまま。このウィンドウが左になる。 | しない | Linux は、動かせないと知らせる。 |
| `NextWindow` | なし | なし | 次のウィンドウを手前に出す。ウィンドウは、開いた順に回る。 | しない | タブ表示のときは、次のタブへ移る。 |
| `PrevWindow` | なし | なし | 前のウィンドウを手前に出す。 | しない | タブ表示のときは、前のタブへ移る。 |
| `WindowList` | なし | なし | ウィンドウの一覧を、ポップアップで出す。選ぶと、そのウィンドウが手前に出る。 | しない | タブバーがあるときは、タブバーの ▼ ボタンと同じ一覧になる。 |
| `MaximizeV` | なし | なし | ウィンドウの高さを、作業領域いっぱいにする。 | しない | Linux は、動かせないと知らせる。 |
| `MaximizeH` | なし | なし | ウィンドウの幅を、作業領域いっぱいにする。 | しない | Linux は、動かせないと知らせる。 |
| `MinimizeAll` | なし | なし | すべてのウィンドウを最小化する。 | しない | 記録なし |
| `ReDraw` | なし | なし | ビューを描き直す。 | する | 記録なし |
| `ActivateWinOutput` | なし | なし | マクロが `TraceOut` で書く内容を出す、出力のパネルを表示する。 | する | サクラのような専用のウィンドウはなく、マクロを動かしたウィンドウの、テキストの下のパネルを表示する。 |
| `WindowTopMost` | 整数（0 切り替え、1 つける、2 はずす） | なし | ウィンドウを、いつも手前に出すかどうかを決める。 | する | Windows と macOS で動く。Linux は、できないと知らせる。0〜2 以外の数は、何もしない。 |
| `GroupClose` | なし | なし | このウィンドウの、すべてのタブを閉じる。 | しない | グループは、ウィンドウ 1 つに当たる。タブバーがあるとき以外は、何もしない。 |
| `NextGroup` | なし | なし | 次のグループ（ウィンドウ）を手前に出す。 | しない | グループは、ウィンドウ 1 つに当たる。開いた順に回る。 |
| `PrevGroup` | なし | なし | 前のグループ（ウィンドウ）を手前に出す。 | しない | `NextGroup` と同じ。 |
| `TabMoveRight` | なし | なし | タブを 1 つ右へ動かす。右端では、何もしない。 | しない | ウィンドウの中のタブの順だけを替える。 |
| `TabMoveLeft` | なし | なし | タブを 1 つ左へ動かす。 | しない | `TabMoveRight` と同じ。 |
| `TabSeparate` | なし | なし | タブを、新しいウィンドウへ取り出す。ペイン、キャレット、取り消しの履歴は、いっしょに移る。 | しない | タブ表示のときだけ。ウィンドウのただ 1 つのタブは、取り出せない。 |
| `TabJointNext` | なし | なし | タブを、次のウィンドウへ移す。移したタブが、そのウィンドウの表示中のタブになる。 | しない | タブがなくなったウィンドウは閉じる。 |
| `TabJointPrev` | なし | なし | タブを、前のウィンドウへ移す。 | しない | `TabJointNext` と同じ。 |
| `TabCloseOther` | なし | なし | このタブ以外を、閉じる。タブ表示でないときは、ほかのウィンドウを閉じる。このウィンドウは残る。 | しない | 未保存の変更があるタブでは、保存するかどうかを尋ね、取りやめると、そこで止まる。 |
| `TabCloseLeft` | なし | なし | このタブより左のタブを、閉じる。 | しない | 未保存の変更があるタブでは、保存するかどうかを尋ね、取りやめると、そこで止まる。 |
| `TabCloseRight` | なし | なし | このタブより右のタブを、閉じる。 | しない | `TabCloseLeft` と同じ。 |


## タブとグループ

- MATSU Editor では、グループはウィンドウ 1 つに当たります（ADR-0015）。
- 「グループ」の名が付く関数は、タブバーがあるときのウィンドウの単位で動きます。
- ウィンドウを動かす関数（`CascadeWin`、`TileWinV`、`TileWinH`、`MaximizeV`、`MaximizeH`、`WindowTopMost`）は、OS の機能を使います。Linux（Wayland）では、プログラムがウィンドウの位置や重なりを決められないので、できないと知らせます。
