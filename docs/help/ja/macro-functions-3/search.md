## 検索と置換の引数 {#search-args}

`SearchNext`、`SearchPrev`、`Replace`、`ReplaceAll` の最後の引数は、次の値を足して作ります。

| 値 | 意味 |
|---|---|
| 0x001 | 単語として探す |
| 0x002 | 大文字小文字を区別する |
| 0x004 | 正規表現 |
| 0x008 | 見つからないとき、知らせる |
| 0x010 | 検索のダイアログを、検索のあとで閉じる |
| 0x020 | 先頭（末尾）から探し直す |
| 0x040 | （置換）クリップボードの貼り付けで置換する。エラーになる |
| 0x080 | （すべて置換）選択の中だけ |
| 0x100 | （置換）一致の前に入れる |
| 0x200 | （置換）一致の後ろに入れる |
| 0x300 | （置換）一致のある行を削除する |
| 0x400 | （すべて置換）置換を繰り返す |
| 0x800 | 文字列を履歴に入れない |
| 0x1000 | 呼び出しのあとで、検索の設定を元に戻す |

- 検索する文字列があるときだけ、0x001、0x002、0x004 を設定します。文字列が空なら、これまでの設定のままです。
- 0x008、0x010、0x020 は、引数があるたびに決まります。足さなければ、オフになります。
- マクロには答える人がいないので、見つからないことを知らせるのは 0x008 を足したときだけです。
- 正規表現が正しくないときは、メッセージを出し、検索も置換もせずに、マクロは続きます。
- 置換のやり方は、0x100 と 0x200 の 2 ビットで決まります。ビットがなければ置き換え、0x100 なら前に入れ、0x200 なら後ろに入れ、両方なら行を削除します。
- 履歴に入れる文字列は、260 文字より短いものだけです。0x1000 を足すと、履歴には入れません。
- 一度の置換（`Replace`）は、選択を範囲として使いません。

## Grep のフラグ {#grep-flags}

`Grep` の 4 つ目の引数です。省略すると 5 です。

| 値 | 意味 |
|---|---|
| 0x01 | サブフォルダーも探す |
| 0x04 | 大文字小文字を区別する |
| 0x08 | 正規表現 |
| 0x10 | 文字コードを自動判定する（古いマクロのため） |
| 0x20 | 該当行を出す |
| 0x40 | ファイルごとに出す |
| 0x80 | 結果だけを出す |
| 0x100 から 0xff00 | 文字コードの番号に 0x100 を掛けた値 |
| 0x10000 | 単語として探す |
| 0x20000 | ファイルごとに、最初の一致だけ出す |
| 0x40000 | 基準フォルダーからの相対パスで出す |
| 0x80000 | フォルダーごとに分けて出す |
| 0x400000 | 一致しなかった行を出す |
| 0x800000 | 除外するファイルを正規表現にする |

`GrepReplace` には、次の 2 つも足せます。

| 値 | 意味 |
|---|---|
| 0x100000 | クリップボードから貼り付ける |
| 0x200000 | バックアップを作る |

文字コードの番号は、サクラの番号です。99 は自動判定です。5 つ目の引数は、その番号をそのまま渡します。

## Jump のオプション {#jump-options}

| 値 | 意味 |
|---|---|
| 0x01 | 行を、改行までの 1 行として数える。なければ、折り返した表示行で数える |
| 0x02 | PL/SQL。ソースとして有効な行だけを、先頭から数える |

- 省略すると 0x01 です。
- PL/SQL の数え方は、空行と、`/* */` の中の空行を数えません。`--` の注釈の行は数えます。ダイアログのように、数え始める行を選ぶことは、マクロからはできません。数え始めは、先頭行です。

## Diff のフラグ {#diff-flags}

| 値 | 意味 |
|---|---|
| 0x01 | 大文字小文字の違いを無視する |
| 0x02 | 空白の違いをすべて無視する |
| 0x04 | 空白の量の違いを無視する |
| 0x08 | 空行を無視する |
| 0x10 | タブを展開して比べる |
| 0x20 | このウィンドウが古いほう |
| 0x40 | 差がないとき、そう知らせる |

フラグは整数です。文字列を渡すと、エラーになります。
