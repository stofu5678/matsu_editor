# マクロの関数（1）

この章は、マクロから呼べる関数のうち、ファイル・編集・カーソル移動・スクロールの 99 個を表にしたものです。全部で 4 つの章に分かれています。

- マクロの関数（1）: この章。ファイル、編集、カーソル移動、スクロール
- マクロの関数（2）: 選択、矩形選択、クリップボード、挿入、変換
- マクロの関数（3）: 検索、モード、設定、マクロ、ウィンドウ、サポート、カスタムメニュー、MATSU Editor だけの関数
- マクロの関数（4）: 値を返す関数

マクロの書き方、言語ごとの呼び方、キーマクロの記録は、「マクロの使い方」の章にあります。ここでは繰り返しません。

## 表の読み方

どの表も、次の列を持ちます。

| 列 | 内容 |
|---|---|
| マクロ名 | マクロが呼ぶ名前。同じ関数の別の名前は、同じ行に並べます |
| 引数 | 引数の型と意味。「数」は整数、「文字列」は文字列です |
| 戻り値 | この章の関数は、どれも値を返しません。値を返す関数は、「マクロの関数（4）」にあります |
| 動き | 1 行の説明 |
| キーマクロに記録 | キーマクロの記録中にこの関数を実行したとき、記録に残るかどうか |
| MATSU での違い | サクラエディタと違うところ、気を付けること |

メニューやキーから使うときの説明は、「コマンド: ファイル」「コマンド: 編集」などの章にあります。

## 共通の決まり

表の行ごとには書かない決まりです。

### 名前

- 名前は、大文字と小文字を区別します。`down` は `Down` の別名ではありません。
- 名前の前に `S_` を付けても、同じ関数になります（古いマクロが `S_Down` と書いていたため）。
- 同じ関数に名前が 2 つあるものは、表の同じ行に並べます。キーマクロが保存するときは、先に書いてある名前を使います（例: `PageUp` と `1PageUp`）。

### 引数

- 引数の数は、表の数より多くできません。多いと、引数の誤りのエラーになります。
- 後ろの引数は省けます。省いたときの動きは、行に書きました。省けない引数が足りないときも、引数の誤りのエラーになります。
- 型が違うと、引数の誤りのエラーになります。数の引数に文字列を渡したとき、またその逆のときです。
- 文字コードの引数は、サクラエディタの番号です。0 が Shift_JIS、1 が JIS、2 が EUC、3 が UTF-16（リトルエンディアン）、4 が UTF-8、5 が UTF-7、6 が UTF-16（ビッグエンディアン）、7 が CESU-8、8 が Latin1、99 が自動判定（保存では「いまの文字コードのまま」）です。Windows のコードページの番号（936 など）も、MATSU Editor が知っているものは使えます。それ以外の番号は、`FileOpen` では自動判定、`InsFile` では Shift_JIS になり、`FileSaveAs`・`FileSaveAsDialog`・`PutFile` ではエラーです。

### 待ち合わせ

ダイアログやパネルを開く関数と、別のウィンドウでファイルを読む関数は、それが終わるまでマクロを待たせます。次の行が動くのは、ダイアログが閉じたあと、ファイルを読み終えたあとです。閉じ方が OK でもキャンセルでも、待ちは終わります。サクラエディタは別のウィンドウでの読み込みを待ちませんが、MATSU Editor は待ちます（ユーザーが 2026-10-17 に決めたこと）。

### 失敗したとき

- 引数の誤りは、スクリプトでは「引数が不正」のエラーになります。
- 動かせない場面（ビューモードで編集するなど）は、「使えない」というエラーになります。
- ブザーを鳴らして何もしないものは、行に「ブザー」と書きました。ブザーはエラーになりません。
