# 開く

ファイルを選んで開きます。

- 機能名: `F_FILEOPEN`
- メニュー: 「ファイル」の「開く...」
- 既定のキー: `Ctrl+O`
- マクロ: `FileOpen(ファイル, 文字コード, ビューモード, 初期の位置)`（機能名は `F_FILEOPEN2`）

## 動き

1. 「開く」のダイアログが出ます。複数のファイルを選べます
2. 選んだファイルを開きます

開き方は次のとおりです。

- すでにどこかのウィンドウで開いているファイルは、開き直さず、そのウィンドウを前に出します
- 1 つ目のファイルは、このウィンドウが「名前がなく、変更もない」文書なら、このウィンドウに開きます
- それ以外のファイルは、新しいウィンドウ（タブを使っているときは新しいタブ）に開きます
- ファイルが読めなかったときは、理由を出します
- 文字コードは、指定がなければ自動で判定します

## マクロ

`FileOpen` は、ファイルを指定して開くマクロの関数です。

| 引数 | 意味 |
|---|---|
| 1 つ目 | 開くファイル。空にすると、ダイアログが出ます |
| 2 つ目 | 文字コードの番号。99 か省略で、自動判定 |
| 3 つ目 | 0 以外なら、ビューモードで開く |
| 4 つ目 | ダイアログが始まるフォルダー、またはファイル |

マクロは、ファイルを読み終えるまで待ちます。待つだけで、マクロが操作する文書は変わりません。ファイルが新しいウィンドウやタブに開いたときは、次の行からも、元の文書を操作します。このウィンドウに開いたときは、次の行から、開いたファイルの文書を操作します。

キーやメニューから呼ぶ `F_FILEOPEN` は、1 つ目（ファイル）と 2 つ目（文字コード）の引数を読みます。ツールバーの「開く」のボタンの矢印（`F_FILEOPEN_DROPDOWN`）は、ファイルの引数だけを読む、同じ動きです。

## サクラエディタとの違い

- 動きはサクラエディタと同じです
- 開くダイアログの下の欄（文字コードや「読み取り専用で開く」）は、OS ごとのダイアログの作りに依存します。サクラエディタのダイアログと同じにはなっていない可能性があります（`docs/sakura-gaps.md` の「ダイアログの下の欄」。確かめていません）
