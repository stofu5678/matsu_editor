# 印刷プレビュー

印刷したときのページの見た目を、画面で確かめます。

- 機能名: `F_PRINT_PREVIEW`
- メニュー: 「ファイル」の「印刷プレビュー」
- 既定のキー: `Ctrl+Shift+P`
- マクロ: `PrintPreview()`

## 動き

プレビューは、ウィンドウの中で、文書の代わりに出ます。上にボタンの並んだバーがあります。

| ボタン | 動き |
|---|---|
| 印刷... | OS の印刷ダイアログを出して、印刷します（[印刷](file-print.md)と同じ） |
| 前 / 次 | ページを移ります |
| 縮小 / 拡大 | 表示の大きさを変えます |
| プリンター | プリンターの設定のダイアログを出します（Windows のみ。下を見てください） |
| ページ設定... | [印刷ページ設定](file-print-pagesetup.md)のダイアログを出します |
| 戻る | プレビューを閉じて、文書に戻ります |

バーには、「3/10頁」のように、今のページと全体のページ数が出ます。使っている用紙も、「A4  縦」のように出ます。`Esc` でも閉じます。

プレビューは、開いた時点の文書の写しで作ります。開いている間に文書が変わっても、ページは変わりません。印刷ページ設定を変えると、ページを作り直します。

## プリンターのボタン（Windows）

「プリンター」ボタン（`R` キーでも押せます）は、Windows の印刷設定のダイアログを出します。ダイアログは、今の印刷ページ設定のプリンター（覚えていなければ、通常使うプリンター）で開き、用紙の大きさと向きも、設定のものになっています。OK を押すと、選んだプリンターと、ダイアログで決めた用紙の大きさ・向きが、今の印刷ページ設定に入ります（設定ファイルにも書きます）。開いているほかのウィンドウのプレビューも、その設定でページを作り直します。キャンセルしたときは、何も変わりません。

ダイアログが返した用紙が、サクラエディタの用紙の一覧にないもの（ユーザー定義の用紙など）や、プリンターのドライバーが値を返さなかった項目は、設定の今の値のままにします。

macOS と Linux には、このボタンがありません。プリンターは、印刷のときに OS の印刷パネル（macOS）や印刷ダイアログ（Linux）で選びます。

## サクラエディタとの違い

サクラエディタと同じく、このコマンドでプレビューを開いたり閉じたりできます（プレビューが開いているときに呼ぶと閉じます）。プレビューの中のキーは本文に届かないので、キーボードからは `Esc` と「戻る」ボタンで閉じます。マクロからこのコマンドを呼んでも、マクロはプレビューが閉じるのを待たずに先へ進みます。サクラエディタと同じです。
