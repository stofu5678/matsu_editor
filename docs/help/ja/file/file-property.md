# ファイルのプロパティ

今の文書とファイルの情報を、一覧で見せます。

- 機能名: `F_PROPERTY_FILE`
- メニュー: 「ファイル」の「ファイルのプロパティ」
- 既定のキー: `Alt+Enter`
- マクロ: `PropertyFile()`

## 動き

「ファイルのプロパティ」という見出しのメッセージの箱に、次の情報を出します。「OK」で閉じます。

| 項目 | 内容 |
|---|---|
| ファイル名 | ファイルのパス（名前のない文書では空） |
| 文字コード | 文字コードの名前。BOM があれば「BOM 付」 |
| 改行コード | 文書が書き出す改行コード（CRLF など） |
| 行数 | 文書の行数 |
| レイアウト行数 | 画面の行数（折り返しを含む）。大きいファイルを読んでいる途中は出ません |
| ビューモードの表示 | ビューモードで開いているときだけ、そう書く |
| 変更の有無 | 「変更されています。」か「変更されていません。」 |

ファイルがディスクにあるときは、「--ファイル情報--」の区切りの下に、次も出ます。

| 項目 | 内容 |
|---|---|
| ロックの状態 | このエディタがファイルにかけているロック（排他制御）の種類 |
| ファイル属性 | 読み取り専用なら「/読み取り専用」 |
| 作成日時、更新日時、アクセス日時 | `2026年10月16日 09:05:03` の形。OS が教えない日時は出ません |
| ファイルサイズ | バイト数 |

## サクラエディタとの違い

- 「改行コード」の行は、MATSU Editor で足しています。サクラエディタのダイアログには、文字コードの行までで、改行コードはありません
- サクラエディタにある「設定のタイプ」「コマンドの実行回数」「MS-DOS 名」の行は、出しません
- 読み取り専用以外のファイル属性（アーカイブ、隠しファイル、システム）は、Windows にしかないので、出しません
- ダイアログではなく、メッセージの箱に文を出します

- サクラのソース: `sakura_core/cmd/CViewCommander_File.cpp` の `Command_PROPERTY_FILE`、`sakura_core/dlg/CDlgProperty.cpp` の `SetData`
