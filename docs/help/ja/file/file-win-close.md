# 閉じる

この文書を閉じます。

- 機能名: `F_WINCLOSE`
- メニュー: 「ファイル」の「閉じる」
- 既定のキー: なし（`key_bindings.rs` の既定の割り当てにありません）
- マクロ: `WinClose()`

## 動き

1. 文書に変更があると、「保存しますか」と聞きます（[章の初めの説明](index.md)を見てください）
2. 閉じてよければ、閉じます。ほかのタブがあるときは、このタブだけを閉じます。最後の 1 つのときは、次のとおりです
   - タブを使っている（タブバーを出し、ウィンドウをグループにまとめている）ときで、共通設定「タブバー」の「最後のファイルを閉じたとき(無題)文書を残す」が入っている（既定は入）ときは、最後の 1 つを閉じても、ウィンドウは閉じず、名前のない文書が残ります。ただし、これはウィンドウが 1 つだけのときです。ウィンドウが 2 つ以上あるときは、どのウィンドウでも、最後の 1 つを閉じるとそのウィンドウが閉じます。タブを使っていないときも、ウィンドウが閉じます。
3. 共通設定「ファイル」の「終了のとき保存の確認をしない」が入っていて、これが最後のウィンドウの最後のタブ（閉じるとアプリケーションが終わる場合）のときは、直前の内容の控えがある文書について、「保存しますか」を聞きません。その文書は、次に起動したときに戻ります
4. 「キャンセル」を選ぶか、保存をやめたときは、何も閉じません

名前のない文書を残したいときは、[閉じて(無題)](file-close.md)を使います。

## サクラエディタとの違い

動きはサクラエディタと同じです。

## 根拠

- サクラのソース: `sakura_core/cmd/CViewCommander_Window.cpp` の `Command_WINCLOSE`、`sakura_core/doc/CEditDoc.cpp` の `OnFileClose`
- MATSU のコード: `crates/matsu-ui/src/ui_commands/file/win_close.rs`、`crates/matsu-ui/src/file_ops/close.rs` の `confirm_and_close_window`
- 既定のキー: `crates/matsu-commands/src/sakura/key_bindings.rs`（この機能のコード 31320 がない）
