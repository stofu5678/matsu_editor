# 印刷ページ設定

印刷のレイアウトを決めるダイアログを出します。

- 機能名: `F_PRINT_PAGESETUP`
- メニュー: 「ファイル」の「印刷ページ設定...」
- 既定のキー: `Ctrl+Alt+P`
- マクロ: `PrintPageSetup()`

プレビューの「ページ設定...」のボタンからも開きます。プレビューを開かなくても使えます。

## 動き

印刷の設定は 8 組あり、ダイアログの「ページ設定」の欄で、どの組を編集するか選びます。組の名前は「設定名変更」で変えられます。

「OK」を押すと、次のことが起きます。

- 8 組の設定を保存します
- 今のタイプ（文書の種類）が使う組を、選んだものにします
- 開いているプレビューは、新しい設定でページを作り直します

### 設定の項目

| 項目 | 意味 |
|---|---|
| 半角フォント、全角フォント | 印刷に使うフォント |
| フォント高 | 文字の高さ（1/10mm） |
| 行送り | 行の間隔（%） |
| 段数、段の隙間 | 1 ページを何段に分けるか、段のあいだの幅（mm） |
| 用紙サイズ、用紙の向き | 用紙の大きさ、縦か横か |
| 余白（上・下・左・右） | 余白の幅（mm） |
| 行番号を印刷 | 行番号を印刷する |
| 英文ワードラップ | 英単語の途中で折り返さない |
| 行頭禁則、行末禁則、改行ぶら下げ、句読点ぶら下げ | 禁則の扱い |
| カラー印刷 | 色分けを印刷する |

ダイアログには、「行あたりの文字数」と「縦方向の行数」も出ます。設定から計算した値です。

プレビューを開かずにこのダイアログを使うと、行番号の幅は、最小の桁数で計算します。

## サクラエディタとの違い

- 数値欄のスピンボタンと、ラベルのアクセスキーはありません。数字は文字で入力します（`docs/sakura-gaps.md`）
- ダイアログのヘルプボタンは、まだありません
