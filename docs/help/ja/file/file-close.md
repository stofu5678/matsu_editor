# 閉じて(無題)

今のファイルを閉じて、同じウィンドウに、名前のない新しい文書を残します。

- 機能名: `F_FILECLOSE`
- メニュー: 「ファイル」の「閉じて(無題)」
- 既定のキー: なし
- マクロ: `FileClose()`

## 動き

1. 文書に変更があると、「保存しますか」と聞きます（[章の初めの説明](index.md)を見てください）。「キャンセル」を選ぶと、文書は開いたままです。ただし、テキストは変えずに、文字コードか BOM だけを変えていたときは、その変更は取り消されます（聞かれる文も、文字コードの変更についてのものになります）
2. 今の文書を閉じて、同じウィンドウに名前のない文書を作ります。ウィンドウは閉じません
3. 共通設定の「オープン後に実行するマクロ」は、この名前のない文書に対して動きます

[閉じる](file-win-close.md)とのちがいは、ウィンドウやタブを残すことです。

## サクラエディタとの違い

動きはサクラエディタと同じです。

## 根拠

- サクラのソース: `sakura_core/doc/CDocFileOperation.cpp` の `FileClose`
- MATSU のコード: `crates/matsu-ui/src/ui_commands/file/file_close.rs`、`crates/matsu-ui/src/file_ops/close.rs` の `close_file`
