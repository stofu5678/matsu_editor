# 共通設定: キー割り当て

キーと機能の対応を決めます。キーは `[KeyBind]` セクションにあります。

## 画面の部品

- 「種別」と、その種別の機能の一覧。「種別」は、メインメニューのページと同じ分類です
- 「キー」の一覧と、`Shift`、`Ctrl`、`Alt` のチェック
- 選んだ機能に割り当ててあるキーの一覧と、選んだキーに割り当ててある機能の表示

| ボタン | 動き |
|---|---|
| 割当 | 選んだキー（と修飾キー）に、選んだ機能を割り当てます |
| 解除 | 選んだキーの割り当てを外します |
| インポート、エクスポート | 割り当てを `.key` ファイルから読み込み、書き出します |

- 読み込みは、ページの表に、ファイルの行を重ねます（ファイルにあるキーはファイルの機能になり、ほかのキーは残ります）。OK を押すまで、設定ファイルには書きません
- OK を押すと、ロックの下で書かれ、すべてのウィンドウのキーの対応と、メニューに出るショートカットが、すぐに変わります

## サクラエディタとの違い

- macOS でも、ページが編集するのはサクラエディタと同じ表です。MATSU Editor の macOS 用の規則は、キーの対応を作るときに、利用者の行の上に重ねられます
- 古い形式（バージョン 2）の `.key` ファイルと、バージョン 3 のマウスの行は、読めません。断られます
- 機能の一覧とキーの一覧のアクセスキー（`(&F)` など）は、ありません
- 種別「プラグイン」には、有効なプラグインのコマンドが並びます

## 根拠

- サクラのソース: `sakura_core/prop/CPropComKeybind.cpp`、`sakura_core/typeprop/CImpExpManager.cpp`（`CImpExpKeybind`）、`CShareData_IO::ShareData_IO_KeyBind`
- MATSU のコード: `crates/matsu-ui/src/common_settings/pages/keys.rs` と `keys/` の下のファイル
