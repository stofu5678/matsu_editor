# 共通設定: カスタムメニュー

25 個のメニューの中身を決めます。キーは `[CustMenu]` セクションにあります。名前は `szCMN[00]` などです。

25 個は、右クリックメニュー、メニュー 1〜23、タブのメニュー（24）です。

## 画面の部品

- 「選択」の一覧で、編集するメニューを選びます。「選択」のボタンは、次のメニューへ進みます
- 「メニュー名」の欄と「設定」のボタンで、メニューの名前を決めます
- 「サブメニューとして表示」で、そのメニューを、サブメニューとして出すかを決めます
- 「種別」と機能の一覧から機能を選び、右のメニューの項目の一覧に入れます。種別は、メインメニューのページと同じ分類です。「外部マクロ」の種別には、登録マクロの名前が並びます
- 項目の「アクセスキー」は、欄に入れて、「設定」のボタンで付けます

| ボタン | 動き |
|---|---|
| 削除 | 選んだ項目を消します |
| --- | 区切り線を入れます |
| →、>> | 選んだ位置、末尾に、機能を入れます |
| ↑、↓ | 項目を上、下へ動かします |
| インポート、エクスポート | メニューを `.mnu` ファイルから読み込み、書き出します |

OK を押すと、ロックの下で書かれ、すべてのウィンドウで、ポップアップ、タブのメニュー、`F_CUSTMENU_n`、メインメニューの一覧が、すぐに変わります。

## サクラエディタとの違い

- ウィンドウを開いたときと、メニューを選んだとき、項目が何も選ばれていません（サクラエディタは先頭の項目を選びます）
- アクセスキーは、欄とボタンで付けます（サクラエディタは、項目をダブルクリックして、小さなダイアログで聞きます）
- `.mnu` ファイルのダイアログに、種類の絞り込みがありません
- 種別「プラグイン」には、コマンドが出ません
