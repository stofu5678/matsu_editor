# フォント設定...

本文のフォントを選びます。選んだフォントは、すべてのウィンドウの共通のフォントになります。

- 機能名: `F_FONT`
- メニュー: 「設定」→「フォント設定...」
- 既定のキー: `Ctrl+7`
- マクロ: `SelectFont()`（引数なし。キーマクロには記録されません）

## 動き

1. フォントの選択ダイアログが出ます。等幅でないフォント（プロポーショナルフォント）も選べます
2. 選ぶと、フォントの名前と大きさが `matsu.ini` の `[Font]` セクションにすぐ書かれ、すべてのウィンドウが新しいフォントで描き直します
3. 「キャンセル」なら、何も変わりません

- ダイアログは、Windows では OS 標準のフォントの選択（`ChooseFont`）を使います。macOS と Linux では、MATSU Editor の窓（フォントの系統、スタイル、大きさ、見本）を使います
- タイプ別設定で、そのタイプ専用のフォントを選んでいるウィンドウは、そのフォントのままです

## 等幅でないフォント

「等幅」は、`0`・`i`・`W` などの字の幅が同じ書体です。MATSU Editor は、選んだ書体が等幅かどうかを調べて、描き方を替えます。

- 等幅の書体: 半角を 1 桁、全角を 2 桁の格子に置きます。見た目は今までと同じです
- 等幅でない書体: 1 文字ずつ、その書体の幅で並べます（`m` は広く、`i` は狭く置きます）。折り返し、タブ、検索の強調、括弧の強調、矩形選択、クリックした位置、横スクロール、IME の位置、ミニマップ、画面を読み上げるソフトへ伝える位置も、その幅に従います。タブは、タブ幅の桁ごとの位置（桁 × 1 桁の幅）まで進みます
- 1 桁の幅は、半角の `0` の幅です。折り返しの桁数やタブ幅、ルーラーの目盛り、縦線は、桁で数えます。「ウィンドウの幅で折り返す」は、等幅でない書体でも桁で数えるので（サクラエディタも同じです）、狭い字が続く行は、右端の手前で折り返すことがあります
- 合字（`fi` など）と字詰め（カーニング）は効きません。1 文字ずつ置くためです（サクラエディタも同じです）
- 色付き HTML のコピーは、タブをそのまま書き、書体を指定しません（サクラエディタも同じです）。HTML を開いたときの字の幅とタブの長さは、開いたブラウザの書体で決まります
- シェルのタブは、エディタの書体が等幅でないときも、等幅の書体で描きます（端末の格子を保つため）
- 印刷は、まだ桁の格子で並べます。等幅でない書体で印刷しても、画面とは文字の位置が違います

## サクラエディタとの違い

- サクラエディタは、ウィンドウが全部閉じるときにファイルへ書きます。MATSU Editor は、選んだときすぐに書きます（ほかのウィンドウが書いた内容を消さないよう、ファイルをロックして書きます）
- `matsu.ini` の `[Font]` の `bFontIs_FIXED_PITCH` には、どのフォントを選んでもいつも 1（等幅）を書きます（以前の動きのままです）。描き方は、この値でなく、書体を調べて決めます（上の「等幅でないフォント」）

## 関連

- 大きさだけを変えるには、`F_SETFONTSIZE` などの機能（Ctrl とホイール）があります
- タブバーのフォントは、[タブバー](page-tab.md) ページで選びます
