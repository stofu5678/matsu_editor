# 共通設定: メインメニュー

メニューバーの組み立てを、木の形で編集します。キーは `[MainMenu]` セクションにあります。

## 画面の部品

- 左の「メニュー」の木が、いまのメニューです。右の「種別」から機能の種類を選び、その機能の一覧から選びます
- 種別は、「ファイル操作系」から「その他」までの 15 の分類、「外部マクロ」、「カスタムメニュー」、「プラグイン」、「特別機能」、MATSU Editor だけの「ワンライナー」です

| ボタン | 動き |
|---|---|
| 上⇒、下⇒、>> | 選んだ機能を、木の選んだ行の上、下、いちばん後ろに入れます |
| ＋ | ノード（サブメニュー）を足します |
| --- | 区切り線を足します |
| 削除 | 選んだ行を消します |
| ↑、↓ | 行を上、下へ動かします |
| →、← | 階層を下げる、上げる |
| 全開、全閉 | 木のノードをすべて開く、閉じる |
| アクセスキーを必ず( )付で表示 | 切り替えます。メインメニューにだけ効きます |
| 検査 | メニューの問題を調べます |
| クリア | メニューを空にします（確認があります） |
| 初期設定 | サクラエディタの既定のメニューに戻します（確認があります） |
| インポート、エクスポート | メニューをファイル（`.ini`）から読み込み、書き出します |

- 「ノード名」と「アクセスキー」は、欄に入れて、「設定」のボタンで、選んだ行に付けます
- 読み込みは、ページの木を置き換えるだけです。OK を押すまで、設定ファイルには書きません

## OK を押すと

- メニューが `matsu.ini` に書かれ、すべてのウィンドウのメニューバー（macOS ではシステムのメニュー）が、すぐに作り直されます
- 木がファイルのメニューと同じなら、何も書きません
- 機能を読めない行（存在しないマクロの名前など）は、機能 0 として読まれ、OK で空のノードになります
- メニューバーの階層 0 に機能や区切りがあっても、ファイルには残りますが、MATSU Editor のメニューバーはメニューだけなので、出ません

## サクラエディタとの違い

- ウィンドウを開いたとき、選ばれている行がありません
- アクセスキーとノード名は、サクラエディタでは、キー入力・ダブルクリック・F2 で直しますが、ここでは欄とボタンです
- ファイルのダイアログに、種類の絞り込みがありません
- 種別「プラグイン」には、有効なプラグインのコマンドが並びます
- カスタムメニューなど、メインメニュー以外のメニューのアクセスキーは、「アクセスキーを必ず( )付で表示」に従いません
