# 共通設定: ワンライナー

登録ワンライナーの一覧です（MATSU Editor だけの機能。ADR-0029）。サクラエディタにはないページで、「シェル」ページの後ろにあります。ワンライナーの使い方は、「MATSU Editor だけの機能」の章にあります。

このページは、「設定」メニューの「ワンライナーの設定...」（`F_ONELINER_SETTINGS`）でも開きます。

キーは `[OneLiner]` セクションにあります。「マクロ」ページと同じ作りで、50 個の枠の一覧と、その下に、Id で選んだ枠の欄があります。欄を直して「設定」を押すと、一覧に入ります。

## 欄

| 欄 | 動き |
|---|---|
| 名前 | ワンライナーの名前 |
| Id | 枠の番号（0〜49） |
| コマンド | 実行するコマンドを 1 行で書きます。選んだ文字列（選んでいないときは文書全体）が標準入力に渡され、出力が結果の置き場所に入ります |
| 結果の置き場所 | 「置き換える」「次の行に入れる」「アウトプットに出す」から選びます |
| 生成 AI に送る | オンのとき、実行の前に確認の窓を出し、送った内容と答えを、読み取り専用のログのタブに残します |
| 送る前に確認する | 生成 AI に送るがオンのときだけ使えます。既定はオン |
| ひな形 | 「Claude Code」「Codex CLI」「Ollama」から選びます |
| ひな形を入れる | コマンドに、ひな形の例を入れ、結果の置き場所を「次の行に入れる」に、生成 AI に送るをオンにします |

## 入れられない値

ファイルに書けない値は、「設定」で断られ、理由が出ます。入力している間は、欄の下に赤い注意が出ます。何も切り詰めません。

- 改行を含む値
- 64 UTF-16 単位以上の名前
- 1024 単位以上のコマンド
- コマンドのない名前（ファイルが、コマンドのない枠を捨てるため）

## OK を押すと

`[OneLiner]` が、ロックの下で書かれます。入力ダイアログの履歴（`Recent`）と、MATSU Editor が知らないキーは、ファイルのとおりに残ります。キャンセルは何も書きません。書いたものは、ウィンドウが使うときに読まれるので、すぐに効きます。
