# 履歴の管理...

「最近使ったファイル」と「最近使ったフォルダー」の履歴を、一覧で見て、お気に入りにしたり、消したりします。検索・置換・Grep・外部コマンド・カレントディレクトリの履歴も、一覧で見て、消したり、直したりできます。

- 機能名: `F_FAVORITE`
- メニュー: 「設定」→「履歴の管理...」
- 既定のキー: なし
- マクロ: `OptionFavorite()`（引数なし。キーマクロには記録されません）

## 動き

編集ウィンドウとは別の窓が開きます。タブが 9 つあります。サクラエディタと同じ順で、「ファイル」「フォルダー」「ファイル・フォルダー除外」「検索」「置換」「GREPファイル」「GREPフォルダー」「コマンド」「カレントディレクトリ」です。`Tab` キーで次のタブに移ります（最後のタブの次は最初に戻ります）。タブが 1 行に入らないときは、折り返して並びます。

- 一覧の項目ごとに、「お気に入り」のチェックがあります
- メニューに出る数をこえた項目には、「(非表示)」と付きます
- 次のボタンで、項目を消します。「すべて」、「お気に入り以外」、「存在しない項目」、「選択項目」です
- 「ファイル」と「フォルダー」のタブで項目を選んで「除外リストに追加(X)」を押すと、その文字列が「ファイル・フォルダー除外」の一覧の先頭に入ります。一覧に入れた文字列を含むパスは、履歴に入りません（すでに履歴にあるものは、そのままです）。一覧は 36 件までで、いっぱいのときは「除外リストがいっぱいで追加できませんでした。」と出ます
- 「ファイル・フォルダー除外」のタブでは、お気に入りのチェックはなく、「すべて」と「選択項目」で消せます
- タブごとにできることは、次のとおりです

  | タブ | お気に入り | 存在しない項目 | 除外リストに追加 | 追加・編集 |
  |---|---|---|---|---|
  | ファイル、フォルダー | あり | 使える | 使える | できない |
  | ファイル・フォルダー除外 | なし | 使えない | 使えない | できる |
  | 検索、置換、GREPファイル、コマンド | なし | 使えない | 使えない | できる |
  | GREPフォルダー、カレントディレクトリ | なし | 使える | 使えない | できない |

- 「追加(I)」を押すと、文字列を入れる窓が重なって開きます。入れた文字列は、一覧の先頭に入ります。すでに一覧にある文字列と、長すぎる文字列（255 文字ほど。コマンドは 1000 文字ほど）は入りません。入れても何も起きないときは、これのどちらかです。同じ文字列かどうかは、「検索」「置換」「コマンド」「カレントディレクトリ」では大文字と小文字を区別し、「GREPファイル」「GREPフォルダー」「ファイル・フォルダー除外」では区別しません（サクラエディタと同じです）
- 項目をダブルクリックするか、項目を選んで `F2` を押すと、その項目の文字列を直す窓が開きます。直した文字列は、同じ場所に入ります。ほかの項目と同じになる直し方はできません
- 文字列を入れる窓は、`Enter` か「OK」で決まり、`Esc` か「キャンセル」でやめます
- 「置換」のタブだけは、空の文字列も入れられます（文字を消す置換のため）。ほかのタブでは、空の文字列は入れられません
- 「GREPフォルダー」のタブの「存在しない項目」は、`;` で区切った複数のフォルダーの項目を、その中の 1 つでもあれば残します
- 変更は、押したときすぐに履歴へ書かれます
- 窓の位置と大きさは、閉じるときに覚え、次に開くときに使います

メニューなどに出す履歴の数は、「共通設定」の [全般](page-general.md) ページで決めます。数を下げても、履歴は消えません（履歴は 36 件まで覚えています）。

ボタンの名前の後ろにある `(A)` のような文字は、`Alt` と組み合わせるアクセスキーです。「追加(I)」「すべて(A)」「お気に入り以外(F)」「存在しない項目(N)」「選択項目(D)」「閉じる(C)」が、`Alt` と文字で押せます。文字は、サクラエディタの「履歴とお気に入りの管理」と同じです。

## サクラエディタとの違い

- サクラエディタには、項目を右クリックしたときのメニュー（編集、新規追加、除外リストに追加、各削除）があります。MATSU Editor にはありません。同じことは、ボタンと、ダブルクリックと `F2` でできます
- サクラエディタは、窓の下の行に、別の窓が履歴を変えたときの知らせ（「履歴(…)が更新されたため編集中情報を破棄し再表示しました。」）を出します。MATSU Editor は、変更をそのつど反映するので、この知らせはなく、一覧だけが新しくなります
- サクラエディタの列の見出しをクリックすると、並べ替えができます。MATSU Editor では、まだできません
- `Ctrl` と `PageDown`・`PageUp` でタブを移る代わりに、`Tab` キーで移ります
- 「除外リストに追加」は、長いパスもそのまま入れます（サクラエディタは、260 文字以上のパスを何も言わずに断ります）。「追加(I)」と編集で打った文字列には、255 文字ほどの上限があります
- 空の文字列は、「置換」のタブのほかでは入れられません（サクラエディタは、どのタブにも入れられます。MATSU Editor は、検索などの一覧に空の行を置かないため）
- 「検索」などの履歴を消しても、別のプロセスが同じ設定ファイルに書くときに、そのプロセスが覚えていた文字列が戻ることがあります（サクラエディタは、共有メモリで 1 つの履歴を使うので、この問題はありません）
- サクラエディタは、チェックの変更を、窓を閉じるときか削除の前にまとめて反映します。MATSU Editor は、そのつど反映します。結果は同じです

- サクラのソース: `sakura_core/dlg/CDlgFavorite.cpp`、`sakura_core/_main/CControlTray.cpp` の `F_FAVORITE` の処理
- サクラのソース: `sakura_core/recent/CRecentImp.cpp`（`AppendItemText`、`EditItemText`、`DeleteItem`）、`sakura_core/recent/CRecentExceptMru.cpp`（大文字と小文字を区別しない比較）
- MATSU のコード: `crates/matsu-ui/src/ui_commands/history/favorite.rs`、`crates/matsu-ui/src/history/dialog.rs`、`crates/matsu-ui/src/history/texts.rs`（検索などの 6 つのタブ）、`crates/matsu-config/src/settings/edit_list.rs`
- マクロ名: `crates/matsu-commands/src/sakura/macro_functions.rs`（`OptionFavorite`）
