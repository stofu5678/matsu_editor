# 共通設定: バックアップ

保存するときに、元のファイルをコピーして残す設定です。キーは `[Common]` セクションです。

バックアップは、ファイルを書く前に、いまあるファイルをコピーして作ります。

## 基本

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| 保存時にバックアップを作成する | `bBackUp` | オフ | オンのときだけ、このページのほかの項目が使えます |
| 作成前に確認する | `bBackUpDialog` | オン | バックアップを作る前に聞きます |
| バックアップファイルをごみ箱に放り込む | `bBackUpDustBox` | オフ | 作ったバックアップを、ごみ箱へ移します。ローカルでないドライブには移しません |
| 指定フォルダーに作成する | `bBackUpFolder` | オフ | バックアップを、決めたフォルダーに作ります |
| リムーバブルメディアのみ | `bBackUpFolderRM` | オフ | 指定フォルダーを使うのを、ローカルでないドライブ（リムーバブルメディアなど）のファイルだけにします。ほかのファイルは、元のファイルの場所にバックアップします |
| フォルダー名 | `szBackUpFolder` | 空 | 上のフォルダー。「指定フォルダーに作成する」がオンのときだけ使えます |

## バックアップのファイルの名前

「詳細設定する」がオフのときは、次の 4 つから選びます。

| 選択 | `nBackUpType` | できる名前 |
|---|---|---|
| 拡張子を .bakに変更したもの（1世代） | 1 | `file.bak` |
| 拡張子を連番に変更したもの | 3 | `file.b00` から `file.b98` |
| ファイル名の後ろに保存時の日付・時刻を付加したもの | 2 | 日付と時刻が付きます |
| ファイル名の後ろに前回の保存時の日付・時刻を付加したもの | 4 | 前の保存の日付と時刻が付きます |

- 「元の拡張子を保存」は、1 番目と 2 番目のときだけ使えます。元の拡張子を、名前に残します。このチェックに専用のキーはなく、サクラエディタの `nBackUpType` の 5 と 6 にあたります
- 「保存する世代数」（1〜99、既定 10）は、連番のときだけ使えます。キーは `bBackUpType2_Opt2` の下位 16 ビットです
- 日付の名前のときは、「西暦」「月」「日」「時」「分」「秒」のうち、名前に入れるものを選びます。キーは `bBackUpType2_Opt1` のビットです

## 詳細設定

| 項目 | キー | 動き |
|---|---|---|
| 詳細設定する | `bBackUpPathAdvanced` | オンにすると、上の 4 つの代わりに、書式でバックアップの名前を決めます |
| 詳細設定の書式 | `szBackUpPathAdvanced` | 書式の文字列 |
| 保存時の日付・時刻を使用、前回のファイル更新時の日付・時刻を使用 | `bBackUpType2_Opt4` | `%Y` などに使う日付・時刻を選びます |

書式では、次の記号が使えます。

| 記号 | 意味 |
|---|---|
| `$x` | x 個上のフォルダー名（x は 0〜9） |
| `*` | 拡張子 |
| `%Y` `%m` `%d` | 年、月、日 |
| `%y` | 西暦の下 2 桁 |
| `%H` `%M` `%S` | 時、分、秒 |
| `%%` | `%` の文字 |

## サクラエディタとの違い

- ファイル名の最後の `.` で拡張子を切ります。ただし、`.` が名前の先頭のとき（`.bashrc`）は、拡張子がないものとして扱います
- 詳細設定の書式にある `*` と `?` は、書式が作った部分だけ置き換えます。その前のフォルダーの部分は置き換えません
- macOS と Linux では、設定のバックスラッシュ `\` を `/` として扱います
- 「詳細設定」の書式の欄は、ほかの部品を変えても、すぐには追いかけません。ダイアログを開くときと OK のときに作られます
