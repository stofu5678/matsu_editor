# 共通設定: ツールバー

ツールバーに並べるボタンを選びます。キーは `[Toolbar]` セクションにあります（`nToolBarButtonNum`、`nTBB[000]` など）。ただし「フラットなボタン」は `[Common]` セクションです。

## 画面の部品

- 「種別」で機能の種類を選び、その機能の一覧（アイコン付き）から、ボタンにするものを選びます。種別は、「メインメニュー」ページと同じ分類です（「ワンライナー」を含む）
- 「外部マクロ」の種別には、登録した 50 個のマクロが名前付きで並びます
- 右の一覧が、いまのツールバーのボタンです。ボタンは最大 512 個です

| ボタン | 動き |
|---|---|
| 削除 | 選んだボタンを消します |
| --- | 区切りを足します |
| → | 選んだ位置に、機能を入れます |
| >> | 末尾に、機能を足します |
| ↑、↓ | ボタンを上、下へ動かします |
| 折返 | ツールバーを折り返す位置を入れます |

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| フラットなボタン | `bToolBarIsFlat` | オン | 枠がなく、ポインターが乗ったときだけ枠が出るボタン。オフのときは、いつも枠のあるボタンです |

OK を押すと、ファイルのロックの下で書かれ、すべてのウィンドウのツールバーがすぐに変わります。

## サクラエディタとの違い

- 種別「プラグイン」には、有効なプラグインのコマンドが並び、ボタンにできます
