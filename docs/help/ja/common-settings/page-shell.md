# 共通設定: シェル

シェルのタブ（MATSU Editor だけの機能）の設定です。サクラエディタにはないページで、ほかのページの後ろにあります。シェルのタブの使い方は、「MATSU Editor だけの機能」の章の「シェル」にあります。

キーは `[Terminal]` セクションにあります（`[Common]` ではありません）。

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| コマンドライン | `Shell` | 空 | シェルとして動かすプログラムと引数を、打つとおりに 1 行で書きます |
| 保持する行数 | `ScrollbackLines` | 5000（0〜50000） | 戻って見られる行数 |
| Option を Meta として使う（macOS だけ） | `OptionAsMeta` | オフ | オンのとき、`Option` とキーで、ESC とそのキーを送ります。オフのときは、`Option` で入る文字を入力します |

- コマンドラインが空のときは、その環境の既定のシェルです（Windows は PowerShell、macOS と Linux はログインシェル）
- macOS と Linux では、`~` や `$HOME` は展開されません
- 読めないコマンドライン（閉じていない引用符など）は、箱の下にそう出ます。そのときは、既定のシェルで始まります
- 保持する行数は、1 タブで 1 万行あたり約 29 MB のメモリを使います。範囲の外の数は、OK で範囲に入れられます
- コマンドラインと行数は、あとから開くシェルのタブから使われます。開いているタブは、そのままです。「Option を Meta として使う」は、開いているタブにもすぐ届きます
