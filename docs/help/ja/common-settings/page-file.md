# 共通設定: ファイル

ファイルの排他制御と更新の監視、保存、ファイルを開くときの動きを決めます。キーは、書いていないものは `[Common]` セクションです。

## ファイルの排他制御

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| 排他制御 | `nFileShareMode` | しない | 「しない」「上書きを禁止する」「読み書きを禁止する」から選びます。開いているファイルを、ほかのプログラムが書いたり読んだりできないようにします |
| 更新の監視 | `bCheckFileTimeStamp` | オン | ほかのプログラムがファイルを変えたとき、知らせて聞きます。排他制御が「しない」のときだけ選べます |
| 自動読込時遅延 | `nAutoloadDelay` | 0 | 自動で読み直すまでに待つ、確認の回数。更新の監視がオンのときだけ使えます |
| 上書き禁止検出時は編集禁止にする | `bUneditableIfUnwritable` | オン | 書き込めないファイルは、編集できない状態で開きます |

排他制御が「しない」でないときは、更新の監視をしません。

## ファイルの保存

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| 無変更でも上書きする | `bEnableUnmodifiedOverwrite` | オフ | 文書が変わっていなくても、保存すると書き込みます |
| 自動的に保存する | `bBackUpType2_Opt1` の 1 ビット | オフ | 決めた間隔で、自動で保存します |
| 間隔は | `bBackUpType2_Opt3` | 5 分（1〜35791） | 自動保存の間隔。自動的に保存するがオンのときだけ使えます |

自動保存は、「MATSU Editor だけの機能」の章の「自動保存」にも書いています。

## 保存していない文書を残す（MATSU Editor だけ）

キーは `[MATSU]` セクションです。

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| 保存していない文書を残し、次の起動で戻す | `KeepUnsaved` | オン | 終了するときに保存していない文書を控えにして、次の起動で戻します |
| 終了のとき保存の確認をしない | `KeepUnsavedNoAsk` | オフ | 上の項目がオンのときだけ使えます |

## 「名前を付けて保存」のファイル一覧

「ファイルの種類」が「ユーザー指定」のときの、一覧の出し方です。

| 項目 | キー | 既定 |
|---|---|---|
| 新規から保存時は全ファイル表示 | `bNoFilterSaveNew` | オン |
| 新規以外から保存時は全ファイル表示 | `bNoFilterSaveFile` | オン |

オンにすると、タイプの拡張子の後ろに、全ファイルの表示（`;*.*`）が足されます。

## ファイルオープン

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| ファイルのドロップは「閉じて開く」にする | `bDropFileAndClose` | オフ | ファイルを落とすと、いまの文書を閉じてから開きます。ファイルは 1 つだけ有効です |
| ファイルのドロップは一度にMAX | `nDropFileNumMax` | 8（1〜99） | 一度に開くファイルの数の上限。上の項目がオフのときだけ使えます |
| ファイルを開いたときにカーソル位置を復元する | `m_bRestoreCurPosition` | オン | 前に閉じたときのカーソルの位置に戻します |
| ファイルを開いたときにブックマークを復元する | `m_bRestoreBookmarks` | オン | 前のブックマークを戻します |
| ファイルを開いたときにMIMEエンコードされたヘッダーをデコードする | `bAutoMIMEdecode` | オフ | ISO-2022-JP のファイルのヘッダーの MIME 符号を読み解きます |
| 前回と異なる文字コードのとき問い合わせを行う | `bQueryIfCodeChange` | オン | 前に開いたときと文字コードが違うと、聞きます |
| 開こうとしたファイルが存在しないとき警告する | `bAlertIfFileNotExist` | オフ | 存在しないファイルを開こうとすると、知らせます |
| 開こうとしたファイルが大きい場合に警告する | `bAlertIfLargeFile` | オフ | 下の大きさ以上のファイルを開く前に、聞きます |
| 警告するファイルの大きさ（MB） | `nAlertFileSize` | 10（1〜2048） | 上の項目がオンのときだけ使えます |
| 範囲ごとに読むファイルの大きさ（MB） | `nHugeFileSizeMB` | 256（1〜1000000） | この大きさ以上のファイルは、範囲ごとに読んで開きます（MATSU Editor だけ。「巨大なファイル」の章） |
