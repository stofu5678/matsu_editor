# 共通設定: 生成 AI

生成 AI に送る送り先の一覧です（MATSU Editor だけの機能。ADR-0035）。サクラエディタにはないページで、「ワンライナー」ページの後ろ（いちばん後ろ）にあります。送り方の説明は、「MATSU Editor だけの機能」の章の[生成 AI に送る](../matsu-only/ai-send.md)にあります。

キーは `[AI]` セクションにあります。「ワンライナー」ページと同じ作りで、50 個の枠の一覧と、その下に、Id で選んだ枠の欄があります。欄を直して「設定」を押すと、一覧に入ります。

## このページの考え方

- モード a は、選んだ文字列（選んでいないときは文書全体）を、そのままプロンプトとして送ります。モード b は、入れた指示をつけて送ります。
- 送り先に書くコマンドは、標準入力からプロンプトを読めるものにします。選んだ文字列は標準入力で渡り、コマンドラインにも環境変数にも入りません。
- どの送り先も、両方のモードで使えます。

## 欄

| 欄 | 動き |
|---|---|
| 名前 | 送り先の名前。メニュー、確認の窓、ログに出ます |
| Id | 枠の番号（0〜49） |
| コマンド | 実行するコマンドを 1 行で書きます。シェルは「シェル」ページのものです |
| 結果の置き場所 | 「置き換える」「次の行に入れる」「ログのタブだけ」から選びます。既定は「次の行に入れる」。「ログのタブだけ」は、文書を変えず、答えを読み取り専用のログのタブにだけ出します |
| 送る前に確認する | オンのとき、送る前に確認の窓を出します。既定はオン。確認の窓の「次から聞かない」でも切り替わります |
| ひな形 | 「Claude Code」「Codex CLI」から選びます |
| ひな形を入れる | コマンドに、ひな形の例を入れ、結果の置き場所を「次の行に入れる」にします。名前が空のときだけ、名前をひな形の名前にします。「送る前に確認する」は変えません |

## ひな形

指示の引数を持たない、標準入力のプロンプトを読む形です。

| ひな形 | 入るコマンド |
|---|---|
| Claude Code | `claude -p --no-session-persistence --tools "" --permission-mode dontAsk` |
| Codex CLI | `codex exec --sandbox read-only --ephemeral --skip-git-repo-check -` |

- どちらも、ツールを使わせず（Claude Code は `--tools ""`、Codex CLI は読み取り専用の枠）、会話の記録を残さない（`--no-session-persistence`、`--ephemeral`）ためのフラグを付けています。
- ひな形の内容は、AI ツールの版で変わることがあります。ツールを入れるのも、認証も、利用者の側でします。
- Ollama のひな形は、ありません。`ollama run` が、標準入力のプロンプトで文章を作れるかが、文書で確かめられなかったためです。使いたいときは、自分でコマンドを書いてください。

## 入れられない値

「ワンライナー」ページと同じです。ファイルに書けない値は、「設定」で断られ、理由が出ます。入力している間は、欄の下に赤い注意が出ます。何も切り詰めません。

- 改行を含む値
- 64 UTF-16 単位以上の名前
- 1024 単位以上のコマンド
- コマンドのない名前

## OK を押すと

`[AI]` が、ロックの下で書かれます。MATSU Editor が知らないキーは、ファイルのとおりに残ります。キャンセルは何も書きません。書いたものは、ウィンドウが使うときに読まれるので、すぐに効きます。
