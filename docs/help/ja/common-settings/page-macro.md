# 共通設定: マクロ

マクロを 50 個まで登録し、自動で動かすマクロを決めます。マクロの書き方と動かし方は「マクロの使い方」の章にあります。

登録したマクロは、キーやメニューやツールバーから `F_USERMACRO_0 + n` として呼べます。

## マクロフォルダーなど

| 項目 | キー | 既定 | 動き |
|---|---|---|---|
| マクロフォルダー | `szMACROFOLDER`（`[Folders]`） | 空 | 登録するマクロのファイルを置く場所。右の `...` で選びます |
| Pythonフォルダー | `nMacroPythonDirectory`（`[Macro]`） | 空 | 未対応。マクロの実行環境が、Python を自分で探します（ADR-0007） |
| キャンセル確認待ち時間 | `nMacroCancelTimer`（`[Macro]`） | 10 秒（0〜9999） | マクロが動き続けているとき、この時間のあと、中止するかを聞きます |

## 登録マクロ

一覧の 1 行が 1 つのマクロです（Id 0〜49）。行を選ぶと、下の欄に値が出ます。欄を直して「設定」のボタンを押すと、一覧に入ります。

| 欄 | 動き |
|---|---|
| 名前 | マクロの名前 |
| Id | 行の番号（0〜49） |
| File | マクロのファイル |
| マクロを実行するたびにファイルを読みなおす | オンなら、実行のたびに読み直します |

「File」は、マクロフォルダーのファイルの一覧から選ぶ形ではなく、書く欄です。

## 自動実行

行ごとの欄です。名前や File といっしょに「設定」で一覧に入れます。チェックを付けた行のマクロが、自動で動きます。

| 項目 | 動き |
|---|---|
| 新規／開ファイル後 | 新しい文書や、ファイルを開いたあとに、そのマクロを自動で動かします |
| タイプ変更後 | 文書のタイプが変わったあとに動かします |
| ファイル保存前 | ファイルを保存する前に動かします |

## OK を押すと

`[Macro]` と `[Folders]` の `szMACROFOLDER` が、ロックの下で書かれます。ファイルのほかの部分は、そのままです。
