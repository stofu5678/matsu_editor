# 共通設定: 強調キーワード

強調して色を付ける単語を、「セット」にまとめて編集します。キーは `[KeyWords]` セクションにあります。どのセットを使うかは、タイプ別設定が決めます。

OK を押すと、ロックの下で、`[KeyWords]` と、セットの番号を持つタイプ別設定の番号が書かれ、すべてのウィンドウが、すぐに新しいセットで色を付けます。

## セットの編集

| 部品 | 動き |
|---|---|
| セットの選択 | 編集するセットを選びます（`nCurrentKeyWordSetIdx`） |
| セット名の入力 | 名前の欄 |
| セット追加 | 欄の名前で、新しいセットを作ります |
| 変更 | 選んだセットの名前を、欄の名前に替えます |
| セット削除... | 選んだセットを消します |
| 英大文字小文字区別 | セットの大文字小文字の区別を決めます |

## キーワードの編集

| 部品 | 動き |
|---|---|
| キーワードの一覧 | 選んだセットの単語。セットの大文字小文字の規則の順に並びます |
| キーワードの入力 | 単語の欄。一覧の単語をクリックすると、欄に入ります |
| 追加、編集、削除 | 欄の単語で、追加、置き換え、削除をします |
| 整理 | 単語を並べ替え、重複を除きます |
| インポート、エクスポート | 選んだセットを、`.kwd` ファイルから読み込み、書き出します |

## 上限

| 項目 | 上限 |
|---|---|
| セットの数 | 100 |
| セットの名前 | 32 文字（UTF-16 の単位） |
| 1 つの単語 | 63 文字（UTF-16 の単位） |
| すべてのセットの単語の合計 | 15000 |

## サクラエディタとの違い

- 名前と単語は、小さなダイアログではなく、ページの 2 つの欄に入れます。ボタンは、欄の文字を使います
- MATSU Editor が持つ既定のセット（ADR-0017）も、OK でファイルに書かれたあとは、ほかのセットと同じに編集・削除できます

## 根拠

- サクラのソース: `sakura_core/prop/CPropComKeyword.cpp`、`CKeyWordSetMgr`、`CImpExpKeyWord`、`CShareData_IO::ShareData_IO_KeyWords`
- MATSU のコード: `crates/matsu-ui/src/common_settings/pages/keyword.rs` と `keyword/` の下のファイル（`entry.rs` の上限）
