# サクラエディタとの違い

MATSU Editor は、サクラエディタの操作感を目指しています。それでも、次のような違いがあります。機能の一覧と、まだ入っていないものは、`docs/sakura-gaps.md`（機能台帳）に記録しています。このページはその要点です。

## 名前と設定

| 項目 | サクラエディタ | MATSU Editor |
|---|---|---|
| 設定ファイル | `sakura.ini` | `matsu.ini`。書式は同じで、置き場所は別です（[設定ファイル matsu.ini](settings-file.md)） |
| 設定の置き場所 | 実行ファイルの隣が基本。`sakura.exe.ini` で利用者ごとの場所にもできる | OS ごとの決まった場所。`sakura.exe.ini` は読まない |
| 新しい文書の改行コード | 設定による | 既定は OS に合わせる（Windows は CRLF、macOS と Linux は LF）。タイプ別設定にあれば、それに従う |

MATSU Editor は、サクラエディタの設定ファイルを読みも書きもしません。サクラエディタと同時に使っても、設定は混ざりません。

## 動きかたの違い

- **1 つのプロセス**: サクラエディタは、ウィンドウごとのプロセスと、常駐するコントロールプロセスで動きます。MATSU Editor は、使う設定ファイル 1 つにつき 1 つのプロセスです。2 回目以降の起動は、動いているプロセスに引数を渡して終わります
- **ダイアログ**: MATSU Editor の自前のダイアログの多くは、モーダルではありません。別のウィンドウとして開き、開いたまま後ろの編集を続けられます。GPUI にモーダルの子ウィンドウがないためです。ただし、バージョン情報と、文字列を 1 行入力するダイアログは、ウィンドウの中に重ねて出します。閉じるまで、後ろの本文にキーは届きません
- **ファイルのダイアログ**: 開く・保存のダイアログは、OS のものを使います。Windows の旧式のダイアログは使えません
- **印刷**: プリンターの選択は、OS の印刷ダイアログに任せます
- **ウィンドウの機能**: Linux では、OS が許さないため、ウィンドウの配置と「常に手前」が使えません

## まだない機能

次の機能は、今の MATSU Editor にありません。

| 機能 | 状況 |
|---|---|
| タスクトレイへの常駐、トレイのショートカットキー | 設定の部品は灰色です。`-NOWIN` は読むだけで何もしません |
| プロファイルマネージャ | ありません。プロファイルは `-PROF=` で選びます |
| Migemo | ありません。ライセンスの確認が済んでいません |
| 画面の表示言語の切り替え | ありません。画面は日本語です |
| ダークモード | 設定の部品は灰色です |
| タイプ一覧の、ファイルの関連付け | ありません（Windows のレジストリに書く機能です） |
| 共通設定のうち、灰色の部品 | 効きません（灰色で表示します） |
| コードページ 51932 と 20932 での保存 | できません |
| ベストフィット表 | 使いません。変換できない文字は `?` になります |
| コマンドラインの `-GROUP=` `-DEBUGMODE` `-PROFMGR` | 受け付けて無視します |
| ダイアログのヘルプボタン | 一部のダイアログにありません |

このほか、サクラエディタの機能で、まだ入っていないものが残っています。詳しくは、機能台帳を見てください。

## 作りが違うもの

### 正規表現

サクラエディタは、`bregonig.dll`（中身は Onigmo）を使います。MATSU Editor は、Onigmo を自分の中に組み込んでいます。サクラエディタの正規表現に合わせて作っていますが、細部で違うことがあります。複数行の照合の細部は、サクラエディタとの比較をまだ続けています。

### マクロ

- キーマクロ（`.mac`）は、本体で動かします
- サクラエディタが WSH 経由で動かす VBScript と JScript は、そのままでは動きません。MATSU Editor は、Lua、JavaScript（QuickJS）、Ruby（mruby）、Python（MicroPython）の処理系を同梱しています。利用者が入れた Node.js、Python、Ruby、PHP なども使えます
- JScript で書いたマクロは、`WScript` や `ActiveXObject` を使わない部分なら、JavaScript として動く見込みです
- VBScript のマクロは、別の言語に書き換える必要があります

### プラグイン

プラグインの定義ファイル（`plugin.def`）は、サクラエディタと同じ形で読みます。違いは次のとおりです。

- 「新規プラグインを追加」を押しても、すぐには有効になりません。追加のときに確認の画面が出て、一覧で「有効」にしたときに初めて動きます
- プラグインは、別のプロセスで動きます。スマートインデントのプラグインは、サクラエディタが文字ごとに同期で呼ぶのに対して、MATSU Editor は改行と、プラグインが宣言した文字のときだけ、コマンドのあとに呼びます

## 直したサクラエディタの不具合

サクラエディタの明らかな不具合は、MATSU Editor では正しく動く形にしています。たとえば、次のものです。

- UTF-16 を指定した保存を、サクラエディタが無視してしまう動き

## MATSU Editor だけの機能

サクラエディタにない機能があります。シェルのタブ、プレビュー、巨大なファイルの扱い、保存していない文書の自動保存、データベース、エンコードとデコードなどです。それぞれのページは、「MATSU Editor だけの機能」の章にあります。
