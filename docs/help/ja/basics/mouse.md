# マウスで動く・選ぶ

マウスの操作は、押したボタン、続けて押した回数、押していたキー（`Shift`、`Ctrl`、`Alt`）で決まります。macOS では、`Alt` は `Option` キーです。

## テキストの上でのクリックとドラッグ

| 操作 | 動き |
|---|---|
| 左クリック | キャレットをクリックした位置へ動かす。選択は解かれる |
| `Shift` + 左クリック | 今のキャレットの位置から、クリックした位置までを選ぶ |
| `Ctrl` + 左クリック | クリックした単語を選ぶ。そのままドラッグすると、単語単位で選択を広げる |
| `Alt` + 左ドラッグ | 矩形で選ぶ（「[矩形選択と矩形の編集](box-select.md)」を見てください） |
| 左ドラッグ | 押した位置からドラッグした位置までを選ぶ |
| 選択範囲の上で押してドラッグ | 選んだ文字列を移動する（`Ctrl` を押していればコピーする。「[ドラッグ&ドロップ](drag-and-drop.md)」を見てください） |
| ダブルクリック | 単語を選ぶ。そのままドラッグすると、単語単位で選択を広げる |
| トリプルクリック | 行を選ぶ。そのままドラッグすると、行単位で選択を広げる |
| クアドラプルクリック（4 回） | すべてを選ぶ |
| 5 回目 | 1 回目と同じ（キャレットを動かすだけのクリックに戻る） |
| 右クリック | 右クリックメニューを出す（「[右クリックメニューとカスタムメニュー](right-click-menu.md)」を見てください） |
| 中ボタン | オートスクロール |

クリックの回数ごとの動きは、「キー割り当て」の表の「ダブルクリック」「トリプルクリック」「クアドラプルクリック」の行が決めています。既定では、それぞれ `F_SELECTWORD`、`F_SELECTLINE`、`F_SELECTALL` です。この行を書き換えると、ダブルクリックなどに別の機能を割り当てられます。

右クリック、中クリック、左右のサイドボタンの行も、同じ表にあります。右クリックの既定は、`Shift`、`Ctrl` を押していても右クリックメニュー（`F_MENU_RBUTTON`）です。`Alt` を押した右クリックには、何も割り当てていません。中クリックの既定は `F_AUTOSCROLL`、サイドボタンの既定は割り当てなしです。

### 矩形のあとの `Shift` + クリック

矩形で選んでいるときに `Shift` を押しながらクリックすると、矩形は解かれ、キャレットの位置からクリックした位置までを、普通の範囲として選びます。

### URL

テキストの中の URL やメールアドレスをクリックすると、その全体が選ばれます（共通設定の「編集」の「クリックでURLを選択する」がオンのとき）。ダブルクリックすると、既定のアプリで開きます。メールアドレスは、`mailto:` として開きます。URL として色が付くのは、「タイプ別設定」の「カラー」で URL の色分けを有効にしているときです。

### 行の右側のクリック

行の終わりより右側をクリックすると、キャレットは行末に動きます。共通設定の「全般」で「フリーカーソル」をオンにしているときは、クリックした位置（空白の上）にキャレットを置けます。そこに文字を入れると、行末からの間が空白で埋められます。

### 行番号の欄

行番号の欄で押すと、その行が選ばれます。そのままドラッグすると、行単位で選択が広がります。`Shift` を押しながら押すと、その行の頭へのクリックとして扱い、今のキャレットの位置からそこまでを選びます。ルーラーをクリックしても、何も起きません。

## ホイールとスクロール

| 操作 | 動き | 機能 |
|---|---|---|
| ホイール | 上下にスクロールする | `F_WHEELUP` `F_WHEELDOWN` |
| `Ctrl` + ホイール | フォントを拡大、縮小する | `F_SETFONTSIZEUP` `F_SETFONTSIZEDOWN` |
| 横ホイール（対応する機器） | 左右にスクロールする | `F_WHEELLEFT` `F_WHEELRIGHT` |

1 回の目盛りで動く行数は、OS の設定の値です。

共通設定の「全般」では、ホイールと組み合わせるキーやボタンを選べます。

- 「組み合わせてホイール操作した時ページスクロールする」: 選んだものを押しながらホイールを回すと、1 ページずつ動きます。
- 「組み合わせてホイール操作した時横スクロールする」: 選んだものを押しながらホイールを回すと、左右に動きます。

選べるものは、「組み合わせなし」、中ボタン、サイドボタン 1、サイドボタン 2、`Ctrl`、`Shift` です。

## オートスクロール

中ボタンを押して離すと、押した位置から、ポインターを動かした向きにテキストが自動でスクロールします。ポインターを離すほど、速くなります。もう一度ボタンを押すか、ほかの操作（キー入力、クリック、ほかの機能）をすると止まります。

- テキストが短くて、スクロールするものがない方向には、動きません。両方向ともスクロールするものがないときは始まりません。
- 200 ミリ秒ごとに、始めの位置からの距離に応じた行数と桁数だけ動きます。

## ウィンドウを有効にするクリック

ほかのウィンドウから切り替えるときのクリックは、キャレットを動かさずに、ウィンドウを有効にするだけにできます。共通設定の「全般」で「マウスクリックでのアクティブ化ではカーソルを移動しない」をオンにします。

## サクラエディタとの違い

- ウィンドウをまたぐドラッグ&ドロップ、ほかのアプリとのテキストのやり取り、右ボタンでのドロップは、まだできません（「[ドラッグ&ドロップ](drag-and-drop.md)」を見てください）。
- ポインターの形（URL の上や選択範囲の上で手や矢印にする）は、まだ変わりません。
- ドラッグの途中で `Esc` を押してやめることと、ドラッグしたまま端に寄せたときの自動スクロールは、まだできません。
- ホイールで動く量は、サクラエディタと同じく OS の設定の値です。
- Windows でウィンドウを有効にする最初のクリックは、GPUI が最初のクリックを教えないため、ウィンドウが有効になって 150 ミリ秒以内の押下を、その最初のクリックとして扱います。macOS と Wayland は、OS が教えてくれる情報を使います。
