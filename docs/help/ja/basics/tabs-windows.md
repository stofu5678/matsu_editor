# 複数の文書：タブとウィンドウ

複数のファイルを同時に開くには、2 つの使い方があります。

- **ウィンドウを別々に使う**（既定）: 1 つの文書に、1 つのウィンドウを使います。
- **タブにまとめる**: 1 つのウィンドウの中に、文書をタブで並べます。

どちらでも、同じ操作で使えます。タブバーを出し入れすることと、まとめるかどうかを選ぶことで、切り替わります。

## どちらの使い方になるか

| タブバーを表示する | ウィンドウをまとめてグループ化する | 使い方 |
|---|---|---|
| しない（既定） | ― | ウィンドウを別々に使う。タブバーは出ない |
| する | する（既定） | タブにまとめる。1 つのウィンドウに複数の文書が入る |
| する | しない | ウィンドウは 1 文書ずつ。各ウィンドウのタブバーが、すべての文書を並べる。タブをクリックすると、そのウィンドウが前に出る |

- タブバーの表示は、「設定」メニューの「タブバーの表示／非表示」（機能 `F_SHOWTAB`）か、共通設定の「タブバー」の「タブバーを表示する」で切り替えます。
- 「ウィンドウをまとめてグループ化する」は、共通設定の「タブバー」にあります。ウィンドウメニューの「タブの操作」の「グループ化」（機能 `F_BIND_WINDOW`）でも切り替えられます。
- タブバーを出して、まとめるようにすると、開いているすべてのウィンドウの文書が、今のウィンドウのタブに集まります。バーを隠すか、まとめるのをやめると、タブは、それぞれのウィンドウに分かれます。

サクラエディタでは、ウィンドウをまとめるしくみが、別々のウィンドウを重ねて 1 つの枠に見せる作りです。マツエディタでは、1 つのウィンドウが文書をタブで持ちます。サクラエディタの「グループ」は、マツエディタの 1 つのウィンドウに当たります。

## 新しい文書が開く場所

ファイルを開いたり、新規作成したりすると、新しい文書は、次のところに開きます。

- タブにまとめているとき: 今のウィンドウの、新しいタブ。
- それ以外のとき: 新しいウィンドウ。
- 「新規ウインドウを開く」（機能 `F_FILENEW_NEWWINDOW`）は、いつでも新しいウィンドウに開きます。
- 共通設定の「タブバー」の「外部から起動するときは新しいウインドウで開く」をオンにすると、エクスプローラーなどからファイルを開いたとき（外部からの起動）は、いつも新しいウィンドウに開きます。

マツエディタは、1 つの設定ファイル（`matsu.ini`）について、1 つのプロセスだけが動きます。2 回目以降の起動は、動いているマツエディタに、開くファイルを渡して終わります。受け取ったほうは、すでに開いているファイルならそのウィンドウを前に出し、そうでなければ、上の規則で開きます。

## タブバーの使い方

- タブをクリックすると、その文書に切り替わります。
- タブの閉じるボタン、またはタブの上での中ボタンのクリックで、その文書を閉じます。変更が未保存なら、保存するかどうかを聞きます。
- タブバーの、タブの右の空いたところをダブルクリックすると、新しい文書ができます。
- タブを右クリックすると、そのタブに対する「タブメニュー」（カスタムメニュー 24）が出ます。
- タブバーの右端に、2 つのボタンがあります。
  - ▼: 左クリックで、すべてのタブの一覧（見出し）、右クリックで、ファイルのパスの一覧が出ます。選ぶと、そのタブに切り替わります。
  - ×: タブにまとめているときは、今のタブを閉じます。共通設定の「タブバー」の「ウィンドウの閉じるボタンは現在のファイルのみ閉じる」をオンにすると、そのウィンドウのタブをすべて閉じます（`F_GROUPCLOSE`）。まとめていないときは、すべてのエディタを終了します（`F_EXITALLEDITORS`）。
- タブをドラッグすると、バーの中で並べ替えられます。
- タブをウィンドウの外へドラッグして離すと、離した場所のウィンドウのタブになるか、ほかのウィンドウがなければ、その場所に新しいウィンドウができます。
- 共通設定の「タブバー」では、タブにアイコンを付ける、タブの幅をそろえる、タブを複数の段にする、バーを下に置く、タブの幅の上限と下限、閉じるボタンの出し方、タブ一覧の並べ方、タイトルの形式などを決められます。

### 見出しと外観

タブの見出しは、その文書の表示名（ファイル名と、変更の印など）です。見出しの形式は、共通設定の「タブバー」のタイトルで決めます。

## 隣のタブ・ウィンドウへ移る

| キー | 動き | 機能 |
|---|---|---|
| `Ctrl+Tab` | 次のウィンドウ（タブ）へ | `F_NEXTWINDOW` |
| `Ctrl+Shift+Tab` | 前のウィンドウ（タブ）へ | `F_PREVWINDOW` |

タブにまとめているときは、同じウィンドウの中のタブを順に移ります。まとめていないときは、すべてのウィンドウを順に移ります。「ウィンドウ一覧」（「ウィンドウ」メニュー）は、どちらの使い方でも、すべての文書を並べます。

## 「ウィンドウ」メニューの機能

| 機能 | 動き |
|---|---|
| 閉じる（`F_WINCLOSE`） | 今のタブ（ウィンドウ）を閉じる |
| すべて閉じる（`F_WIN_CLOSEALL`） | すべてを閉じる |
| このタブ／ウィンドウ以外を閉じる（`F_TAB_CLOSEOTHER`） | 今のもの以外を閉じる |
| 次のウィンドウ、前のウィンドウ | 上の表のとおり |
| ウィンドウ一覧... | 開いている文書の一覧から選んで切り替える |
| 重ねて表示、上下に並べて表示、左右に並べて表示 | ウィンドウの並べ方 |
| 常に手前に表示 | このウィンドウを、ほかの上に出し続ける |
| 縦方向に最大化、横方向に最大化、すべて最小化 | ウィンドウの大きさを変える |

「タブの操作」のサブメニューには、タブとグループの機能があります。

| 機能 | 動き |
|---|---|
| グループ化（`F_BIND_WINDOW`） | タブにまとめる・まとめないを切り替える |
| グループを閉じる（`F_GROUPCLOSE`） | そのウィンドウのタブをすべて閉じる |
| 左をすべて閉じる、右をすべて閉じる | そのタブの左、右にあるタブを閉じる |
| 次のグループ、前のグループ | ほかのウィンドウへ移る |
| タブを右に移動、タブを左に移動 | ウィンドウの中でタブの並びを動かす |
| 新規グループ（`F_TAB_SEPARATE`） | そのタブを、新しいウィンドウに移す |
| 次のグループに移動、前のグループに移動 | そのタブを、隣のウィンドウに移す |

それぞれの機能の詳しい説明は、「コマンド: 設定（タイプ別設定）とウィンドウ」の章にあります。

## タブになる、ほかの種類の画面

文書の編集のほかに、シェル、プレビュー、AI ログも、タブ（またはウィンドウ）に開きます。これらは「MATSU Editor だけの機能」の章にあります。この種類の画面では、ツールバーとファンクションキーのバーは出ません。

## サクラエディタとの違い

- サクラエディタは、文書ごとの別々のウィンドウを重ねて、1 つの枠に見せます。マツエディタは、1 つのウィンドウが、タブで複数の文書を持ちます（ADR-0015）。
- 「グループ」の操作は、ウィンドウに対する操作になります（上の表のとおり）。
- 起動のたびに別のプロセスにはならず、1 つの設定ファイルにつき 1 つのプロセスです（ADR-0016）。
- コマンドラインの `-GROUP=`（タブのグループ指定）は、読むだけで、無視します（`docs/sakura-gaps.md`）。
