## 画面と機能の名前

マツエディタのメニューや機能の名前は、サクラエディタと同じです。サクラエディタを使ったことがあれば、同じ場所で同じ名前の機能が見つかります。違いがあるところは、各ページの「サクラエディタとの違い」に書いています。まとめて知りたいときは、「はじめに」の「サクラエディタとの違い」の章を見てください。

## 操作の考え方

マツエディタの操作は、すべて名前の付いた「機能」です。メニューの項目も、キーも、ツールバーのボタンも、右クリックメニューも、マクロも、同じ機能を呼び出します。そのため、次のことが成り立ちます。

- どの入り口から呼んでも、動きは同じです。
- 右クリックメニューやカスタムメニューから呼んだ機能も、キーマクロに記録されます。
- キー割り当てを変えれば、好みのキーから同じ機能を呼べます。
