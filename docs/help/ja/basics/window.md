# ウィンドウの各部

マツエディタのウィンドウは、上から順に次の部品が並びます。出すか隠すかを選べるものは、既定の状態と切り替え方も書きます。

| 順 | 部品 | 既定 | 切り替え |
|---|---|---|---|
| 1 | メニューバー | 表示 | 隠せない |
| 2 | ツールバー | 表示 | `Ctrl+1`（機能 `F_SHOWTOOLBAR`） |
| 3 | ファンクションキーのバー（上に置くとき） | 隠す | `Ctrl+2`（機能 `F_SHOWFUNCKEY`） |
| 4 | タブバー（上に置くとき） | 隠す | 機能 `F_SHOWTAB`（キーなし） |
| 5 | テキスト領域（ミニマップ、アウトラインのペインを含む） | 表示 | ― |
| 6 | タブバー（下に置くとき） | ― | 共通設定の「タブバー」 |
| 7 | ファンクションキーのバー（下に置くとき） | ― | 共通設定の「ウィンドウ」 |
| 8 | ステータスバー | 表示 | `Ctrl+3`（機能 `F_SHOWSTATUSBAR`） |

切り替えの機能は、「設定」メニューの先頭にあります。ミニマップの出し入れ（機能 `F_SHOWMINIMAP`）も同じ場所にあります。出し入れの結果は、設定ファイルの `[Common]` に書かれます。

## メニューバー

「ファイル」「編集」「変換」「検索」「ツール」「設定」「ウィンドウ」「ヘルプ」の 8 つが並びます。

- Windows と Linux では、ウィンドウの中にメニューバーが出ます。macOS では、画面上部の macOS のメニューバーに出ます。
- Windows と Linux では、`Alt` を押しながらメニュー名の後ろの括弧にある文字（例: 「ファイル(F)」の `F`）を押すと、そのメニューが開きます。`Alt` だけを押して離しても、メニューバーに移ります。ただし、`Alt` と文字の組み合わせにキー割り当てがあるときは、そちらの機能が先に動きます。
- 開いたメニューの中で、項目の後ろの括弧にある文字を押すと、その項目が動きます。同じ文字の項目が複数あるときは、押すたびに次の項目へ選択が移ります。
- メニューの中身は、共通設定の「メインメニュー」で変えられます。

## ツールバー

ボタンで機能を呼びます。ボタンの並びは、共通設定の「ツールバー」で変えられます。

- ボタンの上にポインターを置くと、機能の名前と、その機能に割り当てられたキーが出ます。
- 割り当てた機能がまだ実装されていないボタンは、灰色になります。また、今の状態では使えない機能のボタンも灰色です。
- 状態を持つ機能（例: ミニマップの表示）のボタンは、オンの間、押された形になります。
- 検索ボックスのボタンは、入力欄になります。検索履歴のリストが付き、`Enter` で次を検索します。`Tab` か `Esc` で本文に戻ります。
- 「開く」ボタンは、右に付いた矢印から、最近使ったファイルとフォルダーの一覧を出せます。

## ファンクションキーのバー

`F1` から `F12` までの 12 個のボタンが並びます。ボタンの名前は、そのキーに割り当てられている機能の名前です。`Shift`、`Ctrl`、`Alt` を押している間は、その組み合わせで割り当てられた機能の名前に変わります。割り当てがないキーのボタンは空白です。

- ボタンを押すと、その機能が動きます。
- 4 個ずつ（既定）、少し間を空けて並べます。間隔の個数は、共通設定の「ウィンドウ」で 1 から 12 の間に変えられます。
- バーを置く場所（上か下）も、同じ場所で選びます。

## タブバー

複数の文書をタブで並べるときに使います。使い方は「[複数の文書：タブとウィンドウ](tabs-windows.md)」にあります。

## テキスト領域

文字を書く場所です。行番号、ルーラー、ミニマップ、スクロールバーは「[テキスト領域：行番号・ルーラー・ミニマップ](text-area.md)」にあります。画面分割は「[画面分割](split-view.md)」にあります。

アウトライン解析のペインは、テキスト領域の左右どちらかに付きます。使い方は「コマンド: 検索」の章の「アウトライン解析」にあります。

## ステータスバー

画面の一番下の欄です。内容は「[ステータスバー](status-bar.md)」にあります。

## 表示しない画面

文書を編集する画面ではない種類のタブ（シェル、プレビュー、AI ログ）では、ツールバーとファンクションキーのバーは出ません。ステータスバーは、メッセージの欄だけになるか、出ません（シェルとプレビューは「MATSU Editor だけの機能」の章を見てください）。

## サクラエディタとの違い

- ファンクションキーのバーのボタンは、割り当てた機能が未実装のときだけ灰色になります。サクラエディタは、機能が今使えるかどうかでも灰色にします。
- ツールバーに、プラグインのボタンを出すことは、まだできません。
- macOS では、メニューバーが macOS のメニューバーになります（ウィンドウの中には出ません）。
