# 左をすべて閉じる

いまのタブより左にあるタブを、すべて閉じます。いまのタブは閉じません。

| 項目 | 内容 |
|---|---|
| メニュー | ウィンドウ > タブの操作 > 左をすべて閉じる |
| 機能名 | `F_TAB_CLOSELEFT` |
| 既定のキー | なし |
| マクロ | `TabCloseLeft` |
| キーマクロに記録 | しない |

## 動き

- タブバーを表示しているときだけ働きます（隠していると何も起きません）。
- 変更を保存していない文書は、保存するかどうか聞きます。「キャンセル」を選ぶと、そこで止まります。それまでに閉じたタブは閉じたままです。
- プレビューのタブから使ったときは、そのタブの位置が基準です。左にあるプレビューのタブは閉じません。
- タブバーを表示していて、まとめていないとき（各ウィンドウのバーがすべての文書を並べるとき）は、ウィンドウの並びの左にある文書を閉じます。
- 閉じる文書が 2 つ以上のときは、共通設定「全般」の「同時に複数の編集用ウィンドウを閉じるとき確認」（既定はオフ）がオンなら、最初に確認します。

## サクラエディタとの違い

- サクラの動き（左のウィンドウに閉じる要求を送る）に合わせています。

## 根拠

- サクラのソース: `sakura_core/cmd/CViewCommander_Window.cpp` の `Command_TAB_CLOSELEFT`
- MATSU のコード: `crates/matsu-ui/src/ui_commands/window/tab_closeleft.rs`、`crates/matsu-ui/src/tabs/flows.rs`（`close_side`）、`crates/matsu-ui/src/tabs/order.rs`（`left_range`）
