# タイプ別設定: キーワードヘルプ

カーソルの下の言葉や、選んだ文字列の意味を、辞書のファイルから引いて見せる機能の設定です。辞書は、タイプごとに最大 20 個まで登録できます。

| 項目 | キー | 動き |
|---|---|---|
| キーワードヘルプ機能を使う | `bUseKeyWordHelp` | 機能の入と切。オフのとき、このページのほかの部品は灰色になる |
| 辞書ファイル一覧 | `KDct[00]` から `KDct[19]` | 辞書の一覧。上にあるものが優先される |
| ヒットした次の辞書も検索 | `bUseKeyHelpAllSearch` | 言葉が見つかった辞書より後ろの辞書も、調べる |
| キーワードも表示する | `bUseKeyHelpKeyDisp` | 表示する文章の最初の行に、引いた言葉も出す |
| 選択範囲で前方一致検索 | `bUseKeyHelpPrefix` | 選んだ文字列で引くとき、辞書の見出しが、その文字列で始まっていても、ヒットとして扱う |
| 右クリックメニュー | `nKeyHelpRMenuShowType` | 右クリックメニューに、言葉の意味を出す場所。「表示しない」（0）、「先頭に表示」（1）、「末尾に表示」（2）。最初の値は「先頭に表示」 |

## 辞書の一覧

一覧には、「辞書ファイル」「辞書の説明」「使用」の 3 つの欄があります。「使用」は ○（使う）か ×（使わない）で、一覧の下の欄に書いて変えます。ファイルには、`KDct[NN]=使用,説明,パス` の形で入ります。

次のボタンで、一覧を変えます（「追加」はありません）。

| ボタン | 動き |
|---|---|
| 先頭、最終 | 選んだ行を、一覧の先頭、または最後へ動かす |
| 上へ、下へ | 選んだ行を、1 つ上、または 1 つ下へ動かす |
| 挿入 | 欄のファイルを、選んだ行の前に入れる |
| 更新 | 選んだ行を、欄の内容に書き換える |
| 削除 | 選んだ行を消す |

「挿入」と「更新」では、次のように確かめます。

- すでに一覧にある辞書は、登録できません。「既に登録済みの辞書です。」と知らせます。更新する行自身の辞書は、そのままでかまいません。
- ファイルを開けなければ、「ファイルを開けませんでした。」と知らせます。相対パスは、設定ファイルのある場所からの道筋として読みます。
- 辞書の説明は、ファイルの最初の行から作ります。コンマは `.` に置き換え、最大 49 文字までです。最初の行は、BOM のある UTF-8 なら UTF-8、BOM がなければ Shift_JIS として読みます。
- 新しく入れた辞書は、「使う」になります（欄に × と書いたときは、使いません）。
- 一覧がいっぱい（20 個）のときは、「これ以上登録できません。」と知らせます。

## 辞書のファイル

辞書は文字のファイルです。1 行が 1 つの項目です。

- `キー1,キー2 /// 意味` の形で、「 /// 」（前後に空白）で、言葉と意味を区切ります。キーは、コンマで区切って、いくつも書けます。
- `;` で始まる行は、コメントです。
- 区切りのない行は、何も意味しません。
- 言葉は、大文字と小文字を区別せず、キーと比べます。

## どう働くか

- 選んだ文字列があれば、その最初の行の終わりまで（101 文字まで）が、引く言葉です。選んでいなければ、「設定」メニューの「キーワードヘルプ自動表示」（`F_TOGGLE_KEY_SEARCH`。「キャレット位置の単語を辞書検索」と同じ設定）がオンのとき、カーソルのある単語を引きます。
- マウスを、300 ミリ秒動かさずに置いておくと、意味がマウスの近くに出ます。マウスを動かすと消えます。
- 右クリックメニューには、「キーワードの説明をクリップボードにコピー」と「キーワード辞書を開く」が、「右クリックメニュー」の設定の場所に出ます。
- 入力補完の候補の意味が、候補の一覧の横にも出ます。
- 引いて見つからなかった言葉は、言葉かタイプの設定が変わるまで、引き直しません。

## 一覧のインポートとエクスポート

| ボタン | 動き |
|---|---|
| インポート | 辞書の一覧を書いた文字のファイルを読み、一覧を置き換える。読めない行があれば、その数を、取り込みのあとに知らせる。ファイルを開けなければ、「ファイルを開けませんでした。」と知らせて、何も変えない |
| エクスポート | 一覧を文字のファイルに書き出す。ファイル名の候補は `keyhelp.txt`。ファイルのない行は、辞書として数えない |

どちらも、設定ファイルには、OK を押すまで書きません。

## サクラエディタとの違い

- 一覧の「使用」の欄は、サクラエディタでは各行のチェックボックスですが、MATSU Editor では ○ と × の欄です。
- ヒントの文字のフォントは、共通設定「支援」ページの設定（`khlf`）を使います。
