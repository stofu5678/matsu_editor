# タイプ別設定: 正規表現キーワード

正規表現に合った文字列に、色を付けるページです。強調キーワード（言葉の一覧）より細かい規則を、正規表現で書けます。たとえば「`TODO` で始まるコメント行」や「`#` と 6 桁の 16 進数」のような、決まった形の文字列に使います。

| 項目 | キー | 動き |
|---|---|---|
| 正規表現キーワードを使用する | `bUseRegexKeyword` | オンのとき、一覧の規則で色を付ける |
| 正規表現キーワード（一覧） | `RxKey[000]` から `RxKey[099]` | 規則の一覧。最大 100 個 |

画面には、使う正規表現のエンジンの名前（Onigmo）が出ています。

## 一覧

1 行が 1 つの規則で、「キーワード」（正規表現）と「色指定」の 2 つの欄があります。ファイルには、`RxKey[NNN]=色,キーワード` の形で、1 行に 1 つずつ入ります。一覧は、空のキーワードの最初の行で終わります。

### キーワードの書き方

正規表現を、次のどれかの形で囲みます。

| 形 | 意味 |
|---|---|
| `/正規表現/k` | 大文字と小文字を区別する |
| `/正規表現/ki` | 大文字と小文字を区別しない |
| `m/正規表現/k`、`m#正規表現#k`（とその `ki` の形） | 正規表現に `/` を含められる |

- 囲んでいない書き方は、登録できません。「正規表現キーワードを / と /k で囲ってください」と知らせます。
- すでにある行と同じキーワードは、登録できません。「同じキーワードで登録済みです。」と知らせます。
- 正規表現として使えない書き方のときは、「書式が正しくないか、正規表現ライブラリが見つかりません。登録しますか？」と聞きます。「いいえ」が最初の選択です。登録しても、色分けのときには、使えない規則を飛ばします。
- 1 つのキーワードは、999 文字までです。
- 一覧がいっぱい（100 個）のときは、「これ以上登録できません。」と知らせます。

### 色指定

色は、[カラーページ](type-page-color.md)の項目の名前で書きます（たとえば「正規表現キーワード1」）。選べる色は、文字色と背景色の両方を持つ項目だけです。一覧にない名前を書くと、「正規表現キーワード1」になります。「URL」を選ぶと、マッチした文字列を、クリックで開けるリンクとして扱います。

サクラエディタは色をドロップダウンの一覧から選びますが、MATSU Editor は入力欄に書きます。

### ボタン

一覧の下の欄に、選んだ行の「正規表現」と「色指定」が出ます。次のボタンで、一覧を変えます。

| ボタン | 動き |
|---|---|
| 先頭、最終 | 選んだ行を、一覧の先頭、または最後へ動かす |
| 上へ、下へ | 選んだ行を、1 つ上、または 1 つ下へ動かす |
| 挿入 | 欄の内容を、選んだ行の前に入れる |
| 追加 | 欄の内容を、一覧の最後に足す |
| 更新 | 選んだ行を、欄の内容に書き換える |
| 削除 | 選んだ行を消す |

一覧の順番が、規則を試す順番です。

## インポートとエクスポート

| ボタン | 動き |
|---|---|
| インポート | `*.rkw` のファイルを読み、一覧を置き換える。設定ファイルには、OK を押すまで書かない |
| エクスポート | 一覧を `*.rkw` のファイルに書き出す |

ファイルは文字のファイルで、最初の行が `// 正規表現キーワード Ver1`、そのあとに `RxKey[NNN]=色の名前,キーワード` の行が並びます。色の名前は、`TXT`、`RK1` のような、カラーページの `C[名前]` と同じ名前です。

## サクラエディタとの違い

- 登録するときの確認で、サクラエディタは、正規表現ライブラリ（bregonig）で書式を調べます。MATSU Editor は、MATSU Editor の正規表現（Onigmo）で調べます。
- 色を、入力欄に書きます（上のとおり）。
- ほかは、サクラエディタと同じ規則です。
