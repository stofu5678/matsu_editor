# タイプ別設定: カラー

本文の色と文字飾り、強調キーワードの選択、コメントと文字列の書き方、縦線の位置を決めるページです。

## 色指定

左上の一覧から項目を選び、その項目の表示、太字、下線、文字色、背景色を決めます。項目が持たない設定は、灰色になって変えられません（たとえば、テキストの「色分け/表示」は、いつもオンです）。

| 項目 | 動き |
|---|---|
| 色分け/表示 | その項目を色分けして表示する（項目によっては、いつもオン） |
| 太字 | 太字にする |
| 下線 | 下線を付ける |
| 文字色 | 文字の色。色の欄を押して選ぶ |
| 背景色 | 背景の色 |
| 文字色統一... | 文字色を、ほかの項目にも同じにする（下の「色の統一」） |
| 背景色統一... | 背景色を、ほかの項目にも同じにする |
| インポート... | 色のファイル（`*.col`）から、色を読み込む |
| エクスポート... | いまの色を、色のファイルに書き出す |

一覧には、次の 57 の項目があります。順番もこのとおりです。

| 種類 | 項目 |
|---|---|
| 本文と表示部品 | テキスト、ルーラー、カーソル、カーソル(IME ON)、カーソル行の背景色、カーソル行アンダーライン、カーソル位置縦線、ノート線、行番号、行番号(変更行)、偶数行の背景色、TAB記号、半角空白、日本語空白、コントロールコード、改行記号、折り返し記号、指定桁縦線、EOF記号 |
| 文字の種類 | 半角数値、対括弧の強調表示、選択範囲、検索文字列（1〜5）、コメント、シングルクォーテーション文字列、ダブルクォーテーション文字列、ヒアドキュメント、URL |
| キーワード | 強調キーワード 1〜10、正規表現キーワード 1〜10 |
| そのほか | DIFF差分表示(追加)、DIFF差分表示(変更)、DIFF差分表示(削除)、ブックマーク、表示範囲(ミニマップ) |

キーは、項目ごとに 1 つで、`C[名前]` です（`C[TXT]`、`C[CAR]`、`C[KW1]`、`C[RK1]` など）。値は `色分け,太字,文字色,背景色,下線` の順で、色は 16 進の 6 桁です。

### 色の統一

「文字色統一...」と「背景色統一...」は、小さなダイアログを開きます。選んでいる項目の色を「統一色」にして、同じタイプの別の項目の色を、まとめてその色にします。

- ダイアログには、ほかの項目が使っている色の一覧が、チェックボックス付きで並びます。選んだ色の欄には、その色を使っている項目の名前が出ます。
- OK を押すと、チェックを付けた色を持つ項目すべてが、統一色になります。
- ダイアログが出ている間も、ダイアログを開いたページは使えます。2 度目に押すと、開いているダイアログが前に出ます。

### 色のファイルの出し入れ

- **インポート**: `*.col` のファイルを読みます。ページにいまある色の上に重ね、ファイルにない色は変わりません。ファイルは、最初の行が `; テキストエディタ色設定 Ver3` で、`[SakuraColor]` の節に `C[名前]` のキーが並ぶ形です。古い形式は読めず、そう知らせます。設定ファイルには、OK を押すまで書きません。
- **エクスポート**: いまページに出ている色を書き出します。サクラエディタと同じく、ファイル名の候補は出しません。

## 強調キーワード

タイプは、強調キーワードのセットを最大 10 個まで持てます。各セットは、1〜10 の番号の枠に入り、枠ごとに「強調キーワード 1〜10」の色が決まります。

| 項目 | キー | 動き |
|---|---|---|
| 一覧（1 つ目のセット） | `nInts` の 5 番目 | 1 つ目のセットを選ぶ |
| 2〜10... | `nInts` の 6 番目、`nKeywordSelect3`〜`nKeywordSelect10` | 2〜10 番目のセットを選ぶダイアログを開く |
| 共通設定... | | 共通設定の「強調キーワード」ページを開く（セットそのものの編集） |

- 値はセットの番号で、-1 は「なし」です。
- 2〜10 のダイアログを閉じると、空いた枠が詰められます。後ろのセットが前の枠に移り、色（色分け/表示、太字、下線、文字色、背景色）も、セットと一緒に移ります。セットは、いつもそれが入っている枠の色で描かれます。
- 「共通設定...」は、サクラエディタでは別のダイアログですが、MATSU Editor では共通設定のダイアログが、その「強調キーワード」ページで開きます。

## コメントスタイル

| 項目 | キー | 動き |
|---|---|---|
| ブロック型（2 組） | `szBlockCommentFrom` と `szBlockCommentTo`、`szBlockCommentFrom2` と `szBlockCommentTo2` | 始まりと終わりの記号。この間がコメントになる |
| 行型（3 つ） | `szLineComment`、`szLineComment2`、`szLineComment3` | その記号から行末までがコメントになる |
| 桁 | `nLineCommentColumn`、`nLineCommentColumn2`、`nLineCommentColumn3` | 「桁」をオンにして番号を入れると、記号がその桁から始まるときだけコメントになる |

- 桁は、ページでは 1 から数えます。設定ファイルには、0 から数えた値で保存します。「桁」をオフにした行は、ファイルには -1（どの桁でもよい）で保存します。
- 記号が空の欄は、使いません。このページで入力した記号（ブロック型と行型の両方）が UTF-16 の 15 単位より長いときは、OK で保存するとき、先頭の 15 単位に切られます。
- 行型の記号は、ASCII の英字の大文字と小文字を区別しません。ほかの文字は、そのとおりに比べます。

## 文字列エスケープ

| 項目 | キー | 動き |
|---|---|---|
| 文字列エスケープ | `nInts` の 7 番目 | 文字列の中の引用符の書き方。次の 5 種類から選ぶ |
| 行内のみ | `bStringLineOnly` | 文字列は、その行の中だけで終わる |
| 終了文字がない場合行末まで色分け | `bStringEndLine` | 「行内のみ」がオンのとき、終わりの引用符のない文字列を、行末まで文字列の色にする。「行内のみ」がオフのときは使えない |

エスケープの種類は、「C/C++言語風 `\"`」、「PL/SQL風 `""`」、「HTML/XML風 `=""`」、「C#風 `@""`」、「Python風 `"""`」です。

## 縦線桁指定

| 項目 | キー | 動き |
|---|---|---|
| 縦線桁指定 | `nVertLineIdx1`〜`nVertLineIdx200` | 縦線を引く桁を、コンマで区切って書く |

- 書き方は 2 通りです。`10,20` は、10 桁と 20 桁に線を引きます。`5(10,50)` は、10 桁から 50 桁まで、5 桁おきに線を引きます。
- 縦線の色は、色指定の「指定桁縦線」です。
- 読めない文字までを読み、そこで終わります。書き込める数は、全部で 200 個分の枠までです（`5(10,50)` のような範囲は、3 個分を使います）。ファイルでは、0 が入っているところで終わります。

## サクラエディタとの違い

- 「文字色統一」と「背景色統一」のダイアログは、サクラの不具合を直しています。サクラは、文字色統一の一覧で、色のない項目の名前を出したり、ある項目を出し忘れたりします（一覧の位置と項目の番号を取り違えるため）。OK でも、画面に出ていない（色を持たない）項目まで、統一色にしてしまいます。MATSU Editor は、項目自身の属性で判断し、画面に出た項目だけを変えます。
- ダイアログ（色の統一、2〜10）は、モーダルではありません。
