# タイプ別設定一覧...

文書のタイプの一覧を出します。いまの文書にタイプを当てはめたり、タイプを足したり、並べ替えたり、ファイルに出し入れしたりできます。

| 項目 | 内容 |
|---|---|
| メニュー | 設定 > タイプ別設定一覧... |
| 機能名 | `F_TYPE_LIST` |
| 既定のキー | `Ctrl+4` |
| マクロ | `TypeList` |
| キーマクロに記録 | しない |

## 一覧の見方

1 行が 1 つのタイプです。行は「名前 ( 拡張子 )」の形で、拡張子のないタイプは名前だけです。ダイアログを開いたとき、いまの文書のタイプが選ばれています。

操作のキーは、`↑` `↓` で選ぶ、`Enter` で「設定変更」、`Esc` で閉じる、です。行のダブルクリックは「一時適用」です。

## ボタン

| ボタン | 動き |
|---|---|
| 一時適用 | 選んだタイプを、いまの文書に当てはめます（下の「一時適用」） |
| 設定変更 | 一覧を閉じて、選んだタイプの[タイプ別設定](type-settings.md)を開きます |
| 追加 | 「基本」の写しを、一覧の最後に足します。名前は「設定N」、拡張子は空です |
| 複製 | 選んだタイプの写しを、一覧の最後に足します。拡張子も写し、名前の後ろに番号を付けます |
| 削除 | 選んだタイプを消し、後ろのタイプを 1 つずつ前へ詰めます。確認を出します |
| ↑ ↓ | 選んだタイプを、1 つ前、または 1 つ後ろと入れ替えます |
| 初期化 | 選んだタイプを初期の状態に戻します |
| インポート | ファイルからタイプを読み込みます |
| エクスポート | 選んだタイプをファイルに書き出します |

ボタンを押したあとも、一覧は開いたままで、作ったタイプや動かしたタイプが選ばれます。変更は、すぐ設定ファイルに保存され、すべてのウィンドウに反映されます。別のウィンドウで一覧を開いていれば、そちらの一覧も新しい内容に変わります。

### 使えるボタン

選んだタイプによって、使えないボタンがあります。

- 「基本」（先頭のタイプ）は、削除できず、動かせません。
- 「↑」は 3 番目のタイプから使えます（「基本」より前に動かせないため）。
- 「↓」は、「基本」と最後のタイプでは使えません。
- 「追加」と「複製」は、タイプが 60 個になると使えません。
- 設定ファイルの `nTypesCount=30` は 36 個として読むため、タイプを 30 個にする「追加」と「複製」は、「タイプを 30 個にはできません」と知らせて、何もしません。

### 初期化

- 「基本」は、組み込みの設定に戻ります。「よろしいですか」と確認します。
- 「基本」以外は、「基本」の写しで、名前が「設定N」、拡張子が空のタイプになります。タイプの識別子も新しくなります。拡張子のあるタイプだけ、確認を出します。
- 終わると、「〜を初期化しました。」と知らせます。

### 削除したあとの文書

文書のタイプは、番号ではなく識別子で覚えています。タイプを足したり、消したり、並べ替えたりしても、一時適用で選んだタイプは変わりません。選んだタイプが消えたときは、ファイル名から選び直します。それ以外の文書も、ファイル名からタイプを選び直します。ズームと折り返しの一時的な変更は、タイプが変わった文書では取り消され、変わらなかった文書では残ります。

### インポートとエクスポート

- **エクスポート**: ファイル名を聞きます（タイプの名前に `.ini` を付けたものが最初の名前）。タイプの設定を書き出し、そのタイプが使う強調キーワードの定義ファイルを、同じ場所に書きます。
- **インポート**: ファイルを選ぶと、タイプのファイルかどうかを確かめます。設定の構造が別の版で書かれたファイルなら、続けるかどうかを聞きます。そのあと、次を聞く画面を出します。
  - 読み込む先: 「新規追加」か、選んでいるタイプ（置き換え）
  - 色の取り込み元: ファイルの色、一覧のどれかのタイプの色、ファイルのある場所の色ファイル（`*.col`）
- 同じ名前のタイプがあっても、確認はしません。同じ名前のタイプを 2 つ持てます。

## 一時適用

選んだタイプを、いまの文書に当てはめます。文書の名前から選ばれるタイプではなく、自分で決めたタイプにしたいときに使います。

- 当てはめたタイプは、次にファイルを読み込むまで固定します。ファイル名を変えて保存しても、元のタイプには戻りません。
- ズームと折り返しの一時的な変更は、取り消されます。
- まだ保存していない空の新しい文書なら、そのタイプの新しい文書の文字コードと改行コードに変わります（[ウィンドウ ページ](type-page-window.md)）。

同じことをマクロの `ChangeType(n)` でできます。`n` は、タイプの一覧での番号に 1 を足した数です。`ChangeType(1)` が「基本」です。0 は、いまのタイプのまま固定します。タイプの数より大きな数では、何も起きません。MATSU Editor は、タイプの名前の文字列（`ChangeType("C/C++")`）も受け付けます。同じ名前のタイプが複数あれば、最初のものです。

## サクラエディタとの違い

- 「ファイルの関連付け」の 2 つのチェックボックスと、ヘルプのボタンはありません（関連付けは Windows のレジストリへの書き込みです）。
- ダイアログは、本文の上に描きます（モーダルではありません）。
- 設定ファイルは、`matsu.ini` です。タイプの並びを変えるときは、変わった番号から後ろの `[Types(N)]` を全部書き直します。サクラエディタが終了時にまとめて書く代わりです。
