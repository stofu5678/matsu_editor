# 上下に分割／分割解除

ウィンドウの本文を、上と下の 2 つの区画に分けます。すでに上下に分かれているときは、上下の分割を解除します。

| 項目 | 内容 |
|---|---|
| メニュー | ウィンドウ > 上下に分割／分割解除 |
| 機能名 | `F_SPLIT_V` |
| 既定のキー | `F4`、`Ctrl+Shift+-` |
| マクロ | `SplitWinV` |
| キーマクロに記録 | しない |

## 動き

押すたびに、次のように変わります。

| いまの状態 | 押したあと |
|---|---|
| 分割していない | 上下に分かれる（仕切りは高さの半分） |
| 上下に分かれている | 分割していない |
| 左右に分かれている | 4 つに分かれる（左右の仕切りはそのまま） |
| 4 つに分かれている | 左右だけに分かれる（上下の仕切りがなくなる） |

分割したあとの 4 つの区画（ペイン）は、左上が 0、右上が 1、左下が 2、右下が 3 の番号を持ちます。区画 0 はいつもあります。新しく出る区画は、次のように始まります。

- 分割していない状態から分けるとき: 区画 0 のカーソル位置・選択・スクロールを写します（縦横に分けるときは、区画 0 を区画 1・2・3 に写します）。上下に分けるときだけ、下の区画 2 を、上の区画 0 が見せている行のすぐ後ろから始まる位置までスクロールします。
- 上下だけ（または左右だけ）に分かれた状態から 4 つにするとき: 新しい区画は、同じ行または同じ列の区画を写します（上下だけからは 0 を 1 に、2 を 3 に。左右だけからは 0 を 2 に、1 を 3 に）。いま使っている区画を、新しい区画のすべてに写すわけではありません。

分割を解除するときに、消える区画でマクロが動いていると、解除せず「マクロの実行中は、その画面の分割を解除できない」と知らせます。

## サクラエディタとの違い

- 分割の規則はサクラの分割ウィンドウ（`CSplitterWnd`）から移したものです。
- キーマクロの再生中に分割コマンドを使うと、次のコマンドが分割前の大きさで動きます（既知の不具合で、直していません。`docs/sakura-gaps.md`）。

## 根拠

- サクラのソース: `sakura_core/cmd/CViewCommander_Window.cpp` の `Command_SPLIT_V`、`sakura_core/window/CSplitterWnd.cpp` の `VSplitOnOff` と `DoSplit`
