# ウィンドウ一覧表示...

開いているウィンドウを、チェックボックス付きの一覧にしたダイアログで出します。いくつかのウィンドウをまとめて保存したり、閉じたりするときに使います。

| 項目 | 内容 |
|---|---|
| メニュー | ウィンドウ > ウィンドウ一覧表示... |
| 機能名 | `F_DLGWINLIST` |
| 既定のキー | なし |
| マクロ | なし（マクロ名を持たない） |
| キーマクロに記録 | しない |

## 動き

| ボタン | 動き |
|---|---|
| 上書き保存 | チェックを付けたウィンドウで、上書き保存（`F_FILESAVE`）を実行します |
| ウィンドウを閉じる | チェックを付けたウィンドウを閉じます。保存の確認などは、ふつうに閉じるときと同じです |
| OK | ダイアログを閉じるだけです |

- 行の文字と順番は、「ウィンドウ一覧...」と同じです（アクセスキーを除く）。
- ダイアログを開いている間にウィンドウが増えたり減ったりしたら、一覧が追いかけて変わります（約 0.3 秒ごとに見直します）。
- `Enter` または行のダブルクリックで、そのウィンドウを前面に出します。
- すでに開いているときにもう一度使うと、2 つ目は開かず、閉じます。

ダイアログは、本文の上に描きます（サクラのダイアログは、タスクトレイのプロセスが持つ別のウィンドウです）。

## サクラエディタとの違い

- 前面に出す操作（`Enter`、ダブルクリック）は MATSU Editor が足したものです。サクラのダイアログは、ウィンドウを前面に出しません。

## 根拠

- サクラのソース: `sakura_core/cmd/CViewCommander_Window.cpp` の `Command_DLGWINLIST`、`sakura_core/dlg/CDlgWindowList.cpp`
- MATSU のコード: `crates/matsu-ui/src/ui_commands/window/dlgwinlist.rs`、`crates/matsu-ui/src/window_ops/list.rs`
