# タイプ別設定: スクリーン

タイプの名前と拡張子、折り返し、文字と行の間隔、タブ、インデント、アウトライン解析、フォント、禁則処理を決めるページです。キーは、`matsu.ini` の `[Types(N)]` にあります。`nInts` の組は[タイプ別設定...](type-settings.md)の表を見てください。

## 名前と拡張子

| 項目 | キー | 動き |
|---|---|---|
| 設定の名前 | `szTypeName` | 一覧に出るタイプの名前。UTF-16 で 63 単位まで |
| ファイル拡張子 | `szTypeExts` | このタイプにするファイル名の拡張子。空白、`;`、`,` で区切る。ワイルドカード（`*` `?`）も使える。63 単位まで |

「基本」のタイプでは、この 2 つは変えられません。ファイル名とタイプの結びつけ方は、[タイプ別設定...](type-settings.md)の「文書のタイプの決まり方」にあります。

## レイアウト

| 項目 | キー | 動き |
|---|---|---|
| 折り返し方法 | `nTextWrapMethod` | 「折り返さない」（0）、「指定桁で折り返す」（1）、「右端で折り返す」（2） |
| 折り返し桁数 | `nInts` の 2 番目 | 「指定桁で折り返す」のときの桁数。10〜10240 |
| 文字の間隔 | `nInts` の 3 番目 | 文字と文字の間のドット数。0〜64 |
| 行の間隔 | `nLineSpace` | 行と行の間のドット数。-128〜128 |
| TAB幅 | `nInts` の 4 番目 | タブの幅（桁）。1〜64 の数を入力できるが、保存するときは 2〜（折り返し桁数 - 2）に収める |
| TAB表示 | `bTabArrow` | タブの見せ方。「文字指定」（0）、「短い矢印」（1）、「長い矢印」（2） |
| TAB表示の文字列 | `szTabViewString` | 「文字指定」のときに、タブの位置に出す文字。8 文字まで。ほかの見せ方のときは入力できない |
| SPACEの挿入 | `bInsSpace` | オンのとき、`Tab` キーはタブ文字ではなく空白を入れる |
| TSVモード | `nInts` の 12 番目 | 「通常」（0）、「TSV」（1）、「CSV」（2） |

- 「TSV」では、タブ文字が項目の区切りになり、項目の幅をそろえて表示します。「CSV」では、コンマが区切りで、タブは 1 桁です。「通常」では、タブは「TAB幅」の位置まで進みます。
- 矢印は線ではなく、文字（→ と ─）で描きます。
- 本文は、字の送り幅が桁と合わないとき、1 文字ずつ桁の位置に置きます。

## インデント

| 項目 | キー | 動き |
|---|---|---|
| 自動インデント | `bAutoIndent` | 改行したとき、前の行の先頭の空白を引き継ぐ |
| 全角空白も | `bAutoIndent_ZENSPACE` | 全角空白も、インデントの空白として扱う |
| スマートインデント | `nSmartIndent` | 「なし」（0）、「C/C++」（1）、またはプラグインが足したもの |
| その他のインデント対象文字 | `szIndentChars` | 空白のほかに、インデントとして扱う文字。63 単位まで |
| 折り返し行インデント | `nIndentLayout` | 折り返した行の始まる位置。「なし」（0。左端）、「tx2x」（1。最初の行の最後のタブの後ろ）、「論理行先頭」（2。行頭の空白の後ろ） |
| 改行時に末尾の空白を削除 | `bRTrimPrevLine` | 改行したとき、前の行の末尾の空白を消す |

- 「論理行先頭」で空白に数える文字は、「全角空白も」と「その他のインデント対象文字」で決まります。
- 「C/C++」のスマートインデントの細かい設定は、[支援ページ](type-page-support.md)にあります。

## アウトライン解析方法

| 項目 | キー | 動き |
|---|---|---|
| 標準ルール | `nDefaultOutline` | 一覧のルールで、アウトライン解析をする |
| ルールファイル | `nDefaultOutline`（12）と `szOutlineRuleFilename` | ルールのファイルで解析する。参照ボタンでファイルを選ぶ |

「標準ルール」の一覧は、C/C++、C、C++、PL/SQL、Java、COBOL、Perl、アセンブラ、Visual Basic、Python、Erlang、WZ階層付テキスト、HTML、XML、TeX、テキストです。有効なプラグインがアウトライン解析を足していれば、その名前も、この後ろに並びます。プラグインが使えなくなったときは「（使えないプラグイン N）」と出し、値は変えません。

「ルールファイル」を選ぶと、一覧の側は先頭の項目の表示になり、保存される番号は 12（ファイル）です。「標準ルール」に切り替えると、一覧の先頭（C/C++）が選ばれます。ルールファイルに選べるのは `*.rul`、`*.rule`、`*.txt` です。設定ファイルのある場所の下にあるファイルは、そこからの相対パスで保存します。

## タイプ別フォント

| 項目 | キー | 動き |
|---|---|---|
| 使用する | `bUseTypeFont` | オンのとき、このタイプの文書は、共通設定のフォントではなく、ここで選んだフォントで描く |
| フォント... | `lf` で始まる一連のキー、`nPointSize` | フォントを選ぶダイアログを開く |

- 「使用する」は、オフにすることしかできません。オンにするには、「フォント...」でフォントを選びます（選ぶと自動でオンになります）。
- 「フォント...」を開いたとき、すでに使っていればこのタイプのフォントから、使っていなければ共通設定のフォントから始まります。
- ボタンの横に、選んだフォントの名前と大きさが出ます。使っていないときは空です。

## 禁則処理

| 項目 | キー | 動き |
|---|---|---|
| 英文ワードラップ | `nInts` の 10 番目 | 折り返すとき、英単語の途中で切らない |
| 改行ぶら下げ | `bKinsokuRet` | 行末の改行が、折り返し桁をはみ出して置かれることを許す |
| ぶら下げを隠す | `bKinsokuHide` | はみ出した（ぶら下げた）文字を見せない。「改行ぶら下げ」か「句読点ぶら下げ」がオンのときだけ使える |
| 句読点ぶら下げ | `bKinsokuKuto` と `szKinsokuKuto` | 右の欄の文字が、折り返し桁をはみ出して置かれることを許す。欄の最初の値は `、。，．､｡,.` |
| 行頭禁則 | `bKinsokuHead` と `szKinsokuHead` | 右の欄の文字を、行頭に置かない |
| 行末禁則 | `bKinsokuTail` と `szKinsokuTail` | 右の欄の文字を、行末に置かない |

文字の欄は、199 単位までです（UTF-16）。

## サクラエディタとの違い

- 「使えない」灰色の部品は、このページにはありません。
- 描画の細部（矢印を文字で描くこと、本文を 1 文字ずつ桁に置くこと）は、MATSU Editor の描き方に合わせています。
- スマートインデントと、アウトライン解析の一覧は、プラグインが足した項目も並びます（MATSU Editor のプラグイン）。使えなくなったプラグインの番号は、設定ファイルのまま残し、「（使えないプラグイン N）」と出します。サクラエディタは先頭の項目を見せて、OK で書き換えます。
