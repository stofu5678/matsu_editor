# キーマクロ

キーマクロは、打ったキーやメニューで行った操作を記録して、あとで同じ順に再生する機能です。保存すると、拡張子 `.mac` のテキストファイルになります。

## 操作する場所

メニューの「ツール」にあります。

| メニューの項目 | 既定のキー | 動き |
|---|---|---|
| キーマクロの記録開始／終了 | `Ctrl+Shift+M` | 記録を始める。記録中に使うと、記録を終える |
| キーマクロの保存 | `Ctrl+M` | 記録したキーマクロをファイルに書く |
| キーマクロの読み込み | `Ctrl+L` | 再生するファイルを選ぶ |
| キーマクロの実行 | `Ctrl+Shift+L` | キーマクロを再生する |

機能名は、上から順に `F_RECKEYMACRO`、`F_SAVEKEYMACRO`、`F_LOADKEYMACRO`、`F_EXECKEYMACRO` です。ファイルを選んで `.mac` やほかの言語のマクロを動かすのは、「名前を指定してマクロ実行...」（`F_EXECEXTMACRO`）です。

## 使い方

1. 「キーマクロの記録開始／終了」を選ぶ。記録が始まる
2. 記録したい操作をする
3. もう一度「キーマクロの記録開始／終了」を選ぶ。記録が終わる
4. 「キーマクロの実行」で、記録した操作を再生する
5. 残したいときは「キーマクロの保存」でファイルに書く

記録を終えると、記録した内容は、マクロのフォルダーの `RecKey.mac` に書かれます。マクロのフォルダーは、共通設定の「マクロ」のページの「マクロフォルダー」です。空のときは、設定ファイルがあるフォルダーです。設定ファイルがないときは、ファイルには書かれず、ウィンドウの中だけに残ります。

次に記録を始めると、前の記録は捨てられます。残したいときは、先に保存します。

「保存」と「読み込み」は、記録中なら、先に記録を終えます。

## 何が記録されるか

- 打った文字は、1 文字ずつ `Char(文字コード)` として記録されます。IME で確定した文字も、1 文字ずつです
- カーソルの移動、選択、削除、貼り付け、検索、置換、大文字小文字の変換など、編集の操作は記録されます
- ファイルを開く・保存する・閉じる、印刷、ウィンドウの操作などは、記録されません。何が記録されるかは、「マクロの関数」の表の「キーマクロに記録」の列にあります（サクラの表と同じです）
- 値を返す関数（`GetLineStr` など）は、キーマクロには記録されません
- ほかのマクロファイルを動かす操作は、`ExecExternalMacro(...)` の 1 行として記録されます。再生すると、そのファイルが動きます

## 再生

- 記録した操作を、1 つずつ順に動かします
- 操作の 1 つ 1 つが、元に戻す操作の 1 回分になります
- 途中で失敗した操作があると、そこで止まります
- 「キーマクロの読み込み」は、ファイル名を覚えるだけです。ファイルは、再生するときに読みます。`.mac` 以外のマクロのファイルも選べます
- 再生するファイルの名前は、すべてのウィンドウで共有します。設定ファイルには書かないので、起動し直すと、選び直しが要ります（`RecKey.mac` は残っています）

## ファイルの形

テキストファイルで、1 行に 1 つの操作を書きます。自分で書いたり、直したりできます。

保存したファイルは、BOM 付きの UTF-8 で、改行は CR LF です。1 行目は `//キーボードマクロのファイル` というコメントです。操作の行の終わりには、タブで区切った、機能の名前のコメントが付きます。

```
//キーボードマクロのファイル
GoFileTop();	// ファイルの先頭に移動
InsText('Memo\n');	// テキストを貼り付け
Up();	// カーソル上移動
SelectLine(0);	// 1行選択
ToUpper();	// 大文字
```

上の例は、文書の先頭に `Memo` の行を足し、その行を大文字にします。コメントは、保存するときに機能の表示名が付くものです。手で書くときは、なくてかまいません。

書き方の決まりです。

- 空の行と、`//` で始まる行は読み飛ばします
- `名前(引数, 引数, ...);` の形です。名前は、マクロの関数の名前です。先頭に `S_` を付けても読めます
- 引数は、数か文字列です。数は 32 ビットの整数に収まる必要があります。文字列は `'` か `"` で囲みます
- 文字列の中では、`\\` `\'` `\"` `\r` `\n` `\t` と、`\uXXXX`（16 進数の 1〜4 桁）が使えます
- 関数が取る引数の型と違うものを書くと、エラーです。引数は 4 つまで書けます（関数がそれより多く取るときは、その数まで）
- `)` のあとに書いたものは、読み飛ばします（`;` やコメントが書けます）
- 値を返す関数のうち `ChangeTabWidth`、`ChangeWrapColm`（`ChangeWrapColumn`）、`ChangeInsertSpace`、`SetDrawSwitch`、`Sleep`、メッセージの箱（`MessageBox`、`ErrorMsg`、`WarnMsg`、`InfoMsg`、`OkCancelBox`、`YesNoBox`）は、文として書けます。返す値は捨てます
- BOM のないファイルは、UTF-8 に見えても Shift_JIS として読みます。日本語を使うときは、BOM 付きの UTF-8 で保存してください

ファイルは再生のときに読みます。エラーがあると、行と桁（わかるときだけ）を示して、そこで読むのをやめます。

## サクラエディタとの違い

- 打った文字の記録は、コードポイントです。サクラは UTF-16 の単位で記録するので、絵文字のように 2 単位の文字は、サクラでは 2 行、MATSU Editor では 1 行です。サクラが書いた 2 行のファイルを MATSU Editor で再生すると、2 行目が引数の間違いになります
- ファイルの中のエラーは、最初の 1 つで止めます。サクラは、エラーごとに箱を出して、最後まで読みます
- 記録を終えたとき、マクロのフォルダーが空なら、設定ファイルのあるフォルダーに `RecKey.mac` を書きます。サクラは、空のときカレントフォルダーに書きます
- 記録できる操作と、ファイルの形は、サクラに合わせています

## 根拠

- サクラのソース: `sakura_core/macro/CKeyMacroMgr.cpp`（`LoadKeyMacro`、`SaveKeyMacro`、`ExecKeyMacro`）、`sakura_core/macro/CMacro.cpp`（`Save`）、`sakura_core/macro/CSMacroMgr.cpp`（`CanFuncIsKeyMacro`）、`sakura_core/cmd/CViewCommander_Macro.cpp`、`sakura_core/io/CTextStream.cpp`
- MATSU のコード: `crates/matsu-commands/src/key_macro.rs`（ファイルの形、読み込み、再生、記録）、`crates/matsu-commands/src/sakura/macro_functions.rs`（`key_macro` の列）
- 画面側: `crates/matsu-ui/src/macros/mod.rs`（`stop_key_macro_recording`、`CurrentMacro`）、`crates/matsu-ui/src/macros/statements.rs`（文として書ける関数）、`crates/matsu-ui/src/ui_commands/macros/rec_key_macro.rs`
- 既定のキー: `crates/matsu-commands/src/sakura/key_bindings.rs`（`M` と `L` の行）
- メニュー: `crates/matsu-commands/src/sakura/main_menu.rs`（「ツール」）
- 試験: `crates/matsu-commands/src/key_macro/tests.rs`、`crates/matsu-ui/src/macros/tests.rs`
