# マクロの関数（4）: ExpandParameter

文字列の中の `$` で始まる記号を、ファイル名、キャレットの位置、条件による選択などに置き換えた文字列を返す関数です。共通の決まりは[この章の最初](index.md)にあります。

| マクロ名 | 引数 | 戻り値 | 動き | キーマクロに記録 | MATSU での違い |
|---|---|---|---|---|---|
| `ExpandParameter` | 1 書式（文字列） | 文字列 | 書式の中の記号を置き換えて返す。記号でない文字は、そのまま写す | しない | `$p` `$P` は、いつも印刷プレビュー用の文字列（下の「印刷のページ」） |

## 結果の長さ

- 結果は、UTF-16 の単位で 2047 までです。超える分は切ります。文字の途中では切りません。
- 書式の最後が `$` 1 文字のときは、その `$` を結果に残します。
- 展開は、ウィンドウのタイトルやタブ、印刷のヘッダーと同じ部品が行います。記号の意味は、どこでも同じです（[特殊文字](../specs-regex/expand-parameter.md)）。

## 使える記号

### ファイル

ファイルのない文書（無題）では、ファイルに関する記号は `(無題)` になります。ただし `$b` は空です。

| 記号 | 置き換わるもの |
|---|---|
| `$F` | 文書のファイルのフルパス |
| `$N` | 共通設定「ファイル名表示」の設定で短くしたフルパス |
| `$f` | ファイル名（フォルダーを除く） |
| `$g` | ファイル名から、最後の拡張子を除いたもの。`.bashrc` のように、先頭が `.` で、ほかに `.` がない名前は、そのまま |
| `$/` | フルパス。Windows では、区切りを `\` から `/` にしたもの |
| `$e` | フォルダー。最後の区切りを含む。フォルダーがない名前（区切りのないもの）は空 |
| `$E` | 「ファイル名表示」の設定で短くしたフォルダー |
| `$b` | 拡張子（`.` を除く）。拡張子がなければ空 |

- パスの区切りは、Windows では `\` と `/`、それ以外の OS では `/` です。

### キャレットと選択

| 記号 | 置き換わるもの |
|---|---|
| `$C` | 選択している文字列の、最初の改行までの部分。選択がなければ、キャレットの位置にある単語。最大 259 文字 |
| `$x` | キャレットのある文書の行の中での位置。UTF-16 の単位で数え、1 から |
| `$y` | キャレットのある文書の行の番号。1 から |

- `$C` は、矩形選択のときは、矩形の最初の行の、矩形に入る部分です。
- `$C` と `$x` は、書式にその記号があるときだけ、文書を読みます。長い選択でも、最初の行に必要なところまでしか読みません。

### 文書と日付

| 記号 | 置き換わるもの |
|---|---|
| `$n` | ファイルのない文書の通し番号（普通のウィンドウだけ。ほかは空） |
| `$B` | 文書タイプの名前（基本のタイプなら空） |
| `$Q` | 文書タイプの印刷設定の名前 |
| `$d` `$t` | 今の日付と時刻（共通設定「書式」の形式） |
| `$D` `$T` | ファイルの更新日と更新時刻。保存していないファイルは `(保存されていません)` |
| `$h` | Grep の検索条件（先頭の 32 文字まで。Grep のウィンドウだけ） |

### 製品とマクロ

| 記号 | 置き換わるもの |
|---|---|
| `$$` | `$` |
| `$A` | 製品の名前。`MATSU Editor` |
| `$V` | MATSU Editor の版 |
| `$S` | 実行しているエディタの実行ファイルのフルパス |
| `$M` | 実行しているマクロのファイルのパス。マクロのファイルがなければ空 |
| `$I` | 設定ファイル（`matsu.ini`）のパス |
| `$<profile>` | プロファイルの名前（既定のプロファイルは空） |

### 条件

`${R?甲$:乙$:丙$}` の形です。`?` の前の 1 文字が条件の種類で、その結果に応じて、`$:` で区切った部分のどれか 1 つを使います。`$}` が終わりです。入れ子にできます。

| 条件 | 部分 1 | 部分 2 | 部分 3 |
|---|---|---|---|
| `${R?` | ビューモード | 上書き禁止（ファイルを書き込めない） | どちらでもないとき |
| `${w?` | Grep のウィンドウ | アウトプットのウィンドウ | 通常のウィンドウ |
| `${M?` | キーマクロを記録している | 記録していない | － |
| `${U?` | 文書を変更している | 変更していない | － |
| `${N?` | 無題 | ファイルがある | － |
| `${I?` | （使われません） | いつもこれ（最小化していない） | － |

- 部分は 1 つ目から数えて、使うものを選びます。表の「部分 1」が、`?` の直後の部分です。
- 部分が足りないときは、何も出しません。
- 条件の種類が上の表にないときは、部分 1 を使います。

## 印刷のページ

`$p` `$P` は、`(印刷プレビューでのみ使用できます)` になります。マクロは、印刷プレビューの中では動かないからです。

## ウィンドウがないとき

ウィンドウのない実行では、`$B` `$Q` `$n` `$h` `$I` `$<profile>` は空、`$D` `$T` は `(保存されていません)`、`${R?}` は部分 3、`${w?}` は部分 3 です。

- `${R?}` の「上書き禁止」は、マクロを始めたときの、ファイルを書き込めるかどうかの状態です。
