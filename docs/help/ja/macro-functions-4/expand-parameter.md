# マクロの関数（4）: ExpandParameter

文字列の中の `$` で始まる記号を、ファイル名、キャレットの位置、条件による選択などに置き換えた文字列を返す関数です。共通の決まりは[この章の最初](index.md)にあります。

| マクロ名 | 引数 | 戻り値 | 動き | キーマクロに記録 | MATSU での違い |
|---|---|---|---|---|---|
| `ExpandParameter` | 1 書式（文字列） | 文字列 | 書式の中の記号を置き換えて返す。記号でない文字は、そのまま写す | しない | 使えない記号がある（下の「使えない記号」） |

## 結果の長さ

- 結果は、UTF-16 の単位で 2047 までです。超える分は切ります。文字の途中では切りません。
- 書式の最後が `$` 1 文字のときは、そこで終わります（`$` は結果に入りません）。

## 使える記号

### ファイル

ファイルのない文書（無題）では、ファイルに関する記号は `(無題)` になります。ただし `$b` は空です。

| 記号 | 置き換わるもの |
|---|---|
| `$F` | 文書のファイルのフルパス |
| `$N` | `$F` と同じ（サクラエディタが持つ、パスを短く見せる設定は、MATSU Editor にはありません） |
| `$f` | ファイル名（フォルダーを除く） |
| `$g` | ファイル名から、最後の拡張子を除いたもの。`.bashrc` のように、先頭が `.` で、ほかに `.` がない名前は、そのまま |
| `$/` | フルパス。区切りを `\` から `/` にしたもの |
| `$e` `$E` | フォルダー。最後の区切り（`\` か `/`）を含む。フォルダーがない名前（区切りのないもの）は空 |
| `$b` | 拡張子（`.` を除く）。拡張子がなければ空 |

- パスの区切りは、`\` と `/` のどちらも区切りとして扱います。サクラエディタは `\` だけです。

### キャレットと選択

| 記号 | 置き換わるもの |
|---|---|
| `$C` | 選択している文字列の、最初の改行までの部分。選択がなければ、キャレットの位置にある単語。最大 259 文字 |
| `$x` | キャレットのある文書の行の中での位置。UTF-16 の単位で数え、1 から |
| `$y` | キャレットのある文書の行の番号。1 から |

- `$C` は、矩形選択のときは、矩形の最初の行の、矩形に入る部分です。
- `$C` と `$x` は、書式にその記号があるときだけ、文書を読みます。長い選択でも、最初の行に必要なところまでしか読みません。

### 製品とマクロ

| 記号 | 置き換わるもの |
|---|---|
| `$$` | `$` |
| `$A` | 製品の名前。`MATSU Editor` |
| `$V` | MATSU Editor の版 |
| `$S` | 実行しているエディタの実行ファイルのフルパス |
| `$M` | 実行しているマクロのファイルのパス。マクロのファイルがなければ空 |

### 条件

`${R?甲$:乙$:丙$}` の形です。`?` の前の 1 文字が条件の種類で、その結果に応じて、`$:` で区切った部分のどれか 1 つを使います。`$}` が終わりです。入れ子にできます。

| 条件 | 部分 1 | 部分 2 | 部分 3 |
|---|---|---|---|
| `${R?` | ビューモード | （使われません） | ビューモードでないとき |
| `${w?` | （使われません） | （使われません） | いつもこれ（通常のウィンドウ） |
| `${M?` | キーマクロを記録している | 記録していない | － |
| `${U?` | 文書を変更している | 変更していない | － |
| `${N?` | 無題 | ファイルがある | － |
| `${I?` | （使われません） | いつもこれ（最小化していない） | － |

- 部分は 1 つ目から数えて、使うものを選びます。表の「部分 1」が、`?` の直後の部分です。
- 部分が足りないときは、何も出しません。
- 条件の種類が上の表にないときは、部分 1 を使います。

## 使えない記号

次の記号は、置き換えずに、書いたまま結果に残ります（サクラエディタも、知らない記号を書いたまま残します）。

| 記号 | サクラエディタでの置き換え先 | MATSU Editor |
|---|---|---|
| `$d` `$t` `$D` `$T` | 日付と時刻 | 未対応 |
| `$B` | 文書タイプの名前 | 未対応 |
| `$Q` | 印刷の設定の名前 | 未対応 |
| `$I` | 設定ファイルのパス | 未対応 |

次の記号は、MATSU Editor では、いつも空か、決まった文字列になります。

| 記号 | 結果 | 理由 |
|---|---|---|
| `$n` | 空 | 無題のウィンドウの番号の仕組みがない |
| `$h` | 空 | Grep のウィンドウがない |
| `$<profile>` | 空 | プロファイル名がない |
| `$p` `$P` | `(印刷プレビューでのみ使用できます)` | マクロは、印刷プレビューの中では動かないので、プレビュー以外のときの文字列になる |

- `${R?}` は、読み取り専用のファイルかどうかを調べないので、ビューモードのとき以外は、部分 3 です。サクラエディタは、ファイルの読み取り専用の属性を見ます。
