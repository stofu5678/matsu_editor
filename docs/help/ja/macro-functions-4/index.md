# マクロの関数（4）

この章は、マクロから呼べる関数のうち、値を返す 62 個を、種類ごとのページにまとめたものです。全部で 4 つの章に分かれています。

- マクロの関数（1）: ファイル、編集、カーソル移動、スクロール
- マクロの関数（2）: 選択、矩形選択、クリップボード、挿入、変換
- マクロの関数（3）: 検索、モード、設定、マクロ、ウィンドウ、サポート、カスタムメニュー、MATSU Editor だけの関数
- マクロの関数（4）: この章。値を返す関数

マクロの書き方、言語ごとの呼び方（返った値の受け取り方）、キーマクロの記録は、「マクロの使い方」の章にあります。ここでは繰り返しません。

## 表の読み方

どの表も、次の列を持ちます。

| 列 | 内容 |
|---|---|
| マクロ名 | マクロが呼ぶ名前。同じ関数の別の名前は、同じ行に並べます |
| 引数 | 引数の型と意味。「数」は整数、「文字列」は文字列です。`?` が付いた引数は省けます |
| 戻り値 | 返る値の型と意味 |
| 動き | 1 行の説明 |
| キーマクロに記録 | キーマクロの記録中に呼んだとき、記録に残るかどうか |
| MATSU での違い | サクラエディタと違うところ、気を付けること |

メニューやキーから使う操作の説明は、「コマンド: ファイル」「コマンド: 編集」などの章にあります。

## 共通の決まり

### 戻り値

- 戻り値の型は、数か文字列のどちらかです。表の「戻り値」に書きました。
- 「真偽」を返す関数も、数で返します。1 が「はい」、0 が「いいえ」です。
- 値を返さない関数は、「マクロの関数（1）」から「マクロの関数（3）」にあります。

### 引数

- 引数の数は、表の数より多くできません。省けない引数が足りないときも、多いときも、引数の誤りのエラーになります。
- 型が違っても、引数の誤りのエラーになります。数の引数に文字列を渡したとき、またその逆のときです。
- 数の引数に、64 ビット整数に入らない大きな数を渡しても、引数の誤りのエラーです（0 には変わりません）。

### キーマクロ

- 値を返す関数は、どれも、キーマクロの記録に残りません。
- キーマクロのファイル（`.mac`）に、文として書くことはできます。ただし、効くのは次の 12 の名前（11 の関数）の呼び出しだけです。返った値は捨てます。
  - `ChangeTabWidth`
  - `ChangeWrapColm`、`ChangeWrapColumn`
  - `ChangeInsertSpace`
  - `SetDrawSwitch`
  - `Sleep`
  - `MessageBox`、`ErrorMsg`、`WarnMsg`、`InfoMsg`、`OkCancelBox`、`YesNoBox`
- これ以外の関数を文に書いても、何も起きません（エラーにもなりません）。

### ウィンドウのないとき

画面を持たない形でマクロを動かしたときは、ダイアログを開く関数、`Sleep`、表示領域の大きさを読む関数、文字コードを読む関数などが、「ここでは使えない」というエラーを返します。表には、ウィンドウが要る関数を書き分けていません。ウィンドウのあるエディタから動かす限り、起きません。

### 巨大なファイル

折り返しを背景で計算している巨大な文書では、折り返しの行を数える関数（選択の位置、行・桁の換算）を呼ぶ前に、レイアウトを最後まで計算します。呼び出しは、その分だけ待たされます。
