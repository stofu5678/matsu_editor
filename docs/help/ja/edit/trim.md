# 左右の空白の削除

選んだ行の、行頭の空白、または行末の空白を取ります。「編集」→「整形」にあります。

| 機能名 | メニュー | キー | マクロ | 取るもの |
|---|---|---|---|---|
| `F_LTRIM` | 左(先頭)の空白を削除 | `Alt+L` | `LTrim()` | 行頭の空白 |
| `F_RTRIM` | 右(末尾)の空白を削除 | `Alt+R` | `RTrim()` | 行末の空白 |

## 動き

- ここでの空白は、半角の空白、TAB、全角の空白（U+3000）です。
- 選択の最初の行と最後の行は、選んだ部分だけが対象です。つまり、行の途中から選び始めると、「左の空白を削除」は、選び始めたところの空白を取ります（「右の空白を削除」は、選び終わったところ）。
- 選択がないときは、カーソルのある行が対象です。取ったあと、カーソルはその行の終わりに行きます。
- 選択があるときは、取ったあとの文字が選ばれ、カーソルが終わりに行きます。
- 取るものがないときは、何も編集しません（選択とカーソルは、取ったときと同じように動きます）。

## 矩形選択のとき

矩形の各行について、矩形に含まれる部分の行頭（または行末）の空白を取ります。取ったあと、矩形は外れ、カーソルは矩形の左上の角に行きます。

## サクラエディタとの違い

取るものがないとき、サクラエディタは文字を置き換える編集をしますが、MATSU Editor は編集しません（選択とカーソルの動きは同じです）。

## 根拠

- サクラのソース: `sakura_core/cmd/CViewCommander_Edit_advanced.cpp` の `Command_TRIM`、`sakura_core/view/CEditView.cpp` の `ConvSelectedArea`、`sakura_core/convert/CConvert_Trim.cpp` の `CConvert_Trim::DoConvert`
- MATSU のコード: `crates/matsu-commands/src/commands/edit/ltrim.rs`、`rtrim.rs`（先頭のコメント）
- 試験: 同じ 2 つのファイルの `tests` モジュール
- キー: `crates/matsu-commands/src/sakura/key_bindings.rs`（`L`、`R` の行）
