# 指定行へジャンプ

行番号を決めて、その行へ動きます。

## 呼び出し方

- メニュー: 「編集」→「移動」→「指定行へジャンプ...」
- キー: `Ctrl+J`
- マクロ: `Jump(行番号, オプション)`（ダイアログを開くマクロはありません）
- 機能名: `F_JUMP_DIALOG`（ダイアログを開く）、`F_JUMP`（行へ動く）

## 行番号の入力欄（パネル）

「指定行へジャンプ」を選ぶと、行番号を入れる小さなパネルが開きます。入れた番号で、`F_JUMP` と同じ動きをします。

- 行は、改行で区切った行として数えます。
- サクラエディタのダイアログにある「折り返し単位」の選択は、まだありません。

## 動き（`Jump` マクロ）

- 行番号が 1 より小さいときは先頭の行へ、最後の行より大きいときは最後の行へ動きます。
- カーソルは、その行の先頭に行きます。動く前の位置は、[移動履歴](jump-history.md)に登録されます。
- 「範囲選択開始」で選択を固定している間は、選択がカーソルについていきます。固定していなければ、選択は外れます。

### オプション

`オプション` は、次の値を足したものです。省略すると 1 です。

| 値 | 意味 |
|---|---|
| `0x01` | 行番号を、改行で区切った行として数える。付けないと、折り返し表示の画面の行として数える |
| `0x02` | PL/SQL の行番号として数える。ソースの先頭から、有効な行だけを数える |

`0x02` の「有効な行」には、決まりがあります。

- 最初の行から始まる `/* */` コメントは、数えません。
- 空の行は、有効な行ではありません。`/* */` コメントの中の空の行も同じです。
- `--` で始まるコメントの行と、`/* */` を含む行は、有効な行です。
- 引用符の中の文字は、行末をまたいで続きます。
- サクラエディタのダイアログには、数え始める行を選ぶ欄があります。MATSU Editor のパネルにはなく、マクロでも選べません。先頭の行から数えます。
