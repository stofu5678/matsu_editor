# 連続した重複行の削除(uniq)

選んだ行のうち、直前の行と同じ行を取り除きます。UNIX の `uniq` と同じ考え方です。「編集」→「整形」にあります。

## 呼び出し方

- メニュー: 「編集」→「整形」→「連続した重複行の削除(uniq)」
- キー: `Alt+M`
- マクロ: `Merge()`
- 機能名: `F_MERGE`

## 動き

- 対象の行は、[選択行のソート](sort.md)と同じです（選択の始まりの行から終わりの行まで。改行のない最後の行は触りません）。
- 同じかどうかは、改行まで含めて比べます。離れた場所にある同じ行は、取り除かれません。先に[ソート](sort.md)すると、同じ行が並びます。
- 取り除いたあと、残った行が、先頭から次の行の先頭まで選ばれます。カーソルは、もとの最初の行にあったときは先頭に、そうでなければ終わりに行きます。
- 選択がないとき、または対象の行がないときは、何も起きません。矩形選択のときも、何もせず、警告音も鳴りません。
- 行を調べたときは、メッセージボックスに、取り除いた行の数、または取り除くものがなかったことが出ます。マクロの実行中にも出ます。
