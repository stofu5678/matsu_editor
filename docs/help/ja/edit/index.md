# コマンド: 編集

メニューバーの「編集」にある機能の説明です。メニューの並びは、サクラエディタの既定のメニューに、MATSU Editor が足した項目（「LF改行でコピー」「CR改行でコピー」）を加えたものです。メニューの内容は、「共通設定」の「メインメニュー」で変えられます。ここでは、既定のメニューの順に説明します。

小さな機能が多いので、似た機能は 1 ページにまとめ、表にしました。

## キーについて

ページに書いたキーは、Windows と Linux の既定の割り当てです。macOS では、`Control` がサクラエディタの `Ctrl`、`Option` が `Alt` にあたります。`Cmd+C`、`Cmd+V`、`Cmd+X`、`Cmd+Z`、`Cmd+A`、`Cmd+Shift+Z`（やり直し）も使えます。くわしくは `docs/adr/0008-commands-and-keybindings.md` にあります。キー割り当ては、共通設定の「キー割り当て」で変えられます。

## すべてに共通すること

- ビューモード（読み取り専用）では、文書を変える機能は、警告音が鳴るだけで何もしません。「元に戻す」と「やり直し」も同じです。コピーなど、文書を変えない機能は使えます。
- 矩形選択に対応していない機能は、矩形が何かを選んでいるとき（または矩形の角が行の終わりより右にあるとき）、警告音が鳴って何もしません。矩形選択のときの動きは、機能ごとのページに書いてあります。

## 根拠

- メニューの並び: `crates/matsu-commands/src/sakura/main_menu.rs`（サクラエディタの `MainMenu.ini` から作った表）、MATSU が足した項目は `crates/matsu-config/src/settings/main_menu.rs` の `MATSU_ADDITIONS`
- 機能名、マクロ名、既定のキー: `crates/matsu-commands/src/sakura/functions.rs`、`macro_functions.rs`、`key_bindings.rs`
- 実装: `crates/matsu-commands/src/commands/`（`edit/`、`clipboard/`、`cursor/`、`select/`、`box_select/`、`insert/`）、`crates/matsu-ui/src/ui_commands/`
