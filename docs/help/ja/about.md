# このヘルプについて

このヘルプは、MATSU Editor（マツエディタ）の使い方を説明するものです。MATSU Editor は、サクラエディタの操作感を macOS・Windows・Linux で再現するテキストエディタです。

## ライセンス

このヘルプの文章と、ヘルプに載せたサンプルのコードは、MATSU Editor のプログラムと同じ、MIT License または Apache License 2.0 の好きな方の条件で使えます（`MIT OR Apache-2.0`）。ライセンスの全文は、リポジトリの `LICENSE-MIT` と `LICENSE-APACHE` にあります。

## サクラエディタのヘルプとの関係

サクラエディタのヘルプは、GNU Free Documentation License 1.1 以降の条件で公開されています。MATSU Editor のヘルプは、その文章を写していません。言い換えて写してもいません。

このヘルプは、MATSU Editor 自身の動きから書いています。動きの根拠は、MATSU Editor のプログラムと試験、サクラエディタのソースコード（zlib License）、実際にサクラエディタを動かして確かめた結果です。各ページの終わりの「根拠」に、その場所を書いています。

メニューの名前、機能の名前、マクロの関数の名前、設定の項目の名前は、サクラエディタを使ってきた人が探せるように、サクラエディタと同じにしています。名前は文章ではないので、同じにしても問題ありません。

サクラエディタと動きが違うところは、ページの中で書いています。
