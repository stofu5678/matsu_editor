# 外部コマンド実行

コマンドラインを 1 行入力して実行します。コマンドの出力を、アウトプットか編集中の文書に入れられます。選んでいる文字列（なければ文書全体）を、コマンドの標準入力に渡すこともできます。`sort` や `grep` のような、文字列を加工するコマンドと相性がよい機能です。

- メニュー: 「ツール」→「外部コマンド実行...」
- 既定のキー: `Ctrl+F5`
- 機能: `F_EXECMD_DIALOG`
- ダイアログを出さずに実行するマクロは [外部コマンド実行のマクロ（ExecCommand）](exec-command-macro.md) に書いています

## 使い方

1. 「ツール」→「外部コマンド実行...」を選びます。ダイアログが開きます。
2. 「名前」に、実行するコマンドラインを入れます。前回のコマンドが、はじめから入っています。
3. 必要なら、下の選択肢を変えます。
4. 「実行(E)」を押します。

「キャンセル(X)」か `Esc` で、何も実行せずに閉じます。

## ダイアログの項目

| 項目 | 何をするか |
|---|---|
| 名前 | 実行するコマンドラインです。右の「履歴」で、実行したコマンドの一覧が開きます。「...」で、プログラムのファイルを選べます（空白を含む名前は、`"` で囲んで入ります） |
| 標準出力を得る(S) | チェックを入れると、コマンドの出力を受け取り、終わるまで待ちます。右のボタンは出力の文字コードで、押すたびに Shift_JIS、Unicode、UTF-8 と替わります |
| 標準出力リダイレクト先 | 出力の行き先です。「アウトプットウィンドウ(O)」か「編集中のウィンドウ(C)」。「標準出力を得る」を切ると、どちらも選べません |
| 標準入力に送る(I) | チェックを入れると、選んでいる文字列を標準入力に送ります。何も選んでいなければ文書全体を送ります。右のボタンは、送る文字コードです |
| カレントディレクトリ(R) | チェックを入れると、下の欄のフォルダでコマンドを動かします。「履歴」と「...」（フォルダ選び）は、チェックを入れたときだけ使えます |

はじめの状態は「標準出力を得る」だけが入った形です。2 回目からは、前回に選んだ形で開きます。

文字コードの既定は、出力も入力も Shift_JIS です。macOS や Linux で、UTF-8 を出すコマンドを使うときは、UTF-8 に替えてください。

文書が読み取り専用（ビューモード）のときは、「編集中のウィンドウ」は選べません。出力はアウトプットに入ります。

### コマンドラインの `$` の記号

実行の前に、コマンドラインの `$F` は、編集中のファイルの名前に替わります。`$$` は `$` 1 文字になります。ダイアログの注にもこの 2 つが書いてあります。ほかの記号も、マクロの `ExpandParameter` と同じに替わります。一覧は「仕様等と正規表現」の章にあります。

替えたあとのコマンドラインは、1024 文字（UTF-16 の単位）までです。それより長い部分は切られます。

## 動き

### どこで動くか

- フォルダを指定しなければ、編集中のファイルのあるフォルダで動きます。ファイルのない文書では、MATSU Editor を起動したフォルダです。
- コマンドは、まずプログラムとして直接起動します。
  - Windows では、直接起動できなければ `cmd.exe /C` に渡します。
  - macOS と Linux では、`|` `>` `&` `;` `$` や引用符のような、シェルが意味を持たせる文字が 1 つでもあれば、はじめから `/bin/sh -c` に渡します。それがなければ、空白で区切ってプログラムを直接起動します。
- 標準出力と標準エラーは、書かれた順の 1 本にまとまって届きます。

### 「標準出力を得る」を切ったとき

起動したら、すぐに戻ります。終わるのを待たず、出力も受け取りません。Windows では、コマンドは自分のコンソールで動きます（`cmd.exe /K`）。

### 出力をアウトプットに入れるとき

- 出力は、受け取るたびに追加されます。
- 「実行中」の小さな箱が、画面の右下に出ます。箱の中の「キャンセル(X)」を押すと、コマンドと、そのコマンドが起こした子のプロセスを止めます。
- 前後に、次の情報が入ります。

  ```text
  #============================================================
  #DateTime : （日付） （時刻）
  #CmdLine  : （実行したコマンドライン）
  #============================================================
  （出力）
  終了コード: 0
  ```

  止めたときは「中断しました。」の行も入ります。

### 出力を編集中の文書に入れるとき

- 出力は、キャレットの位置に入ります。
- 画面全体を覆う「コマンド実行中・・・」の箱が出て、終わるまでキー入力は文書に届きません。`Esc` か「キャンセル(X)」で止められます。
- 出力の挿入は、全体で「元に戻す」1 回で戻ります。
- 前後の情報（上の `#====` の行や終了コード）は、既定では入りません。マクロの選択肢で入れられます（[外部コマンド実行のマクロ](exec-command-macro.md)）。
- 選択の扱いは、次のとおりです。

  | 状態 | 動き |
  |---|---|
  | 何かを選んでいて、標準入力に送る | 選んだ範囲を送り、出力で置き換えます。入った出力は、選んだ状態になります |
  | 何も選んでいなくて、標準入力に送る | 文書全体を送り、出力で文書全体を置き換えます |
  | 何かを選んでいて、標準入力に送らない | 選んだ範囲を、出力で置き換えます。出力が空なら、選択はそのままです |
  | 何も選んでいなくて、標準入力に送らない | キャレットの位置に出力を入れます |
  | 矩形選択 | 矩形の中身を送り、矩形は消して、出力をキャレットの位置に 1 度で入れます |

### 標準入力へ送る文字

- 文書は、行ごとに読みながら、小さな塊にして送ります。巨大な文書でも、全文を 1 つの文字列にはしません。
- 送る文字コードで書けない文字は `?` になります。
- 文書に BOM があれば、UTF-8 と Unicode では、先頭に BOM を付けて送ります。
- 出力の先頭にある BOM は、文字として入れません。

### 同時に動かすのは 1 つ

出力を受け取るコマンドは、1 つの窓で 1 つずつ動かします。動いている間にもう 1 つ実行しようとすると、「別のコマンドを実行中です。終了してから実行してください。」と出て、実行されません。

### 実行できなかったとき

コマンドを起動できないと、「コマンド実行は失敗しました。」の文に、コマンドラインと、OS が返した理由を付けて、箱で知らせます。シェルが「見つからない」と言ったときは、その文が出力として入ります。

## 覚えておくこと

実行したコマンドとフォルダは、履歴に入ります。

- 数は、それぞれ 32 件までです。新しい順に並び、同じものは 1 つにまとまります。
- 長さは、コマンドが 1023 文字（UTF-16 の単位）まで、フォルダが 259 文字までです。それより長いものは覚えません。空のものも覚えません。
- 「実行(E)」を押したときの選択肢（文字コード、行き先、チェックの状態）も覚えて、次に開くときの初期値にします。
- 保存先は `matsu.ini` の `[Cmd]` 節（`szCmdArr[00]`、`nCmdArrNum`、`szCurDirArr[00]`、`nCurDirArrNum`）と、`[Other]` 節の `nExecFlgOpt` です。数の意味は、マクロのページの表にあります。

マクロで実行しても、履歴は変わりません。ダイアログから実行したときだけ覚えます。

## キーマクロとの関係

ダイアログから実行すると、キーマクロの記録には、ダイアログの中身ではなく、実行したコマンドと選択肢が `ExecCommand` の呼び出しとして記録されます。再生すると、ダイアログは出ずに、同じ実行をします。

## サクラエディタとの違い

動きはサクラエディタに合わせてありますが、次の点が違います。

- コマンドは裏で動きます。実行中でも、ウィンドウの描画と操作は止まりません。出力を文書に入れるときだけ、箱が画面を覆ってキーを止めます。
- 標準入力は、一時ファイルにしません。文書を行ごとに読みながら送ります。
- 出力全体が「元に戻す」1 回です。サクラエディタは、受け取った塊ごとに別々に入れます。
- 出力の前後の情報の改行は、文書の改行コードに合わせます（サクラエディタは常に CR LF です）。
- 「中断」は、コマンドが起こした子のプロセスもまとめて止めます。サクラエディタは、最初のプロセスだけを止めます。
- 2 つ同時には動かしません（上の「同時に動かすのは 1 つ」）。サクラエディタは、実行中の箱が操作を止めるので、同時には動かせません。
- macOS と Linux では、コマンドの渡し先が `/bin/sh -c` です（Windows の `cmd.exe /C` に当たります）。
- ダイアログの 2 つの選択ボックスは、MATSU Editor では、テキスト欄と「履歴」ボタンです。文字コードは、ボタンで順に替えます。
- ダイアログのヘルプのボタンは、まだありません。
