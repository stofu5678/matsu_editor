# カスタムメニュー

好きな機能を並べた、自分用のポップアップメニューです。メニューは 25 個まで作れます。キー、マウス、または「ツール」メニューから開きます。

- メニュー: 「ツール」→「カスタムメニュー」の中に、作ってあるメニューの名前が並びます
- 機能: `F_CUSTMENU_1` から `F_CUSTMENU_24`（番号 1 から 24）と、`F_MENU_RBUTTON`（番号 0、右クリックメニュー）
- マクロの名前: `CustMenu1` から `CustMenu24`、右クリックメニューは `RMenu`

## メニューの番号

| 番号 | 何のメニューか | 開く機能 |
|---|---|---|
| 0 | 右クリックメニュー。文書の上で右クリックすると開きます | `F_MENU_RBUTTON` |
| 1 から 23 | 自由に使えるカスタムメニュー | `F_CUSTMENU_1` から `F_CUSTMENU_23` |
| 24 | タブバーの上で右クリックしたときのメニュー（タブメニュー） | `F_CUSTMENU_24` |

番号 24 のメニューは、キーでも開けます（`F_CUSTMENU_24`）。

## 開き方

### キー

既定のキー割り当ては、次のとおりです。

| キー | 開くメニュー |
|---|---|
| `Alt+1` から `Alt+9`、`Alt+0` | 1 から 9、10 |
| `Alt+Shift+1` から `Alt+Shift+9`、`Alt+Shift+0` | 11 から 19、20 |
| `Ctrl+Shift+1` から `Ctrl+Shift+4` | 21 から 24 |

右クリックメニューは、アプリケーションキー（メニューキー）でも開けます。割り当ては、共通設定の「キー割り当て」で変えられます。

### 「ツール」メニューから

「ツール」→「カスタムメニュー」を開くと、項目のあるメニューが、名前で並びます。右クリックメニュー（番号 0）が先頭です。選ぶと、そのメニューが開きます。

### マクロから

`CustMenu1` から `CustMenu24`、右クリックメニューは `RMenu` を呼びます。キーマクロには記録されません。

## どこに開くか

ポップアップは、マウスポインタの位置の、少し（4 ピクセル）上に開きます。キーで開いたときも、そのときのマウスポインタの位置です。窓の外に出るときは、窓の中に収まるように寄せます。

右クリックでは、クリックした位置です。ただし、クリックした位置が選択範囲の外なら、キャレットを先にそこへ動かします。選択範囲の中なら、選択を残したままです（切り取りやコピーを、そのまま使えるようにするためです）。

## メニューの中身

1 つのメニューには、最大 48 個の項目を入れられます。項目は、次のどれかです。

- 機能。名前は、メニューや「コマンド一覧」と同じです。キー割り当てがあれば、名前の右に出ます。
- 区切り線。
- ほかのカスタムメニュー。その相手の「サブメニューとして表示」が入っていれば、サブメニューになります。入っていなければ、ただの項目で、選ぶとその相手のメニューを開きます。同じメニューが、自分の中にもう開いているときも、ただの項目になります。
- 実行時に中身が決まる一覧。最近のファイル、登録済みマクロ、カスタムメニューの一覧などです。中身がなければ「(なし)」が灰色で出ます。
- 「ワンライナー」（MATSU Editor だけ）。登録したワンライナーの一覧、「ワンライナーを入力して実行...」、「ワンライナーの設定...」のサブメニューになります。

実行できない機能（このバージョンにまだないもの）は、灰色で出ます。項目のない、空のメニューを開いても、何も出ません。メニューの項目を選ぶと、メインメニューの項目と同じに実行します。キーマクロも、同じに記録します。

項目の名前には、アクセスキーを付けられます。ポップアップが開いているときに、その文字のキーを押すと、項目が動きます。同じ文字が複数あるときは、押すたびに次の項目へ進みます。「アクセスキーを必ず( )付で表示」の設定に従って、名前の後ろに `(F)` のように付けて見せます。

### 右クリックメニューだけの項目

右クリックメニューには、メニューの項目のほかに、キーワードヘルプの項目が出ることがあります。メニューが空でも、キーワードヘルプの項目があれば、メニューは開きます。

## メニューを作る・変える

共通設定の「カスタムメニュー」ページで編集します。

- 25 個のメニューから 1 つを選び、名前（32 文字まで）と「サブメニューとして表示」を決めます。
- 機能を選んで、メニューの項目に足します。区切り線、並べ替え、削除もできます。項目ごとにアクセスキーを付けられます。
- 「エクスポート」で、メニューを `.mnu` ファイルに書き出せます。「インポート」で、読み込めます。`.mnu` ファイルは、サクラエディタの `.mnu` と同じ形式です。違う版の形式のファイルは、読み込めません。
- 「OK」を押すと、開いているすべての窓のメニューが、すぐに変わります。

ページの項目の説明は、「コマンド: 設定（共通設定）」の章にあります。

メニューは、`matsu.ini` の `[CustMenu]` 節に保存されます。

### MATSU Editor が足す項目

右クリックメニューには、MATSU Editor だけの項目（選んだ文字列のエンコードとデコード、ワンライナー）が入っています。これらは、MATSU Editor の新しい版で増えたときに、保存してある右クリックメニューへ、1 度だけ足されます。足したかどうかは、`[CustMenu]` 節の `nMatsuCustomMenuVer` に記録します。足されたものは、あとから自分で削除できます。サクラエディタは、このキーを読みません。

## サクラエディタとの違い

- ポップアップは、GPUI のポップアップで描きます。アクセスキーの下線は引けないので、名前の後ろに `(F)` を付けて見せます。
- 「ワンライナー」のサブメニューと、右クリックメニューの MATSU Editor だけの項目は、MATSU Editor にしかありません。

## 根拠

- サクラのソース: `sakura_core/view/CEditView.cpp` の `CreatePopUpMenuSub`、`sakura_core/cmd/CViewCommander_CustMenu.cpp`、`sakura_core/view/CEditView_Mouse.cpp` の `OnRBUTTONDOWN` と `OnRBUTTONUP`、`sakura_core/window/CEditWnd.cpp` の `InitMenu_Special`、`sakura_core/func/CKeyBind.cpp`（既定のキー）
- MATSU のコード:
  - `crates/matsu-ui/src/custom_menu/mod.rs`、`model.rs`（項目の組み立て）、`popup.rs`（開く位置、アクセスキー）、`mouse.rs`（右クリック）
  - `crates/matsu-ui/src/ui_commands/custom_menu/`（`F_CUSTMENU_1` などの命令）
  - `crates/matsu-ui/src/tabs/bar.rs`（タブメニューは番号 24）
  - `crates/matsu-config/src/settings/custom_menu.rs`（25 個、48 項目、32 文字、`[CustMenu]`、`.mnu`、`nMatsuCustomMenuVer`）
  - `crates/matsu-ui/src/common_settings/pages/custom_menu.rs`（編集のページ）
  - `crates/matsu-commands/src/sakura/key_bindings.rs`（`Alt+数字` ほか）、`macro_functions.rs`（`CustMenu1` ほか）
- 試験: `crates/matsu-ui/src/custom_menu/tests.rs`
