# 入力補完

キャレットの前にある言葉の書きかけから、候補を探して一覧に出します。選ぶと、書きかけの言葉が、選んだ候補に替わります。長い名前を、何度も打たずに済みます。

- メニュー: 「ツール」→「入力補完」
- 既定のキー: `Ctrl+Space`
- 機能: `F_HOKAN`
- マクロの名前: `Complete`

## 使い方

1. 言葉の途中まで打ちます。たとえば `Ap` と打ちます。
2. `Ctrl+Space` を押します。
3. 候補の一覧が、その言葉の始まりの下に出ます。先頭の候補が選ばれています。
4. 候補を選んで決めます。書きかけの `Ap` が、たとえば `apple` に替わります。

### 候補が 1 つか 0 のとき

| 候補の数 | 動き |
|---|---|
| 0 | 何も出しません |
| 1 | 一覧は出さず、その候補にすぐ替えます |
| 2 以上 | 一覧を出します |

キャレットの前に言葉がないとき（行の頭や、空白の直後）は、ステータスバーに「補完対象がありません」と出ます。

## 一覧の操作

| 操作 | 動き |
|---|---|
| `↑` `↓` | 1 つ上、1 つ下の候補を選びます。端で止まります（回り込みません） |
| `PageUp` `PageDown` | 10 件ずつ動きます |
| `Home` `End` | 先頭、末尾の候補を選びます |
| `Enter` | 選んでいる候補に決めます（既定で有効） |
| `→` | 選んでいる候補に決めます（既定で有効） |
| `Tab` | 選んでいる候補に決めます。ただし、設定で入れたときだけです（既定は切れています） |
| `Esc` | 一覧を閉じます |
| クリック | 候補を選びます |
| ダブルクリック | 候補に決めます |

一覧は、一度に 10 件を見せます。それ以上は、キーでスクロールします。

「決める」キーの組み合わせは、共通設定の「支援」ページの「候補決定キー」（`Enter`、`Tab`、`→`）で変えられます。`matsu.ini` では `bHokanKey_RETURN`、`bHokanKey_TAB`、`bHokanKey_RIGHT` です。既定は `Enter` と `→` が入り、`Tab` が切れています。

上の表にないキーは、そのまま文書への入力になります。

### 打ちながら絞り込む

一覧を出したまま文字を打つか、`Backspace` を押すと、一覧は新しい言葉に合わせて絞り込まれます。候補が 1 つもなくなったり、言葉がなくなったりすると、一覧は閉じます。

ほかのコマンドを実行したとき、クリックしたとき、キャレットを動かしたときは、一覧は閉じます。

### 決めたとき

書きかけの言葉を消して、候補を入れます。「元に戻す」1 回で戻ります。候補の大文字小文字がそのまま入ります（`Ap` と打って `apple` を選べば `apple` になります）。

### キーワードヘルプの意味

選んでいる候補に、キーワードヘルプの辞書で見つかる意味があれば、一覧の横に表示します。辞書は、タイプ別設定の「キーワードヘルプ」ページで決めます。

## 候補はどこから来るか

候補は、次の順に集めます。同じ言葉は 1 つにまとめます。

1. 単語ファイル
2. 編集中の文書の中の言葉
3. 強調キーワード
4. プラグイン

どれを使うかと、大文字小文字の扱いは、**文書のタイプごと**に、タイプ別設定の「支援」ページ（「入力補完機能」の枠）で決めます。

| 項目 | `matsu.ini` のキー | 意味 |
|---|---|---|
| 単語ファイル | `szHokanFile` | 候補の元にする、単語のファイルです。空なら使いません |
| 候補: 編集中のファイル | `bUseHokanByFile` | 文書の中の言葉を候補にします |
| 候補: 強調キーワード | `bUseHokanByKeyword` | タイプに設定した強調キーワードを候補にします |
| 英大文字小文字を同一視 | `bHokanLoHiCase` | 前方の一致を調べるとき、大文字と小文字を同じとみなします |
| 入力補完機能の種類 | `nHokanType` | 候補を足すプラグインを選びます。「なし」か、使えるプラグインです |

タイプ別設定の各項目の説明は、「コマンド: 設定（タイプ別設定）とウィンドウ」の章にあります。

### 単語ファイル

- 1 行に 1 語を書きます。
- `;` で始まる行は、注釈です。候補にしません。
- 文字コードは、先頭に UTF-8 の BOM があれば UTF-8、なければ Shift_JIS です。
- 相対パスは、`matsu.ini` のあるフォルダから数えます。
- 読めないファイルは、候補が 0 のものとして扱います。
- ファイルは、大きさと更新時刻が変わるまで、読み込み直しません。
- 行は、そのまま候補になります。ファイルに同じ語が 2 度あれば、2 度出ます（文書の中の言葉などと同じ語は、1 つにまとまります）。

### 文書の中の言葉

- 文書の前から順に探し、同じ言葉は 1 つにします。最大 1024 語です。
- キャレットのある言葉（書きかけの自分自身）は、候補に入れません。
- 言葉の区切りは、文字の種類で決めます。英数字と `_` が 1 つの言葉になります。漢字、カタカナ、ひらがななども、種類が変わるところで区切ります。ひらがなは、漢字のあとにあるときだけ、言葉の一部になります（送りがな）。
- 記号は、言葉に入れません。ただし、`$` `@` `#` `\` で始まる言葉は、書きかけも同じ記号で始まるときだけ、候補になります。
- 1020 文字を超える言葉は、候補にしません。

### プラグイン

プラグインの `Complement` の仕組みを持つものが、候補を足せます。`F_HOKAN` を実行して一覧を開くときに、1 度だけ呼びます。そのあとの絞り込みでは、呼び直しません。呼ぶ時間は 1 秒までです。くわしくは、「プラグインとスクリプトの言語」の章を見てください。

## キーマクロ

`F_HOKAN` を実行しても、`Complete` という呼び出しは記録されません。決めたときの動き（書きかけの言葉を消す `WordDeleteToStart` と、入れた文字）が記録されます。再生では、一覧は出ずに、同じ結果になります。

## サクラエディタとの違い

- 文字を打つたびに、自動で候補を出す機能（自動補完）は、ありません。`Ctrl+Space` で呼ぶときだけです。
- 一覧を出しているときに文字を打っても、プラグインは呼び直しません。最初に集めた候補を、新しい言葉で絞ります。
- プラグインを待つ間、候補が 2 つ未満なら一覧を出しません（0 件なら何もせず、1 件なら即決する決まりを、プラグインの結果が来てから守るためです）。
- 行頭では、前の行の終わりを見に行きません。行の頭にキャレットがあれば、候補はありません。
- 文字数は UTF-16 の単位ではなく、1 文字を 1 と数えます。大文字小文字の比較は、文字ごとに小文字にして比べます。
