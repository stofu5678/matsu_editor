# コマンド: ツール

メニューの「ツール」にある機能の章です。この章に書くのは、次の 3 つです。

- 外部コマンド実行
- 入力補完
- カスタムメニュー

ほかの機能は、持ち主の章に書いています。下の表で、どこにあるかを引けます。

## 「ツール」メニューの項目

| 項目 | 機能 | 書いてある場所 |
|---|---|---|
| キーマクロの記録開始／終了 | `F_RECKEYMACRO` | 「マクロの使い方」の章のキーマクロ |
| キーマクロの保存 | `F_SAVEKEYMACRO` | 「マクロの使い方」の章のキーマクロ |
| キーマクロの読み込み | `F_LOADKEYMACRO` | 「マクロの使い方」の章のキーマクロ |
| キーマクロの実行 | `F_EXECKEYMACRO` | 「マクロの使い方」の章のキーマクロ |
| 登録済みマクロ（サブメニュー） | 共通設定に登録したマクロの一覧 | 「マクロの使い方」の章 |
| 名前を指定してマクロ実行... | `F_EXECEXTMACRO` | 「マクロの使い方」の章 |
| [外部コマンド実行...](exec-command.md) | `F_EXECMD_DIALOG` | この章 |
| ワンライナー（サブメニュー） | 登録済みワンライナーの一覧、入力して実行、設定 | 「MATSU Editor だけの機能」の章のワンライナー |
| データベースの出力を表示 | `F_ACTIVATE_SQLPLUS` | 「MATSU Editor だけの機能」の章のデータベース |
| データベースで実行 | `F_PLSQL_COMPILE_ON_SQLPLUS` | 「MATSU Editor だけの機能」の章のデータベース |
| 接続を選んでデータベースで実行... | `F_PLSQL_COMPILE_ON_DATABASE_CHOICE` | 「MATSU Editor だけの機能」の章のデータベース |
| [入力補完](complete.md) | `F_HOKAN` | この章 |
| プラグインコマンドリスト | 有効なプラグインのコマンドの一覧 | 「プラグインとスクリプトの言語」の章 |
| [カスタムメニュー](custom-menu.md)（サブメニュー） | 作ってあるカスタムメニューの一覧 | この章 |

「ワンライナー」と 3 つの「データベース」の項目は、MATSU Editor の「ツール」メニューにあります。機能の名前（`F_` で始まる名前）はサクラエディタのものを借りていますが、動きは MATSU Editor 独自です。

## この章のページ

| ページ | 何をするか |
|---|---|
| [外部コマンド実行](exec-command.md) | コマンドを実行し、出力を文書かアウトプットに入れます。文書を標準入力に渡すこともできます |
| [外部コマンド実行のマクロ（ExecCommand）](exec-command-macro.md) | ダイアログを出さずに実行します。選択肢は、数の和で渡します |
| [入力補完](complete.md) | キャレットの前の言葉を、候補の一覧から選んで完成させます |
| [カスタムメニュー](custom-menu.md) | 好きな機能を並べた自分のメニューを、キーやマウスで開きます |

## 根拠

- MATSU のコード: `crates/matsu-commands/src/sakura/main_menu.rs` の「ツール」の節、`crates/matsu-commands/src/sakura/functions.rs`（機能の名前）
