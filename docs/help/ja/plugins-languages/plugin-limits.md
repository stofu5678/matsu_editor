# 時間の制限と失敗

プラグインは、別のプロセスで動きます。止まったり、無限に繰り返したりしても、MATSU Editor は固まりません。呼び出しごとに、ジャックで決まった制限の時間があります。

## 制限の時間

| ジャック | 制限 |
|---|---|
| `Command` | 30 秒 |
| `EditorStart`、`EditorEnd` | 5 秒 |
| `DocumentOpen`、`DocumentClose` | 5 秒 |
| `DocumentBeforeSave`、`DocumentAfterSave` | 5 秒 |
| `Outline` | 10 秒 |
| `Complement`、`ComplementGlobal` | 1 秒 |
| `SmartIndent` | 0.5 秒 |

時間は固定です。設定では変えられません。

制限を超えると、プロセスを終わらせます（止めるまでにハンドラが `Editor` でした編集は、残ります）。

- `DocumentBeforeSave` が時間を超えても、保存は続けます。
- `Outline` が時間を超えると、空のアウトラインと理由を出します。
- `Complement` は、制限の前に足した候補を残します。
- `SmartIndent` は、そのあとに何も挿入しません。

## 失敗の数え方と停止

次の 3 つは「失敗」です。

- ハンドラが例外を投げた（構文の間違いも含みます）
- 制限の時間を超えた
- プロセスが、呼び出しの途中で終わった

失敗が 3 回続くと、そのプラグインを止めます。成功が 1 回あれば、数は 0 に戻ります。

- 止めたプラグインは、一覧の状態が「停止（失敗が続きました）」になります。
- 止めたあとは、呼び出しません。コマンドを選んだときは、「失敗が続いたので止めています。もう一度「有効にする」を押すと戻ります」と出ます。
- 戻すには、一覧で「有効にする」を押して、確認の画面で承知します。「無効にする」のあとに有効にしても、戻ります。
- 止めた記録は、MATSU Editor を動かしている間だけのものです。終了すると、数え直しになります。

次のことは、失敗に数えません。

- 利用者が止めた（ウィンドウが閉じた、文書が別のものに替わった、など）。
- 呼び出しが始まらなかった（止めている、フォルダーの外のファイルを指している、ハンドラのファイルを読めない、処理系を起動できない、など）。

## プロセスの寿命

- プロセスは、そのプラグインの最初の呼び出しで起動します。設定を読んだだけでは、起動しません。
- `UseCache=1` も `Resident=1` も指定していないプラグイン（既定）は、呼び出しが終わるたびにプロセスを終わらせます。呼び出しごとに起動するので、何も残りません。
- `UseCache=1` か `Resident=1` のプラグインは、呼び出しがうまくいくたびにプロセスを残して、次の呼び出しに使います。失敗したときは、プロセスを終わらせます。次の呼び出しで、新しく起動します。
- プラグインを無効にする、外す、MATSU Editor を終了する、のどれかで、プロセスは終わります。
- 1 つのプラグインは、1 度に 1 つの呼び出ししか動かせません。複数のウィンドウから同時に呼ばれたときは、待たせるか、補完とスマートインデントのように遅れて意味がないものは飛ばします。

## エラーの見え方

エラーは、出力パネルと状態バーに出ます。

| 起きたこと | 出力パネルと状態バー |
|---|---|
| ハンドラの例外 | ファイル名と行番号つきのエラーの文。続けて「エラーで終了しました」 |
| 制限の時間を超えた | 「時間切れで中止しました (N 秒)」 |
| プロセスが落ちた | 「プラグインのプロセスが終わりました (…)」 |
| 始められなかった | 「プラグイン `<名前>`: `<理由>`」 |

3 回続いて止めたときは、「失敗が続いたので、このプラグインを止めました。もう一度「有効にする」を押すと戻ります」も出ます。

コマンドは、始めたときと終わったときに、出力パネルに知らせます。イベント、アウトライン、補完、スマートインデントは、うまくいったときは何も言いません。失敗したときと、ハンドラが出力したときだけ、出力パネルを開きます。利用者が打ち続けたために止めたスマートインデントも、何も言いません。

出力パネルの「中止」は、マクロ用です。プラグインの呼び出しを、手で止める操作は、いまのところありません。

## サクラエディタとの違い

- サクラエディタには、時間の制限も、失敗で止める仕組みもありません。呼び出しが終わるまで、エディタは待ちます。
- MATSU Editor は、プラグインの失敗で、保存や閉じる操作を止めません。

- 制限の時間と失敗の数え方: `crates/matsu-plugin/src/plugin_host.rs` の `LIMITS`、`limit_of`、`MAX_FAILURES`、`Outcome`、`PluginHost::note`、`finish_progress`、`close_process`、`BeginError`
