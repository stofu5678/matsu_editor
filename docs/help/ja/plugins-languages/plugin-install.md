# プラグインを入れる

プラグインは、フォルダーごと置いて、共通設定の「プラグイン」のページで追加し、有効にします。ボタンと一覧の説明は、「コマンド: 設定（共通設定）」の章の「プラグイン」のページにあります。ここでは、置き場所と、有効にするときの確認と、変更の検出を説明します。

## 手順

1. プラグインのフォルダーを、下の「置き場所」のどちらかに置きます。
2. 共通設定の「プラグイン」で、「プラグインを有効にする」を入れます。既定は切れています。
3. 「新規プラグインを追加」を押します。見つかったフォルダーごとに、追加するかどうかを尋ねます。
4. 一覧で、プラグインを選んで「有効にする」を押します。確認の画面を読んで、「有効にする」を選びます。
5. 共通設定の「OK」を押します。ここで初めて、有効にした記録が書かれます。

3 で追加しただけでは、プラグインは動きません。一覧の状態は、追加した直後が「追加」、4 のあとは「追加・有効」です。5 で記録されて設定を開き直すと、「有効」になります。

## 置き場所 {#place}

次の 2 か所の `plugins` フォルダーを探します。同じ名前のプラグインが両方にあるときは、1 番目を使います。

1. `matsu.ini` と同じフォルダーの `plugins`
2. 実行ファイルと同じフォルダーの `plugins`（1 番目と同じ場所のときは、1 つだけ数えます）

「フォルダーを開く」は、1 番目を開きます。そのフォルダーがないときは作ります。プラグインのオプションの値も、1 番目の `plugins` に、`<フォルダー名>.ini` というファイルで書きます（[プラグインのオプション](plugin-options.md)）。

## 追加

「新規プラグインを追加」は、`plugin.def` を持ち、まだ登録していないフォルダーを探します。次のフォルダーは見ません。

- 隠しフォルダー（Windows は隠し属性のもの、そのほかは名前が `.` で始まるもの）
- 名前が `unuse` のフォルダー（大文字と小文字の違いは区別しません）

見つかったフォルダーごとに、次の 3 つから選びます。

- 追加。登録して、一覧に出します。
- 追加しない。次のフォルダーに進みます。
- キャンセル。ここで打ち切ります。

質問には、確認の画面と同じ内容（次の節）が付きます。

追加できないときは、理由が出ます。

| 理由 | 出る言葉 |
|---|---|
| `plugin.def` がない | 「プラグイン定義ファイル（plugin.def）がありません」 |
| `Id` がない | 「Plugin.IDがありません」 |
| `Id` に使えない文字がある | 「Plugin.IDに…は使用できません」 |
| `Id` の先頭が数字 | 「Plugin.IDの先頭に数字は使用できません」 |
| `Id` が 64 文字以上 | 「Plugin.IDは63文字までです」 |
| フォルダー名が 64 文字以上 | 「フォルダー名は63文字までです」 |
| 登録の枠（40 個）が埋まっている | 「プラグインをこれ以上登録できません」 |

`Id` に使えない文字は、空白、タブ、`/`、`\`、`,`、`[`、`]`、`*`、`?`、`<`、`>`、`&`、`|`、`;`、`:`、`=`、`"` です。

同じ `Id` のプラグインが、別のフォルダー名で登録済みのときは、「上書きしますか」と尋ねます。「はい」は新しいフォルダーを使い、「いいえ」は登録済みのほうを使います。

## 有効にするときの確認

「有効にする」を押すと、次の内容の画面が出ます。

- 名前、作者、バージョン、配布元、フォルダー
- 動くとき。使うジャックを、「ファイルを保存する前に自動で動く」のような言葉で並べます。コマンドは「メニュー・ツールバー・キーで選んだとき」です。
- 使う言語と、動かすプログラム
- 注意。「このプラグインはあなたの権限で、制限なしに動きます。信頼できる配布元のものだけを有効にしてください。」

プラグインは、あなたの権限で動きます。外へ出られないように閉じ込める仕組みは、ありません。守りは、この確認と、次の変更の検出だけです。信頼できるものだけを有効にしてください。

この画面を出してから「有効にする」を押すまでに、プラグインのファイルが変わったときは、有効になりません。もう一度押します。

## 変更の検出

有効にするとき、MATSU Editor は、プラグインのフォルダーの中のすべてのファイル（下のフォルダーを含む）の SHA-256 を、`plugins.ini` に記録します。

プラグインを動かす前に、フォルダーを記録と比べます。ファイルが変わった、足された、消えたのどれかがあると、そのプラグインは動きません。一覧の状態は「変更あり（停止）」です。もう一度「有効にする」を押して承知し直すと、動きます。

- 記録できるのは、5000 ファイルまで、全体で 64 MiB までです。これを超えるフォルダーと、シンボリックリンクを含むフォルダーは、調べられないので、有効にできません。
- オプションの値のファイルは、プラグインのフォルダーの外にあります。変わっても検出しません。
- 呼び出しのたびにすべてのファイルを読み直すと遅くなります。そのため、ファイルの一覧と大きさと更新時刻が前に調べたときと同じなら、前の値を使います。大きさと更新時刻を変えずにファイルを書き換えられたときは、気づきません。更新から 3 秒以内のファイルがあるときは、値を覚えません。
- ハンドラに指定できるファイルは、プラグインのフォルダーの中のものだけです。`..` や絶対パスや、フォルダーの外を指すリンクは、断ります。

## 無効にする、削除する

- 「無効にする」は、記録を消します。OK を押すと、動いているプラグインのプロセスも終わります。
- 「削除」は、一覧から外します。同じ `Id` のプラグインを追加し直すと、元の枠に戻ります。
- 「プラグインを有効にする」を切って OK を押すと、すべてのプラグインのプロセスが終わり、以後は動きません。

## `plugins.ini` {#plugins-ini}

有効にした記録は、`matsu.ini` ではなく、同じフォルダーの `plugins.ini` に書きます。`matsu.ini` だけを別のパソコンへ写したときに、承知した記録まで写って、黙って動くのを避けるためです。設定のフォルダーごと写すと、`plugins.ini` も写ります。

```
[Plugin.jp.example.sample]
Enabled=1
Date=2026-10-26
Folder=Sample
File[001]=（64 文字の SHA-256） plugin.def
File[002]=（64 文字の SHA-256） local/plugin_ja_JP.def
```

プラグインの一覧そのもの（40 個の枠と、機能の入り切り）は、`matsu.ini` の `[Plugin]` にあります。

## サクラエディタとの違い

- 追加と有効化が別です。確認の画面は、有効にするたびに出ます。
- 変更の検出があります。
- 「ZIPプラグインを導入」と、ReadMe を見るボタンは、まだありません。
- 登録は 40 個までです。これはサクラエディタと同じです。

## 根拠

- 置き場所、追加、`Id` の規則: `crates/matsu-config/src/plugins.rs` の `SearchDirs`、`PluginSettings::install`、`check_id`、`RESERVED_CHARS`、`ID_MAX_CHARS`、`MAX_PLUGIN`
- 追加のダイアログと言葉: `crates/matsu-ui/src/common_settings/pages/plugin/list.rs` の `search_new`、`install_error_text`、`enable_selected`、`enable_row_checked`。状態の言葉は `rows.rs` の `state_text`
- 確認の画面: `crates/matsu-ui/src/common_settings/pages/plugin/confirm.rs`
- 記録と検出: `crates/matsu-config/src/plugins/consent.rs`（`fingerprint`、`fingerprint_cached`、`compare`、`MAX_FILES`、`MAX_BYTES`）。書き込みと、プロセスを終わらせること: `crates/matsu-ui/src/common_settings/pages/plugin.rs` の `apply`、`rows.rs` の `write_consent`
- ハンドラがフォルダーの外を指せないこと: `crates/matsu-plugin/src/plugin_host.rs` の `handler_path`
- 試験: `crates/matsu-config/src/plugins/tests.rs`、`crates/matsu-ui/src/common_settings/pages/plugin/tests.rs`
- サクラのソース: `sakura_core/plugin/CPluginManager.cpp` の `SearchNewPlugin`、`InstallPlugin`
