# コマンド

`Command` ジャックは、利用者が自分で選んだときだけ動きます。プラグインの中で、いちばん安全な場面です。メニュー、キー、ツールバーのボタンから動かせます。

## コマンドの作り方

次の 2 つで、コマンドができます。

- `plugin.def` の `[Command]` に書く（[plugin.def の書き方](plugin-def.md)）。
- 動いているプラグインが、`Plugin.AddCommand` で足す（[ハンドラの中で使えるもの](plugin-api.md)）。

コマンドは、次の条件がそろったプラグインのものだけが、使えます。

- 共通設定の「プラグインを有効にする」が入っている
- プラグインを登録して、有効にしている
- プラグインのファイルが、有効にしたときのままである
- MATSU Editor が動かせる種類である（DLL と VBScript は不可）

条件が崩れると、コマンドはなくなります。プラグインを無効にしたり、外したりしたときに、足したコマンドも消えます。

## 呼び出す場所

| 場所 | 出方 |
|---|---|
| メニュー「ツール」の「プラグインコマンドリスト」 | プラグインごとの副メニューが並び、その中にコマンドが並びます。コマンドのあるプラグインだけです。副メニューの名前は `Name`（なければフォルダー名）、項目の名前は `C[n].Label` です |
| 共通設定の「キー割り当て」 | 種別「プラグイン」の一覧に、コマンドが並びます |
| 共通設定の「メインメニュー」と「カスタムメニュー」 | 種別「プラグイン」の一覧に並びます |
| 共通設定の「ツールバー」 | 種別「プラグイン」の一覧に並びます。ボタンの絵は、すべて同じ既定のものです |

設定ファイルには、コマンドを `<プラグインの Id>/<2 桁の番号>`（例: `jp.example.hello/01`）の名前で書きます。サクラエディタと同じ書き方です。このため、プラグインを一時的に無効にしても、割り当てやメニューの設定は消えません。有効にすると、また効きます。

## 動かしたときの様子

1. 出力パネルに、「プラグイン `<名前>` の Command (`<ハンドラ>`) を開始します」と出ます。
2. ハンドラが動きます。`console.log` などの出力は、出力パネルに出ます。
3. 終わると、出力パネルと状態バーに「正常に終了しました」などと出ます。エラーのときは、エラーの文も出ます（[時間の制限と失敗](plugin-limits.md)）。

動かせないときは、状態バーに理由が出ます。

- 条件がそろっていない: 「このプラグインコマンドは、今は使えません（プラグインが有効でないか、読み込まれていません）」
- 別のプラグインかマクロが、そのウィンドウで動いている: 「ほかのプラグインかマクロが動いている間は動かせません」
- ファイルが変わった: 「ファイルが変わったので止めています。もう一度「有効にする」を押してください」
- ハンドラが `.js` でない: 「`<ハンドラ>` は動かせません。今は .js のプラグインだけです」
- 失敗が続いて止めた: 「失敗が続いたので止めています。もう一度「有効にする」を押すと戻ります」

動かしている間も、ウィンドウは固まりません。ただし、1 つのウィンドウで同時に動かせるプラグインは 1 つです。マクロが動いている間は、プラグインのコマンドも動かせません。手で止める操作は、いまのところありません。制限の時間（30 秒）で止まります。

プラグインが文書にしたことは、元に戻す操作で、まとめて 1 回で戻せます（例外は[ハンドラの中で使えるもの](plugin-api.md)にあります）。

## 設定ページの「試しに実行」

共通設定の「プラグイン」の「試しに実行」は、選んだプラグインの 1 番目のコマンドを、設定を開いたウィンドウの文書で動かします。設定を保存して、有効にしたあとで使えます。

## サクラエディタとの違い

- コマンドのアイコン（BMP）は、サクラと同じく、ツールバーとメニューの両方に出ます。フォルダーの外を指すファイル名は読みません。
- 1 つのウィンドウで同時に動かせるプラグインは 1 つです。
- `EditorStart` で `Plugin.AddCommand` を使うプラグインのコマンドは、ウィンドウができたときに現れます。保存してあるキーやボタンは、そのとき効きます。

## 根拠

- コマンドの登録と条件: `crates/matsu-ui/src/plugin_commands.rs` の `refresh_for`、`PluginList`、`run_plugin_command`
- 関数コードと設定ファイルの名前: `crates/matsu-commands/src/plugin_commands.rs`（`function_code`、`name_of`、`by_name`）
- 一覧の種別「プラグイン」: `crates/matsu-ui/src/common_settings/func_lookup.rs` の `codes_of_kind`。ツールバー: `crates/matsu-ui/src/bars/toolbar.rs` の `plugin_icon`。メニューの項目: `crates/matsu-commands/src/sakura/main_menu.rs`（`F_PLUGIN_LIST`）
- 動かしたときの言葉と制限: `crates/matsu-ui/src/macros/plugin_call.rs` の `prepare`、`run`、`describe`
- 試験: `crates/matsu-ui/src/plugin_commands/tests.rs`
- サクラのソース: `sakura_core/plugin/CPlugin.h`（関数コードの式）、`CEditWnd.cpp` の `InitMenu_Special`（`F_PLUGIN_LIST`）
