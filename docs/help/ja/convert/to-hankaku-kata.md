# 全角カタカナ→半角カタカナ

全角のカタカナを、半角のカタカナにします。

## 呼び出し方

| 項目 | 内容 |
|---|---|
| メニュー | 「変換」の「全角カタカナ→半角カタカナ」 |
| 機能名 | `F_TOHANKATA` |
| マクロ | `ToHankata` |
| 既定のキー | なし |
| キーマクロ | 記録される |

選んでいる文字列が対象です。何も選んでいないときは、メニューの項目が灰色になり、実行しても何も起きません。そのほかの共通の動き（選択の残り方、箱型の選択、閲覧モード、元に戻す）は、[共通の動き](index.md#共通の動き)を見てください。

## 動き

- 全角のカタカナと、かなの記号（`。` `、` `「` `」` `・`、`ー`、`゛` `゜`）を、半角にします
- 濁点と半濁点のある文字は、2 文字（文字と `ﾞ` か `ﾟ`）になります。文字数が増えます
- `ー` は、前の文字がカタカナ（濁点付きの文字も含む）として変わったときだけ半角（`ｰ`）になります。そうでないときは、そのままです
- 単独の濁点・半濁点（`゛` `゜`）は、前の文字が濁点のない普通のカタカナのときだけ半角（`ﾞ` `ﾟ`）になります。`ガ゛` は `ｶﾞ゛` になり、`ｶﾞﾞ` にはなりません
- ひらがなと英数字は、変わりません
- `ヰ` `ヱ` `ヮ` `ヵ` `ヶ` は、半角にそれぞれの形がないので、`ｲ` `ｴ` `ﾜ` `ｶ` `ｹ` になります。逆の変換では元に戻りません

## 例

```text
ガー。ひ   ->   ｶﾞｰ｡ひ
```

## サクラエディタとの違い

- 動きの違いは、共通の動きの節に書いたものだけです。
