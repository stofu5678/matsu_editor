# 置換文字列の書き方

「正規表現」にチェックを入れた「置換」と「Grep 置換」で、置換後の文字列に書ける記法です。検索パターンの書き方は [正規表現の構文](regex-syntax.md) にあります。

置換文字列は、一致するたびに組み立てなおします。グループの内容を取り込んだり、大文字・小文字を変えたりできます。

## グループの取り込み

| 書き方 | 意味 |
|---|---|
| `$1` … `$9`、`\1` … `\9` | その番号のグループの文字列 |
| `${1}` | 番号のグループ。後ろに数字が続くときに使う（`${1}0`） |
| `$&`、`${0}` | 一致した部分の全体 |
| `$+` | 一致に加わったグループのうち、いちばん番号の大きいもの |
| `${名前}`、`$+{名前}`、`\k<名前>`、`\k'名前'` | その名前のグループ。同じ名前が複数あるときは、番号がいちばん小さいもの |
| `$-{名前}[n]` | その名前の n 番目のグループ（0 が最初、`-1` が最後） |

- 一致に加わらなかったグループは、空の文字列になります。
- パターンにない番号や名前は、空の文字列になります。置換は、そのまま続きます。
- 2 桁以上の番号（`\10`）は、パターンにそれだけのグループがあれば、グループです。ないときは、8 進数の 2 桁か 3 桁で `\377` までなら、その文字です。それ以外は、空のグループです。
- `$` のあとに、参照として読めない文字が続くときは、`$` と続く 1 文字が、そのままの文字列になります。`$$1` は文字列 `$$1`、`$0` は文字列 `$0` です。`$` だけを出したいときは、`\$` と書きます。
- `${...}` は、先頭が数字のときは、数字と `}` だけで書きます（`${1a}` は文字列）。それ以外は、`}` までを名前として読みます。`}` がないときは、文字列です。

## 文字

| 書き方 | 意味 |
|---|---|
| `\t` `\n` `\r` `\b` `\f` `\a` `\e` | タブ、LF、CR、バックスペース、改ページ、ベル、ESC |
| `\0nn` | 8 進数の文字コード（`0` を含めて 3 桁まで） |
| `\xHH` `\x{H...}` | 16 進数の文字コード（波かっこなしは 2 桁まで、ありは 8 桁まで。`\x{}` は U+0000） |
| `\o{n...}` | 波かっこの中の 8 進数 |
| `\cX` | 制御文字（`\c[` は ESC） |
| `\` と、それ以外の文字 | その文字そのもの（`\\` `\$` `\/` など） |

- `\n` は LF、`\r\n` は CR LF を、そのまま入れます。入れた位置で、行が分かれます（`,` を `\n` に置き換えると、`a,b,c` が 3 行になります）。
- `\v` は、`v` という文字になります。
- `\xHH` と 8 進数は、そのコードポイントの文字です。バイト列ではないので、`\xC3\xA9` は 2 文字になります。`é` にはなりません。

## 大文字と小文字の変換

| 書き方 | 意味 |
|---|---|
| `\u` `\l` | 次の 1 文字を大文字、小文字にする |
| `\U` `\L` | `\E` まで（なければ最後まで）を大文字、小文字にする |
| `\E` | `\U` `\L` の効果を終える |
| `\Q` | 何もしない（読み飛ばす。引用の働きはしない） |

- 変換するのは、ASCII の英字だけです。
- `\U` と `\L` の効果は、文字列、エスケープ、グループの中身に続けて効きます。
- `\u` と `\l` は、次に出る文字に効きます。空のグループは、その 1 回を使い切りません。`\U` や `\L` と一緒に使うと、`\u` と `\l` が勝ちます。

## 例

| パターン | 置換文字列 | 元の文字列 | 結果 |
|---|---|---|---|
| `(\d+)年(\d+)月` | `$2/$1` | `2026年11月` | `11/2026` |
| `(?<k>\w+)=(?<v>\w+)` | `${v}=${k}` | `a=b` | `b=a` |
| `\b(\w)` | `\u$1` | `hello world` | `Hello World` |
| `(\w+)@(\w+)` | `\U$1\E at $2` | `ab@cd` | `AB at cd` |

## エラーと警告

- 置換文字列の末尾が、エスケープされていない `\` のときは、使えません。パターンの末尾の `\` と同じ理由です（サクラは、パターンと置換文字列のあとに区切りの文字を付けて、bregonig.dll に渡します）。
- 参照の番号や名前が、パターンにないときは、結果は空の文字列で、置換は続きます。

## サクラエディタとの違い

- bregonig の説明書（`bregonig.html`）に書いていない動きは、bregonig.dll 4.20 を Windows で動かして測った結果に合わせています（2026-10-16 の測定）。
- bregonig.dll は、`\x{D800}` のような、サロゲートの範囲や 0x10FFFF より大きい値を、壊れた文字として出します。MATSU Editor の文字列はそれを持てないので、何も出しません。
- `$-{名前}[n]` の n が、グループの数を越えると、bregonig.dll は、読んではいけない場所を読みます（32 ビット版と 64 ビット版で結果が違います）。MATSU Editor は、空の文字列にします。
- グループの番号に 20 桁以上の数字を書くと、bregonig.dll では桁があふれて別の番号になります。MATSU Editor は、上限で止めます。
- bregonig のソースは、GPL か Artistic License で使えないので、読んでいません。MATSU Editor の置換は、説明書と実物の結果から、独立に書いています（ADR-0006）。
