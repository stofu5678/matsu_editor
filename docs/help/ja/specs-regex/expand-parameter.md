# 特殊文字（ExpandParameter）

`$F` や `${U?(更新)$}` のように、`$` で始まる記号を、ファイル名や状態に置き換える仕組みです。サクラエディタの `ExpandParameter` に当たります。

## 使う場所

| 場所 | 説明 |
|---|---|
| ウィンドウのタイトル | 共通設定「ウィンドウ」ページの「タイトルバー」の「アクティブ時」「非アクティブ時」（`szWinCaptionActive`、`szWinCaptionInactive`） |
| タブのキャプション | 共通設定「タブバー」ページのタブの文字（`szTabWndCaption`） |
| 印刷のヘッダーとフッター | 印刷ページ設定の、ヘッダーとフッターの左・中央・右 |
| マクロの `ExpandParameter` 関数 | 引数の文字列を展開して返す |
| 外部コマンド実行のコマンド | 実行前に、コマンドの文字列を展開する |
| マクロの `TraceOut` | 出力する文字列を展開する |

上の 3 つ（画面と印刷）と、下の 3 つ（マクロと外部コマンド）は、MATSU Editor の中で、別々の部品が展開しています。使える記号の範囲が、次の表のとおり違います。

## 記号の一覧

「画面」は、ウィンドウのタイトル、タブ、印刷のヘッダーとフッターです。「マクロなど」は、マクロの `ExpandParameter`、外部コマンド実行、`TraceOut` です。「そのまま」は、記号を展開せずに、書いた文字のまま残すことです。

| 記号 | 意味 | 画面 | マクロなど |
|---|---|---|---|
| `$$` | `$` 1 文字 | 同じ | 同じ |
| `$A` | アプリの名前（`MATSU Editor`） | 同じ | 同じ |
| `$F` | ファイルのフルパス。ファイルがない文書は `(無題)` | 同じ | 同じ |
| `$f` | ファイル名（フォルダーを除く）。ファイルがなければ `(無題)` | 同じ | 同じ |
| `$g` | 拡張子を除いたファイル名。先頭の `.` は拡張子と見ない（`.bashrc` はそのまま） | 同じ | 同じ |
| `$/` | `$F` の `\` を `/` にしたもの | Windows だけ `\` を置き換える | `\` を常に置き換える |
| `$N` | 短くしたフルパス | 共通設定「ファイル名表示」の設定で短くした形 | `$F` と同じ（短くしない） |
| `$e` | ファイルのフォルダー（最後の区切りを含む） | 同じ | 同じ |
| `$E` | 短くしたフォルダー | 「ファイル名表示」の設定で短くした形 | `$e` と同じ |
| `$n` | ファイルのない文書の通し番号 | 普通のウィンドウの、ファイルのない文書の番号 | 空 |
| `$B` | 文書タイプの名前 | 基本のタイプでなければ、その名前 | そのまま |
| `$b` | 拡張子（`.` を除く） | 同じ | 同じ |
| `$Q` | 印刷設定の名前 | 印刷のときだけ。それ以外は空 | そのまま |
| `$C` | 選択した文字列の、最初の行。選択がなければ、キャレットの位置の単語 | 同じ | 同じ（最大 259 文字） |
| `$x` `$y` | キャレットの桁と行（どちらも 1 から）。桁は UTF-16 の単位で数える | 同じ | 同じ |
| `$d` `$t` | 今の日付と時刻 | 共通設定「書式」の形式 | そのまま |
| `$D` `$T` | ファイルの更新日と更新時刻。保存していないファイルは `(保存されていません)` | 「書式」の形式 | そのまま |
| `$p` `$P` | ページ番号と全ページ数 | 印刷プレビューの中だけ。外では `(印刷プレビューでのみ使用できます)` | いつも `(印刷プレビューでのみ使用できます)` |
| `$V` | MATSU Editor の版 | 同じ | 同じ |
| `$h` | Grep の検索条件（先頭の 32 文字まで。切ったときは `...`） | Grep のウィンドウで値が入る | 空 |
| `$S` | 実行ファイルのパス | 同じ | 同じ |
| `$I` | 設定ファイル（`matsu.ini`）のパス | 同じ | そのまま |
| `$M` | 実行中のマクロのファイル | 同じ | 同じ |
| `$<profile>` | プロファイルの名前（既定のプロファイルは空） | 同じ | 空 |

- ほかの `$` と文字の組み合わせは、そのまま残ります。
- 文字列の最後に `$` 1 つだけがあるときは、画面では `$` を残します。マクロなどでは、その `$` は消えます。

## 条件

`${条件?A$:B$:C$}` の形で、条件によって、3 つまでの部分から 1 つを選びます。選ばなかった部分は出力しません。部分の数が足りないときは、足りない部分は空です。条件は入れ子にできます。

| 条件 | 1 番目 | 2 番目 | 3 番目 | 画面 | マクロなど |
|---|---|---|---|---|---|
| `R` | ビューモード | 上書き禁止 | どちらでもない | 3 つとも選ばれる | 1 番目と 3 番目だけ（上書き禁止は選ばれない） |
| `w` | Grep のウィンドウ | アウトプットのウィンドウ | 普通のウィンドウ | Grep のとき 1 番目、それ以外は 3 番目 | いつも 3 番目 |
| `M` | キーマクロの記録中 | 記録中でない | － | 同じ | 同じ |
| `U` | 変更あり | 変更なし | － | 同じ | 同じ |
| `N` | ファイルのない文書 | ファイルのある文書 | － | 同じ | 同じ |
| `I` | 最小化している | 最小化していない | － | いつも 2 番目 | いつも 2 番目 |

知らない条件は、1 番目を選びます。

例: `${U?(更新)$:$}$f` は、変更のある文書では `(更新)a.txt`、ないときは `a.txt` になります。

## 初期値の書式

画面で使う書式の初期値は、次のとおりです。

- タイトル（アクティブ時）: `${w?$h$:アウトプット$:${I?$f$n$:$N$n$}$}${U?(更新)$} - $A $V ${R?(ビューモード)$:(上書き禁止)$}${M?  【キーマクロの記録中】$} $<profile>`
- タイトル（非アクティブ時）: `${w?$h$:アウトプット$:$f$n$}${U?(更新)$} - $A $V ${R?(ビューモード)$:(上書き禁止)$}${M?  【キーマクロの記録中】$} $<profile>`
- タブ: `${w?【Grep】$h$:【アウトプット】$:$f$n$}${U?(更新)$}${R?(ビューモード)$:(上書き禁止)$}${M?【キーマクロの記録中】$}`

## 長さの上限

- 画面（タイトル、タブ、ヘッダーとフッター）の展開結果は、UTF-16 の 1024 単位で切ります。文字の途中では切りません。
- マクロの `ExpandParameter` の結果は、UTF-16 の 2047 単位で切ります。
- 外部コマンド実行は、展開したあとに、コマンドを UTF-16 の 1024 単位で切ります。

## サクラエディタとの違い

- サクラは、どの場所も 1 つの関数で展開します。MATSU Editor は、上のとおり、画面と印刷の部品と、マクロなどの部品に分かれています。マクロなどの部品は、`$B` `$Q` `$d` `$t` `$D` `$T` `$I` を展開せず、`$n` `$h` `$<profile>` は空にします。`${R?...}` の「上書き禁止」と、`${w?...}` の Grep とアウトプットも選びません。
- `$A` は、`MATSU Editor` です。
- `$f` `$g` `$e` `$b` のようにパスを区切る記号は、画面では、Windows なら `\` と `/`、それ以外の OS なら `/` だけを区切りにします。マクロなどでは、どの OS でも、両方を区切りにします。
