# 特殊文字（ExpandParameter）

`$F` や `${U?(更新)$}` のように、`$` で始まる記号を、ファイル名や状態に置き換える仕組みです。サクラエディタの `ExpandParameter` に当たります。

## 使う場所

| 場所 | 説明 |
|---|---|
| ウィンドウのタイトル | 共通設定「ウィンドウ」ページの「タイトルバー」の「アクティブ時」「非アクティブ時」（`szWinCaptionActive`、`szWinCaptionInactive`） |
| タブのキャプション | 共通設定「タブバー」ページのタブの文字（`szTabWndCaption`） |
| 印刷のヘッダーとフッター | 印刷ページ設定の、ヘッダーとフッターの左・中央・右 |
| マクロの `ExpandParameter` 関数 | 引数の文字列を展開して返す |
| 外部コマンド実行のコマンド | 実行前に、コマンドの文字列を展開する |
| マクロの `TraceOut` | 第 2 引数に `0x01` のビットがあるときだけ、出力する文字列を展開する（`TraceOut("$F")` は `$F` のまま出力し、`TraceOut("$F", 1)` は展開する） |

展開は 1 つの部品（`matsu-print` の `expand_parameter`）が行います。サクラエディタも、どの場所も `ExpandParameter` 1 つです。場所によって違うのは、渡される状態（ファイルや文書タイプなど）と、結果の長さの上限だけです。

## 記号の一覧

| 記号 | 意味 | 場所による違い |
|---|---|---|
| `$$` | `$` 1 文字 | なし |
| `$A` | アプリの名前（`MATSU Editor`） | なし |
| `$F` | ファイルのフルパス。ファイルがない文書は `(無題)` | なし |
| `$f` | ファイル名（フォルダーを除く）。ファイルがなければ `(無題)` | なし |
| `$g` | 拡張子を除いたファイル名。先頭の `.` は拡張子と見ない（`.bashrc` はそのまま） | なし |
| `$/` | `$F` の `\` を `/` にしたもの | Windows だけ `\` を置き換える |
| `$N` | 短くしたフルパス | 共通設定「ファイル名表示」の設定で短くした形。ウィンドウがないときは `$F` と同じ |
| `$e` | ファイルのフォルダー（最後の区切りを含む） | なし |
| `$E` | 短くしたフォルダー | 「ファイル名表示」の設定で短くした形。ウィンドウがないときは `$e` と同じ |
| `$n` | ファイルのない文書の通し番号 | 普通のウィンドウの、ファイルのない文書だけ。ほかは空 |
| `$B` | 文書タイプの名前 | 基本のタイプでなければ、その名前 |
| `$b` | 拡張子（`.` を除く） | なし |
| `$Q` | 印刷設定の名前 | 印刷のときは、そのページの設定。それ以外は、文書タイプの印刷設定 |
| `$C` | 選択した文字列の、最初の行。選択がなければ、キャレットの位置の単語 | マクロなどでは最大 259 文字 |
| `$x` `$y` | キャレットの桁と行（どちらも 1 から）。桁は UTF-16 の単位で数える | なし |
| `$d` `$t` | 今の日付と時刻 | 共通設定「書式」の形式 |
| `$D` `$T` | ファイルの更新日と更新時刻。保存していないファイルは `(保存されていません)` | 「書式」の形式 |
| `$p` `$P` | ページ番号と全ページ数 | 印刷とプレビューでは、ページごとの番号。ウィンドウのタイトルとタブでは、印刷プレビューを開いている間だけ番号が入る。ほかの場所（マクロ、外部コマンド、`TraceOut`、プレビューを開いていないとき）は `(印刷プレビューでのみ使用できます)` |
| `$V` | MATSU Editor の版 | なし |
| `$h` | Grep の検索条件（先頭の 32 文字まで。切ったときは `...`） | Grep のウィンドウで値が入る。ほかは空 |
| `$S` | 実行ファイルのパス | なし |
| `$I` | 設定ファイル（`matsu.ini`）のパス | なし |
| `$M` | 実行中のマクロのファイル。マクロが動いていなければ空 | なし |
| `$<profile>` | プロファイルの名前（既定のプロファイルは空） | なし |

- ほかの `$` と文字の組み合わせは、そのまま残ります。
- 文字列の最後に `$` 1 つだけがあるときは、`$` を残します。
- マクロの `ExpandParameter`、外部コマンド実行、`TraceOut` は、いま動いているウィンドウの状態で展開します。マクロが文書やキャレットを変えたあとの状態が入ります。ウィンドウのないところ（画面のない実行）では、文書タイプ、通し番号、Grep、設定ファイル、プロファイル、印刷設定の記号は空か、既定の値になります。

## 条件

`${条件?A$:B$:C$}` の形で、条件によって、3 つまでの部分から 1 つを選びます。選ばなかった部分は出力しません。部分の数が足りないときは、足りない部分は空です。条件は入れ子にできます。

| 条件 | 1 番目 | 2 番目 | 3 番目 |
|---|---|---|---|
| `R` | ビューモード | 上書き禁止 | どちらでもない |
| `w` | Grep のウィンドウ | アウトプットのウィンドウ | 普通のウィンドウ |
| `M` | キーマクロの記録中 | 記録中でない | － |
| `U` | 変更あり | 変更なし | － |
| `N` | ファイルのない文書 | ファイルのある文書 | － |
| `I` | 最小化している | 最小化していない | － |

知らない条件は、1 番目を選びます。`I` はいつも 2 番目です（ウィンドウは、マクロが動いている間も最小化されません）。

例: `${U?(更新)$:$}$f` は、変更のある文書では `(更新)a.txt`、ないときは `a.txt` になります。

## 初期値の書式

画面で使う書式の初期値は、次のとおりです。

- タイトル（アクティブ時）: `${w?$h$:アウトプット$:${I?$f$n$:$N$n$}$}${U?(更新)$} - $A $V ${R?(ビューモード)$:(上書き禁止)$}${M?  【キーマクロの記録中】$} $<profile>`
- タイトル（非アクティブ時）: `${w?$h$:アウトプット$:$f$n$}${U?(更新)$} - $A $V ${R?(ビューモード)$:(上書き禁止)$}${M?  【キーマクロの記録中】$} $<profile>`
- タブ: `${w?【Grep】$h$:【アウトプット】$:$f$n$}${U?(更新)$}${R?(ビューモード)$:(上書き禁止)$}${M?【キーマクロの記録中】$}`

## 長さの上限

- タイトル、タブ、ヘッダーとフッターの展開結果は、UTF-16 の 1024 単位で切ります。文字の途中では切りません。
- マクロの `ExpandParameter` の結果は、UTF-16 の 2047 単位で切ります。
- 外部コマンド実行は、展開したあとに、コマンドを UTF-16 の 1024 単位で切ります。

## サクラエディタとの違い

- サクラと同じく、展開の部品は 1 つです。長さの上限は、サクラの呼び出し側のバッファに合わせています。
- `$A` は、`MATSU Editor` です。
- `$f` `$g` `$e` `$b` のようにパスを区切る記号は、Windows なら `\` と `/`、それ以外の OS なら `/` だけを区切りにします（マクロなどでも同じです）。
- `${R?...}` の「上書き禁止」は、ファイルを書き込めないとき（ファイルの属性など）に選ばれます。マクロの実行中に、その状態が変わっても、マクロの開始のときの値です。

- サクラのソース: `sakura_core/env/CSakuraEnvironment.cpp` の `ExpandParameter`、`_ExParam_SkipCond`、`_ExParam_Evaluate`
- MATSU のコード（展開）: `crates/matsu-print/src/header.rs` の `expand_parameter`、`expand_parameter_limited`
- MATSU のコード（画面と印刷）: `crates/matsu-ui/src/file_names/title.rs`（既定の書式と、窓の状態の取り込み）、`crates/matsu-ui/src/view/mod.rs` の `header_context_for`（`$C` `$x` `$B` `$Q` `$d` `$t` `$D` `$T` `$S` `$I` `$M` `$<profile>`）、`crates/matsu-ui/src/tabs/caption.rs`
- MATSU のコード（マクロなど）: `crates/matsu-plugin/src/functions/expand.rs`（`header_context` が、窓の状態と、マクロが変えられる状態を集めて、上の展開に渡す）、`crates/matsu-ui/src/macros/host.rs` の `host_env`（窓の状態を渡す）、`crates/matsu-ui/src/exec/flow.rs` の `expand`、`crates/matsu-core/src/exec.rs` の `limit_command`、`crates/matsu-ui/src/ui_commands/macro_only/traceout.rs`
- 試験: `crates/matsu-print/src/header.rs` の `tests`、`crates/matsu-plugin/src/functions/expand.rs` の `tests`（`every_symbol_is_what_the_header_path_gives` が、画面の展開と同じ結果になることを確かめる）、`crates/matsu-ui/src/file_names/tests.rs`、`crates/matsu-ui/src/macros/tests.rs` の `expand_parameter_knows_the_macro_file`、`expand_parameter_in_a_macro_is_what_the_title_gives`
