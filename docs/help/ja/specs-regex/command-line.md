# コマンドラインオプション

MATSU Editor の起動に付けられるオプションです。サクラエディタのオプション（`-X=` `-GREPMODE` など）と同じ書き方で使えます。

```sh
matsu [--separate-process] [サクラのオプション] [--] [ファイル...]
```

## 起動のしかた

- 同じ設定ファイル（`matsu.ini`）で動いている MATSU Editor が、すでにあるときは、新しい起動は、ファイルとオプションをそのプロセスに渡して、すぐに終わります。渡された側が、ウィンドウを開きます（ADR-0016）。
- `--separate-process` を付けると、ほかのプロセスを探さず、独立したプロセスとして動きます（開発と試験のためのオプションです）。
- ファイルを 1 つも指定しないと、空の新しい文書を 1 つ開きます。
- 相対パスのファイルは、起動したときの作業フォルダーからの相対です。`file:///` で始まる URL も、ファイルとして開けます。
- 前回の文書を復元する設定のときは、ウィンドウを開く以外に頼みのない起動（ファイルも、マクロも、Grep も、その他のオプションもない起動）は、新しいウィンドウを作りません。

## オプションの読み方

- `-` で始まる引数が、オプションです（`"-X=1"` のように全体を引用符で囲んだものも読みます）。名前の大文字・小文字は、区別しません。
- 値は、`=` か `:` のあとに書きます（`-X=10`、`-X:10`）。
- 知らないオプションと、必要な値がないオプションは、読み捨てます。
- 引数の値を囲む引用符は、外します。`-GKEY=` `-GREPR=` `-GFILE=` `-GFOLDER=` `-M=` の値と、引用符で囲んだファイル名の中では、`""` を `"` 1 つとして読みます。
- `--` より後ろの引数は、`-` で始まっていても、すべてファイル名です。
- オプションでない引数は、すべてファイル名です。

## ファイルを開くときのオプション

| オプション | 意味 |
|---|---|
| `-X=桁` `-Y=行` | 開いたあとのキャレットの位置。1 から数える。桁は UTF-16 の単位で数える。1 未満の値は、指定なしと同じ |
| `-VX=桁` `-VY=行` | 開いたあとの、ウィンドウの左上に見せる桁と行。1 から数える。両方を指定したときだけ使う |
| `-CODE=番号` | ファイルを読む文字コード。番号は下の表。`99` は自動判定 |
| `-R` | ビューモード（読み取り専用）で開く |
| `-TYPE=拡張子` | 文書タイプを、その拡張子のファイルとして選ぶ。7 文字より長いと、7 文字で切る |
| `-M=マクロ` | 開いたあとに実行するマクロ。`-MTYPE=` がないか `file` なら、ファイルの名前。そうでなければ、その言語のマクロの本文 |
| `-MTYPE=種類` | `-M=` が何かを決める。拡張子（`js` など）で、言語を指す |
| `-PROF=名前` | プロファイルを選ぶ。設定ファイルは、`matsu.ini` を置く場所の下の、その名前のフォルダーに置く。名前が空なら、既定のプロファイル |
| `-@=ファイル` | オプションとファイル名を書いたファイル（レスポンスファイル）を読む。最後に書いたものが有効 |

- `-X=` `-Y=` `-VX=` `-VY=` `-CODE=` `-R` は、起動で開く、すべてのファイルに効きます。
- `-TYPE=` `-M=` `-SX=` `-SY=` `-WX=` `-WY=` は、起動で開く、最初の文書にだけ効きます。
- すでに開いているファイルを指定したときは、読みなおさずに、そのウィンドウを前に出します。`-Y=` があれば、その行へ移ります（`-X=` があれば、その桁へ）。
- 空の文書を開く起動では、`-TYPE=`、`-CODE=`、`-R` が、その文書に効きます。`-CODE=` が文書タイプの既定の文字コードと同じなら、タイプの設定を使います。違うなら、その文字コードで、BOM は既定どおり、改行は CR LF です。
- レスポンスファイルは、UTF-8（BOM つき）か Shift_JIS で書きます。中身は空白で切って、同じ起動の続きの引数として読みます。ファイルの行は、間に何も入れずにつなぎます。
- `-PROF=` の名前に、フォルダーの区切り、ドライブ、`.`、`..`、制御文字、`/ \ : * ? " < > |` のどれかが入っているときや、260 文字以上のときは、無視します。

### 文字コードの番号（`-CODE=` `-GCODE=`）

| 番号 | 文字コード |
|---|---|
| 0 | Shift_JIS |
| 1 | JIS（ISO-2022-JP） |
| 2 | EUC-JP |
| 3 | UTF-16LE |
| 4 | UTF-8 |
| 5 | UTF-7 |
| 6 | UTF-16BE |
| 7 | CESU-8 |
| 8 | Latin1 |
| 12000、12001 | UTF-32LE、UTF-32BE |
| 99 | 自動判定 |

- 8 より大きい番号は、Windows のコードページの番号です。MATSU Editor が持っているコードページだけが使えます。持っていない番号は、自動判定と同じになります（[文字コード](encodings.md)）。

## ウィンドウのオプション

| オプション | 意味 |
|---|---|
| `-SX=幅` `-SY=高さ` | 新しいウィンドウの大きさ（ピクセル）。サクラと同じく、値から 1 を引いた大きさになる。0 以下は、既定の大きさ |
| `-WX=x` `-WY=y` | 新しいウィンドウの左上の位置。値は、そのまま使う |

- 大きさと位置は、新しいウィンドウを作るときだけ効きます。新しいタブには効きません。

## Grep のオプション

| オプション | 意味 |
|---|---|
| `-GREPMODE` | Grep のウィンドウを開いて、すぐに検索する。`-TYPE=` が先になければ、文書タイプは `grepout` |
| `-GREPDLG` | 検索を始めずに、Grep のダイアログを開く。`-GREPMODE` と一緒のときだけ効く |
| `-GKEY=条件` | 検索する文字列 |
| `-GREPR=置換後` | Grep 置換の、置換後の文字列。空でもよい |
| `-GFILE=ファイル` | 検索するファイルのパターン。除外するパターン（`!ファイル`、`#フォルダー`）も書ける |
| `-GFOLDER=フォルダー` | 検索するフォルダー。複数は `;` で区切る。相対パスは、作業フォルダーからの相対 |
| `-GCODE=番号` | ファイルを読む文字コード。指定しないと、Shift_JIS。`99` は自動判定 |
| `-GOPT=文字` | 下の表の文字を並べて指定する（大文字だけ） |

`-GOPT=` の文字は、続けて並べます（`-GOPT=SLR`）。意味のない文字は、読み飛ばします。

| 文字 | 意味 |
|---|---|
| `S` | サブフォルダーからも検索 |
| `L` | 英大文字と小文字を区別する |
| `R` | 正規表現 |
| `W` | 単語単位 |
| `K` | 文字コードの自動判定（古い書き方） |
| `P` | 結果出力を「該当行」にする |
| `N` | 結果出力を「否該当行」にする（何も付けなければ「該当部分」） |
| `1` `2` `3` | 出力形式。1 はノーマル、2 はファイル毎、3 は結果のみ |
| `F` | ファイル毎最初のみ |
| `B` | ベースフォルダー表示 |
| `D` | フォルダー毎に表示 |
| `C` | クリップボードの文字列を置換後の文字列にする（Grep 置換） |
| `O` | バックアップを作る（Grep 置換） |
| `E` | 除外ファイルを正規表現で指定する |

- `-GREPDLG` で開いたダイアログには、`-GKEY=` `-GFILE=` `-GFOLDER=` などの値が入ります。ダイアログを閉じても、その値が、次の Grep の初期値として残ります。
- `-GOPT=C` で、クリップボードに文字列がないときは、「クリップボードに有効なデータがありません！」という通知を出して、Grep を始めません。

## 読んで捨てるオプション

次のオプションは、読んだあとに、何もしません。

| オプション | 理由 |
|---|---|
| `-NOWIN` | MATSU Editor には、常駐のプロセスがない。ほかの起動と同じに、ウィンドウを開く |
| `-GROUP=` | タブのグループに番号がない |
| `-DEBUGMODE` | `OutputDebugString` を見せるウィンドウがない |
| `-PROFMGR` | プロファイルマネージャーがない |
| `-GOPT=` の `U` `H` `X` | 標準出力へ書かない。見出しは、いつも付ける。カレントフォルダーを変えない |

## サクラエディタとの違い

- サクラは、コマンドラインを 1 つの文字列として読んで、空白で切ります。MATSU Editor は、OS が切った引数を、そのまま 1 つずつ読みます。空白を含むファイル名は、引用符で囲んでください。サクラが先頭の引数をつなげて、存在するファイルを探す動きは、しません。
- プログラム名の数字から文字コードを決める動き（`ParseKanjiCodeFromFileName`）と、長すぎるファイル名や使えない文字への警告の箱は、ありません。ファイルを開くときの、通常のエラーになります。
