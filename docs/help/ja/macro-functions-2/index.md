# マクロの関数（2）: 選択・クリップボード・挿入・変換

マクロから呼べるコマンドのうち、選択、矩形選択、クリップボード、挿入、変換をまとめた表です。名前の並びは、マツエディタの表 `MACRO_COMMANDS` の順です。

ほかの関数は、同じ並びの別のグループにあります。

- マクロの関数（1）: ファイル、編集、カーソル移動
- マクロの関数（3）: 検索、モード、設定、マクロ、ウィンドウなど
- マクロの関数（4）: 値を返す関数

各言語での呼び方は「マクロの使い方」の章にあります。ここには書きません。

## 表の読み方

- **マクロ名**: マクロが呼ぶ名前です。先頭に `S_` を付けた古い書き方（`S_Down` など）も通ります。大文字と小文字は区別します。
- **別名**: 同じ関数に複数の名前があるときは、同じ行に並べます。キーマクロに記録するときに使うのは、先に書いた名前です。
- **引数**: 型は「整数」と「文字列」の 2 つです。後ろの引数は省略できます。表にある数より多く渡すと、エラーになります。型が合わないときも、エラーになります。
- **戻り値**: このグループの関数は、どれも値を返しません。値を返す関数は、マクロの関数（4）にあります。
- **キーマクロに記録**: 「する」は、キー操作を記録したとき（キーマクロ）に、その操作が記録に入ることです。「しない」は、入らないことです。
- **MATSU での違い**: コードのコメントや試験に、サクラとの違いが書いてあるものだけを書きます。「記録なし」は、違いの記録がないという意味です。

## どの関数にも当てはまること

- 閲覧モードの文書は、書き換わりません。書き換える関数を呼ぶと、ビープ音が鳴ります。マクロは止まらず、次の行に進みます。
- 矩形選択があるとき、矩形に対応していない編集は、文書を書き換えず、ビープ音を鳴らします。
- 引数の数や型が合わないとき、またはテキストが要る関数にテキストがないときは、マクロにエラーが返ります。
- ウィンドウが要る関数（ダイアログを開くもの、ページ単位の移動、色付き HTML のコピーなど）は、画面のある MATSU Editor の中で動きます。
